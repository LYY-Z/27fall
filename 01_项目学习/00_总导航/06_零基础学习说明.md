# 按你的当前基础学机器人：白话讲解与学习办法

本说明根据你在P1学习中反复追问的内容整理。它用来决定教材应该怎么讲，不是对能力、智力或未来表现的评判。

## 1. 目前的学习起点是什么？

从对话看，你有编程基础，能跟踪变量、函数、数组和代码调用；当公式的对象与步骤说明清楚时，也能算出具体数字。你现在需要补的主要是机器人理论的地基：

- **向量和几何还不够熟。**点积为什么是某方向的分量、叉积怎样表示转动方向、坐标轴正负如何判断，需要从图和简单数字重新建立。
- **运动学和动力学还没有连起来。**角度、角速度、位置、力、力矩和惯量的区别，以及一个量怎样造成另一个量的变化，需要逐步解释。
- **控制器容易停留在公式记忆。**PID的每一环、级联控制里外环输出给谁、角速度反馈为何能提前制动，需要用机器人动作过程说明。
- **状态估计和优化仍是新知识。**协方差、Kalman增益、LQR的P/K、MPC约束等概念，暂时不能只靠符号推导理解。

这不等于“什么都不会”。你一直会追问“球为什么会这样动”“这个正负号对应哪边”“算出来的数送给了谁”。这说明你在检查因果关系；这正是学机器人和排查控制错误需要的习惯。现在最合适的描述是：**编程基础可用，机器人数学、物理与控制处在入门学习阶段，能在逐步解释和例子帮助下建立联系，尚不宜假设可以独立推导复杂公式。**

## 2. 后续文档统一怎样讲？

每一章按下面顺序展开。读者不需要先懂公式才能开始。

1. **先说现实里发生什么。**指出具体的轮、连杆、传感器、电机、消息或线程。
2. **说明这一步要解决什么。**先用一句普通话说结果想得到什么。
3. **认清输入和输出。**说明它们是什么东西、单位是什么、在哪个坐标系、是一项数还是一组数。
4. **再引入公式。**公式每个字母第一次出现都解释；说明为什么做乘法、相减、求导或积分。
5. **完整算一组简单数字。**每一步写出来，不从输入跳到最后答案。
6. **接回项目。**指出源码中谁提供输入、哪段代码做计算、结果写进哪个字段或交给哪个模块。
7. **说明可能失败的地方。**指出单位、符号、时刻、限幅、模式或模型假设如何使结果变错。
8. **最后练面试。**先给可以理解的中文回答，再给自然、不过度夸大的英文表达。

公式仍然保留，因为它是机器人的精确语言；但公式前后必须有解释。类比只用来帮助建立直觉，不能替代真实的力学或代码定义。

## 3. 遇到公式时按这五个问题读

以弧长公式 \(s=r\theta\) 为例，先不要背它：

1. \(s\) 是什么？轮子沿地面走过的距离，单位是米（m）。
2. \(r\) 是什么？轮子的半径，单位是米（m）。
3. \(\theta\) 是什么？轮子转过的角度；代进这条公式时要用弧度（rad）。
4. 为什么相乘？同样转一个角度，大轮子走得更远；同样的轮子，转得越多，走得也越远。
5. 数字怎样算？若 \(r=0.05\,\text{m}\)、\(\theta=2\,\text{rad}\)，则 \(s=0.05\times2=0.10\,\text{m}\)。

矩阵也按同一办法读：先说输入是什么，再说明每一行/列代表什么，最后只算一行乘一列。某一步不清楚时，先停在这一步，不要靠背后面的公式跳过去。
## 4. 你需要优先补的基础顺序

1. 单位、角度、三角函数；
2. 向量、点积、叉积、正负方向和坐标系；
3. 矩阵乘法、转置、逆矩阵与伪逆；
4. 位置、速度、加速度的导数和积分；
5. 质量、力、力矩、重心、转动惯量；
6. 传感器读数、噪声、滤波和状态估计；
7. 反馈、PID、级联、LQR、MPC；
8. 最后再把这些放回具体项目的源码和面试回答。

不要求先学完整数学课程。某章缺什么，就沿链接补那个小知识，再回来继续。

## 5. 一次只完成一个小学习闭环

拿“轮子角度怎样变成前进距离”为例：

1. 先画轮子和地面，标出半径与转动角；
2. 用 (s=r\theta) 算一次；
3. 把半径加倍，重新算并解释距离为什么加倍；
4. 找编码器反馈在源码中怎样进入计算；
5. 说出打滑时这个推算为什么不再可靠；
6. 用两句英文解释，并回答一个“这个假设什么时候不成立”的追问。

若只看过答案、不能自己把半径或转角换一个数字重算，就先标记为“看过”；能独立算并对上代码，才标“会用”。

## 6. 判断一份项目文档是否真的适合你

- 新名词第一次出现时有中文解释，而不是只有缩写。
- 公式前说“要算什么”，公式后逐项解释结果。
- 数字例写出中间步骤并标单位。
- 写清这是源码真实行为、教学模型、设计建议还是实测结论。
- 源码事实给出文件或函数入口；缺证据时直接说缺证据。
- 一页只围绕一个主要问题，不用一长串术语替代因果解释。
- 英文答案先能用中文讲通，不靠背句子掩盖不理解。

七个项目各有一条入门路径，详见[项目课程总览](../02_项目课程/00_项目课程总览.md)。如果仍读不懂某段，问题通常不是“你应该再背一次”，而是文档还没把某个对象、方向、时间或中间步骤讲清楚；把卡住的原句和那一步指出来即可继续拆解。
