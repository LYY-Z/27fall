## 使用方法

1. 先读[学校清单与事实核验](../01_学校清单与事实核验.md)，处理招生批次、项目名和 PS 版本风险。
2. 进面试前只练申请系统里确切匹配的一页；不需要把相近学校的课程混在一起。
3. 把英文答案里的方括号按系统正式专业名替换。若官方项目状态未确认，先向招生办公室或系统核实，不在面试里把推测当事实。
4. 每个“Why this programme”控制在 45–75 秒；被追问时再展开课程、经历、学习缺口和职业目标。
5. 项目技术细节回到[项目实习技术深挖](../03_项目实习技术深挖.md)，不要把每所学校的动机回答写成项目技术报告。
