# P7 术语表与三种长度口述

## 1. 最重要的术语

|中文|英文|口语化解释|
|---|---|---|
|轮腿机器人|wheeled-bipedal robot|用轮子移动、用腿改变支撑高度的机器人|
|五连杆闭链|closed five-bar linkage|五根杆首尾约束在一起的平面腿机构|
|正运动学|forward kinematics|给关节角，算腿端在哪里|
|逆运动学|inverse kinematics|给腿端目标，算主动关节角|
|状态空间模型|state-space model|用一组状态和输入描述系统下一刻如何变化|
|倒立摆|inverted pendulum|支撑点在下、质心在上的不稳定结构|
|拉格朗日方程|Euler–Lagrange equation|从动能、势能推导运动方程的方法|
|连续 LQR|continuous-time LQR|基于连续模型和二次代价计算反馈增益|
|变腿高增益调度|leg-height-dependent gain scheduling|腿高变化时使用不同反馈系数|
|虚拟模型控制|Virtual Model Control, VMC|软件先算腿端应施加的力，再换算为关节力矩|
|雅可比矩阵|Jacobian matrix|把关节小速度换成腿端速度的局部换算表|
|MIT 力矩字段|MIT torque field|通信结构中承载关节力矩命令的字段|
|TWAI/CAN|TWAI/CAN communication|ESP32 上的 CAN 通信接口路径|
|任务周期抖动|loop-period jitter|相邻两次任务实际运行间隔不稳定|

## 2. 20 秒版本

中文：

> 这是一个轮式双足机器人的课程项目。我按课程顺序学习了五连杆腿的正逆运动学、基于倒立摆的平衡控制和腿部 VMC。第八课从简化模型推导四状态连续 LQR；后续代码中，轮平衡反馈和腿部力矩映射是两条不同的控制路径。

English:

> This is a course-based study of a wheeled-bipedal robot. I studied five-bar leg kinematics, inverted-pendulum balance control, and virtual model control. The LQR model has four states and one torque input, while the later implementation handles wheel balance and leg joint torques through separate control paths.

## 3. 60 秒版本

中文：

> 我先从五连杆闭链的几何开始。已知两个主动关节角时，主动杆端点确定，两个被动杆长度约束输出点落在两个圆的交点上；逆解则从目标点反求主动角并选择可行分支。之后我按课程视频把机器人简化成轮驱动倒立摆，从动能和势能用拉格朗日方程整理出四状态、单输入的连续模型，再用 MATLAB 的 LQR 求反馈增益。第九课展示系数拟合的想法，第十一课则按腿高计算轮反馈系数，并用 VMC 计算腿端虚拟力、再映射到关节 torque 字段。我会把课堂模型、仓库代码和硬件实测结果分开说明。

English:

> I started with the closed-chain five-bar geometry. The active joint angles determine two link endpoints, and the passive link lengths constrain the output point to the intersection of two circles. I then followed the course derivation of a wheel-driven inverted pendulum, formed a four-state, single-input continuous model with the Euler–Lagrange method, and used MATLAB LQR to calculate the feedback gain. Later lessons show gain fitting and a separate VMC path from virtual leg force to joint torque commands. I distinguish the teaching model, the code snapshot, and any measured hardware result.

## 4. 两分钟版本的展开顺序

1. 先指明机械结构：两侧五连杆腿、地面轮、上方机身。
2. 解释几何：关节角如何决定腿端，逆解如何选解支。
3. 解释平衡物理：机身质心高于轮轴，轮子需要跟随身体移动以维持支撑。
4. 解释 LQR：简化模型四状态 \([\theta,\dot\theta,x,\dot x]\)，一个等效轮驱动力矩输入；LQR 的增益来自模型和 Q/R 代价。
5. 解释后续实现：轮目标反馈与 VMC 腿关节 torque 各做什么。
6. 说证据限制：周期、静态库单位和硬件性能需实测或补齐库/日志证据。

## 5. 避免的表达

不要说：“六状态 2×6 LQR 同时输出轮矩和腿矩。”当前选定课程中的第八课不是这套结构。

不要说：“仓库证明达到 1 kHz 或已安全恢复。”配置的发送间隔并非实测频率，且代码片段不足以证明完整安全状态机。

不要把模型 \(\tau\)、轮电机目标、关节 MIT torque 字段说成一个量。
