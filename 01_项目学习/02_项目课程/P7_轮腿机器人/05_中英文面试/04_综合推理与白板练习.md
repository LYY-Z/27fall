# P7 综合推理与白板练习

## 白板一：五连杆正运动学

画 O、D 两个固定轴；从 O 画长度 L1 的主动杆到 A，从 D 画长度 L4 的主动杆到 C。再以 A、C 为圆心，半径分别 L2、L3 画圆。交点是 B。

要讲出的重点：主动角先决定 A、C；被动杆长再共同决定 B；两个圆交点对应两种装配支路。标注第五课尺寸单位为 mm。

追问：如果两圆没有交点？目标/角度对应的闭链几何不可达，程序不能把虚数结果当正常输出。

## 白板二：视频中的 LQR 路线

画出轮轴平移 x、机身倾角 theta 和质心高度 h。状态：

\[
z=[\theta,\dot\theta,x,\dot x]^\mathsf T
\]

接着画“动能和势能 → 拉格朗日方程 → 两条耦合加速度方程 → A/B → Q/R → Riccati → K”。

要讲出的重点：第八课是四状态、一个等效模型力矩输入；它是教学用倒立摆近似。代码 B 最后一项需与手推消元核对，不能隐藏差异。

## 白板三：LQR、轮目标和腿 VMC 的界线

画三条并行标签：

- 第八课：状态 z → \(\tau=-Kz\)（模型输入）。
- 后续轮控制：pitch、gyro、位置、速度和腿高增益 → 左右轮目标。
- 腿部 VMC：腿端目标误差 → \(F_x,F_y\) → 几何映射 → 两个关节 torque 字段。

追问：为什么不是一个六状态两输出控制器？因为当前第八课 B 是 4×1；后续左右轮计算和腿关节 VMC 属于代码中的不同路径。

## 白板四：VMC 的转置映射

写腿端速度 \(\delta x=J\delta q\)，腿端功 \(F^\mathsf T\delta x\)，关节功 \(\tau^\mathsf T\delta q\)。令两边相等得到 \(\tau=J^\mathsf TF\)。

解释每个量：F 是作用在腿端的虚拟力；J 描述关节微动怎样改变腿端；关节力矩是电机需要提供的转动作用。强调这不是求速度用的伪逆。

## 白板五：第十一课一次循环

按真实顺序写：

wheel_control
→ CAN_Control（接收并发已有 torque）
→ remote_switch
→ calRightVMC / calLeftVMC（更新 torque）
→ snake_case
→ sendMotorTargets
→ storeFilteredPPMData / mapPPMToRobotControl

旁边画独立 IMUTask。追问时指出 VMC 新算出的 torque 通常到下一次 CAN_Control 才打包；配置的 1 ms 发送门槛不代表测得 1 kHz。

## 综合英文表达

> The course presents several connected control ideas rather than one monolithic controller. The LQR lesson derives a four-state, single-input balance model. Later code computes left and right wheel targets using feedback terms and leg-height-dependent gains, while the VMC path converts virtual leg-end forces into joint torque command fields. I would verify the actuator units and measure timing before claiming hardware performance.
