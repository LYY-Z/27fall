# 01 反馈平衡点采样与稳定性

先修：[估计与时间对齐](../04_传感器与状态估计/README.md)。项目：P1、P2、P3、P7。目标：能按单位和周期算一轮控制，解释反馈的作用与限制。

## 1. 发命令以后为什么还要重新测量

目标r=1m/s，读到y=.8，误差e=r-y=.2。控制器根据误差算u，电机接收后改变运动；下一周期要读新的y。电压、力矩、速度参考和位置目标都可能是u，但**u的含义由控制器所在层决定**，不是所有输出都等于“下一个位置”。

闭环：目标→误差→控制→执行器→机器人→测量→回到误差。没有反馈时，风阻、摩擦、打滑和负载变化不被自动纠正。反馈也不是万能，错误测量/符号/延迟会把控制方向带错。

## 2. 平衡点与误差坐标

系统ẋ=f(x,u)，平衡点满足f(x*,u*)=0。例如静止吊住重物仍要u*=mg，不是输入0。定义δx=x-x*，δu=u-u*。LQR常在此误差坐标设计；PID的e=r-y则与x-x*符号相反，不能直接混用增益符号。

手算一阶电机模型v̇=(-v+u)/τ，τ=.5s，保持v*=1需要u*=1（教学归一化输入）。当前v=.8、u=1.2，v̇=.8/s，dt=.01，Euler估计v_next=.808。控制输出1.2不是下一速度1.2。

## 3. 稳定是随时间不发散

最简单误差离散式e_next=a e。若|a|<1，误差逐步减小；a=-.5则正负交替减小，a=1.2则增长。a=1不衰减，不能说收敛。

同一电机、目标固定、u=kp(r-v)，得到误差ė=[r-(1+kp)e]/τ，纯P静态e=r/(1+kp)，输入不是固定的重力/负载补偿。若加正确前馈u=r+kp e，则ė=-(1+kp)e/τ。

Euler时前馈闭环e_next=[1-dt(1+kp)/τ]e。τ=.5,kp=4,dt=.01系数.9稳定；dt=.3系数-2，离散失稳。这个条件属于简化模型，不能当所有PID安全调参规则。

## 4. 采样、带宽与限制

采样频率1/dt是计算次数；闭环带宽是对变化响应能力。采样很快但电机响应慢/滤波延迟大，闭环仍不快。执行器幅值、速率与电流限制会改变实际响应；上线前需在明确模型/环境下观测。

## 5. 代码、失败与英文练习

[PID实验](../../03_代码实验/01_基础实验/08_PID抗饱和与级联/README.md)使用一阶模型，不等于真实电机。失败：控制正号与硬件方向相反形成正反馈；采样抖动；把限幅后系统仍当无约束线性；用旧状态过度纠正。

“A feedback controller repeatedly compares the reference with the measured state. Its output is an action or a reference for the next layer, and the plant dynamics determine how that command changes the state.”

追问：Does a high update rate guarantee a fast response? No. Plant dynamics, filtering and delay determine the achievable bandwidth.

1. 概念：平衡时u一定0？答：不，可能要重力/摩擦补偿。
2. 计算：e0=1,a=-.5，三步？答：-.5,.25,-.125。
3. 代码：误差定义从r-y改y-r怎么办？答：相应改变反馈符号，明确接口。
4. 解释：输出正确而状态不跟踪？答：查执行器单位/使能/限幅、动态、通信和传感器。

## 精读补充：把中间步骤讲清楚

### A. 一条命令的三种不同身份

位置环输出.3m/s，是速度参考；速度环输出.4m/s²，是加速度参考；电流环输入可能是1A。这三个数都叫控制量u，但模型B、限幅和单位完全不同。写控制图时在每条箭头旁标单位，比只写“PID→电机”更清楚。

### B. 离散稳定从三步看到

e_next=.8e、e0=1，三步为.8,.64,.512，趋向0。系数−.8则−.8,.64,−.512，左右摆但幅值缩小；−1.2则−1.2,1.44,−1.728，振荡越来越大。稳定不是“每次符号相同”，也不是“曾经经过目标”。限幅、延迟引入后不能继续只用这个单系数模型作保证。

英文练习：Define the signal before naming the controller. 答：The position loop generates a velocity reference, while the actuator interface determines the final command unit.
