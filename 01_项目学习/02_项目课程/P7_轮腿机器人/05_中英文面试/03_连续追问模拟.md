# P7 连续追问模拟：从原理追到证据

## 对话一：五连杆为什么不是普通二连杆

**Interviewer:** How do you calculate the leg endpoint?

**Candidate:** I use the two active joint angles to calculate the active link endpoints. The two passive link lengths constrain the output point to the intersection of two circles.

**Interviewer:** Why can there be two answers?

**Candidate:** Two circles can intersect at two points, corresponding to different assembly branches. The mechanism stays on one continuous branch, so branch selection must be consistent with the physical assembly and motion history.

**Interviewer:** Does the inverse-kinematics function guarantee that the robot can execute the target?

**Candidate:** No. The course function solves geometric angles. Actuator limits, collisions, motor dynamics, and safety still need separate checks.

## 对话二：LQR 到底是哪一套

**Interviewer:** How many states and inputs are used in the LQR lesson?

**Candidate:** The eighth lesson uses four states: body pitch, pitch rate, wheel position, and wheel velocity. The simplified model has one equivalent wheel torque input.

**Interviewer:** But the robot has two wheels and two legs. Why only one input?

**Candidate:** The lesson first reduces the physical system to a planar balance model to teach the derivation. It does not represent every actuator independently. Later code expands implementation into left and right wheel targets, while leg torques are calculated through VMC.

**Interviewer:** So are the two wheel targets the two outputs of that LQR?

**Candidate:** Not directly. The eighth lesson's B matrix is 4 by 1. Later control code uses side-specific feedback calculations to form wheel targets. The dimensions and interface are different.

## 对话三：腿高增益怎样来

**Interviewer:** Does the code solve LQR online as the leg changes height?

**Candidate:** I did not find an online Riccati solve. The later source evaluates height-dependent gain functions.

**Interviewer:** Where did the polynomial coefficients come from?

**Candidate:** The ninth-lesson fitting script contains sample gains at three heights and fits a quadratic. It does not show the process that generated each sample. The eleventh-lesson coefficients are a different set, so I would treat those snapshots separately unless their provenance is documented.

## 对话四：VMC 的力矩

**Interviewer:** What does VMC output?

**Candidate:** It first forms virtual leg-end forces from height and position errors, damping, gravity feedforward, and balance correction. A geometry-dependent force mapping then produces the front and back joint torque command fields.

**Interviewer:** Is that the same torque as the LQR input?

**Candidate:** No. LQR's tau belongs to the simplified wheel-pendulum model. VMC's values are leg-joint commands sent through the MIT torque field.

**Interviewer:** Can you claim those fields equal calibrated newton-metres?

**Candidate:** Not from the source alone. I would verify protocol scaling, motor configuration, and measured actuator response.

## 对话五：控制频率和数据延迟

**Interviewer:** The source says one millisecond. Does that mean one kilohertz?

**Candidate:** It is a 1 ms send condition in the CAN code, not a measured loop rate. The IMU task, loop workload, communication, and RTOS scheduling affect actual timing. I would measure timestamps and jitter.

**Interviewer:** Does every command use the latest feedback?

**Candidate:** Not necessarily. In the main loop, wheel control runs before CAN receive and before the new leg geometry is calculated. VMC computes torques after CAN_Control sends its current command structures, so the new torques are typically sent on the next pass.

## 对话六：如何不夸大项目成果

**Interviewer:** Did you make the robot stable?

**Candidate:** I would only make that claim if I can point to my role and synchronized test logs. The repository lets me trace the control structure, but code inspection alone does not establish stable hardware performance.

**Interviewer:** What would you record?

**Candidate:** Body pitch and rate, wheel and joint feedback, targets, applied commands, saturation, timestamps, communication age, and a defined disturbance/recovery test.
