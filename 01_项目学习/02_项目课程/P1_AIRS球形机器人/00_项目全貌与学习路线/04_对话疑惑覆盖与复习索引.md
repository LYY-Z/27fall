# P1 对话疑惑覆盖与复习索引

本页把多轮学习中卡住的概念按因果关系归并，指向已经展开讲解的正文标题。它用于定位和复习；完整公式、数值中间步骤、源码调用及实验操作在各主讲章节，不要求初学者从面试短答案自己补出推导。

本轮核查依据是现有 P1 文档、带补偿的 C++ 控制器、PID/滤波类、模型脚本、Pinocchio 节点、单独与整机组合 launch，以及底盘驱动。所有新增手算为教学例；仿真实验仍是学习操作指南，本轮没有执行实验、ROS 或实机，也没有改原源码。

## 2. 建议的复习顺序

1. **先认物体与量。**读[结构与状态](../01_原理与子系统/01_结构传感器与平衡状态.md)，画大球、小轮、机身、地面，写位置/角度/两种速度及其单位。
2. **先学运动学，再追控制。**完成 A 组轮速往返计算，再读 B 组两环端口与一个完整手算；合上文档能说清“参考”与“执行器命令”。
3. **单独建立动力学。**按 C 组从质心求导、能量、两条耦合方程一路到 Ac/Bc，最后学 Q/R/P/K；每次切换模型都先写输入单位。
4. **再做 D 组独立仿真。**准备环境、运行、保留元数据与曲线，再做每次一个因素的对照。此时才填写自己的实验结论，不提前填写示例性能。
5. **回到手臂与真实执行链。**按 E 组从 Rr+p 到质量加权，再解释重力矩和补偿，核对实际模型、关节数组与坐标证据。
6. **最后读 F 组保护和时间。**逐分支区分 reset、return、零字段与硬件停机，再按完整时间链说明每个频率和年龄。
7. **用英语复述并标出证据等级。**先中文画输入→计算→输出，再读[术语与三种长度口述](../05_中英文面试/01_术语与三种长度口述.md)、[原理实现问答](../05_中英文面试/02_原理实现与验证问答.md)和[实时性深挖](../05_中英文面试/05_控制链路与实时性深挖.md)。对源码可见行为用明确表达，对待验证性能用计划表达，对个人职责回查材料。
