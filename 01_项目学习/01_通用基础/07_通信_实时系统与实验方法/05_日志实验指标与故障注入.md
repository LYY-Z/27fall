# 05 日志实验指标与故障注入

先修：[04_设备生命周期通信与状态机](04_设备生命周期通信与状态机.md)。项目：P1—P7。目标：明确接口、时效、恢复和可追溯实验记录。

## 1. 实验回答一个明确问题

“控制更好”不够。先问：同一扰动下峰值误差是否下降？同一速度下是否饱和更少？延迟增加后是否稳定？定义自变量、保持条件、观测指标与失败标准，再运行。

日志至少time、reference、measurement、estimate、u_raw、u_applied、valid/status；另记模型、参数、单位、版本、seed、初态和完整命令。输出文件名不等于实测证据，需可追溯运行记录。

## 2. 手算误差指标

误差[.1,-.2,.1]m，平均误差0，不能说没有误差；MAE=(.1+.2+.1)/3=.13333m；MSE=(.01+.04+.01)/3=.02m²；RMSE=√.02≈.14142m；最大绝对误差.2m。

超调、恢复时间和稳态误差还需定义参考起点、容差带与保持时长。控制峰值/饱和时间评估动作代价，不只看位置。每周期.01s，连续20周期饱和累计.2s；周期不等时按实际dt求和。

## 3. 故障注入为何有用

在教学模拟加入固定偏置、噪声、延迟、丢帧、乱序、输入限幅或不可达目标。它们是不同原因，分别变化才知道算法哪个假设失效。软件模拟不连接硬件、不自动刷机。

先预测：延迟让反馈过时；偏置使积分漂移；乱序可能回退状态；饱和使原控制不可执行。再读实际日志对照预期，异常结果记录原因，不删失败只留漂亮曲线。

## 4. 数据与事实边界

教学真值可直接计算误差；真实机器人需外部参考或明确代理指标。没有外部真值只凭估计器输出平滑，不能说定位准确。队伍奖项不是某模块性能数据；源文件存在不是本人职责证据。

## 5. 实验、失败与英文

[学习记录](../../05_实验与学习记录/README.md)给模板，[综合闭环](../../03_代码实验/03_综合闭环/README.md)给人工真值。失败：改变多个参数又无法归因；复用旧输出当新运行；缺版本/单位；平均掩盖峰值；把未执行预期写成实测。

“I define the comparison conditions and metrics before running an experiment. I record both raw and applied control outputs, timing and failure status, and I distinguish simulation results from hardware evidence.”

追问：What if you have no ground truth? State that limitation and report the available proxy metrics without claiming absolute accuracy.

1. 概念：均值误差0代表RMSE0吗？答：正负抵消不表示无误差。
2. 计算：误差[1,-1]m的RMSE？答：1m。
3. 代码：两实验同目录输出怎么办？答：使用独立运行目录并记录命令，避免覆盖来源。
4. 解释：未运行的预期能写进CV吗？答：不能当历史成果，可作为学习实验计划/理解。
