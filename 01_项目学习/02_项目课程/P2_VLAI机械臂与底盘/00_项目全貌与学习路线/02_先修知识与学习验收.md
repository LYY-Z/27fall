# P2 先修知识与学习验收

## 先选一条线，不要把三套机器人当成一条控制链

先读[端到端流程与面试地图](03_P2端到端流程与面试地图.md)，确认现在学的是：

1. VR 手柄驱动仿真手臂；
2. Leader 手臂带动 Follower 手臂；
3. 差速底盘及待核实的ROS 2桥接。

三条线共用一部分机器人知识，但输入、控制目标和输出不同。一次只跟一条链，先说清“谁给了什么，程序算了什么，谁接收结果”。

## 进入每条线前需要的基础

| 学习主题 | 先认识的东西 | 暂时只需掌握的直觉 |
|---|---|---|
| VR 位置与朝向 | 三维坐标、向量、角度和弧度、旋转矩阵 | 位置是点在哪里；旋转说的是三根轴朝哪里。描述一个数时要说明它在哪个坐标系里 |
| SE(3) 与相对控制 | 刚体变换、矩阵乘法、初始位姿 | 手柄移动多少，先相对起点求增量，再映射到机器人；不是把 VR 房间的绝对坐标直接复制给机器人 |
| 正运动学与 Jacobian | 关节角、关节轴、连杆长度、导数 | 正运动学由关节姿势算末端位置；Jacobian 描述当前姿势下关节小变化对末端小运动的影响 |
| Mink、QP 与阻尼 | 向量范数、平方误差、线性约束、伪逆 | 求解器选一组折中解；阻尼惩罚大动作，但不等于硬限速；σ=0伪逆系数为0 |
| MuJoCo 仿真 | 关节状态、模型、积分时间步 | MuJoCo 用模型计算当前几何和运动；它可以做仿真，也能作为运动学计算工具，不代表真实机器人已经动了 |
| KDL 重力补偿与主从 | 质量、重力、力臂、力矩、关节坐标 | 手臂不动也可能需要电机力矩托住重量；Leader 的关节状态与 Follower 的目标要经过映射 |
| 差速底盘 | 轮半径、轮距、左右轮速度、线速度 | 左右轮同速主要前进，速度不同会转弯；实际命令单位要看电机接口和转换代码 |

通用数学入口：[基础课程总览](../../../01_通用基础/00_基础课程总览.md)。不用先学完整套微积分；需要偏导或矩阵运算时，先补定义，再对着本章的小例子算一次。

## 推荐学习次序

1. 先看端到端地图，把三条线分别画成“输入 → 状态/目标 → 计算 → 输出 → 反馈”。
2. VR 线先学坐标系、相对位置和相对旋转；再学 SE(3)、末端任务、当前位姿误差。
3. 接着学 Jacobian：关节转动怎样让腕部平移和转动；然后学 Mink/QP 如何把腕部任务分配到关节。
4. 最后学阻尼、奇异、限位和 MuJoCo 的小步积分。每一步都分清“求得的关节速度”“积分后的关节位置”和“仿真显示的姿势”。
5. 主从线单独读 URDF/KDL、重力力矩、Leader 状态到 Follower 目标的映射；不要拿 VR 的 Jacobian 求解过程替代这条线。
6. 底盘线从差速几何开始，接着追 PID、里程计、ROS 2 消息和电机接口。
7. 每个主题先重算教学例，再按源码地图确认当前仓库中实际使用的函数、参数和接口。

## 每个公式旁边标注五件事

写公式时，顺手写清：

- **对象**：手柄、机器人基座、手腕、关节还是轮子；
- **参考系**：VR 世界、机器人基座、手腕自身坐标还是电机坐标；
- **单位**：m、rad、m/s、rad/s、N·m，或设备协议整数；
- **形状**：例如位置是 3 个数，末端速度是 6 个数，7 个关节速度是 7 个数；
- **下游使用者**：这个数下一步交给哪个任务、求解器、仿真器或驱动。

例如，\(q\in\mathbb{R}^n\) 是 n 个关节位置，通常单位 rad；\(\dot q\) 是关节角速度，单位 rad/s。腕部位置误差用 m，朝向误差用 rad。单位不同的量不能直接相加。

## 学完一节后的验收

1. **先用白话讲因果**：实际哪个物体动了，目标是什么，程序为什么需要这一步。
2. **画坐标和结构**：标坐标原点、轴方向、关节轴和连杆；矩阵下标要能读成“从哪个系看哪个系”。
3. **检查维度与单位**：矩阵相乘形状能对上；每个结果的单位符合物理含义。
4. **手算一个小例子**：位置变换、Jacobian 单列、QP 折中或关节积分，至少能独立重算其中一项。
5. **说清模块边界**：MuJoCo 负责模型状态/仿真，Mink 负责任务求解，电机接口负责实机命令；调用仿真工具不等于真实电机执行。
6. **核对证据和失败**：指出源码调用位置，并举出超工作空间、奇异、关节限位、求解失败、状态过期等一种失效；教学例、仿真结果和硬件事实分别陈述。

辅助自检：手算
\[
R_z(90^\circ)\begin{bmatrix}0.1\\0\\0\end{bmatrix}
=\begin{bmatrix}0\\0.1\\0\end{bmatrix}.
\]
这表示“按手腕局部 x 轴描述的方向，换成基座坐标后指向基座 +y”；它本身不表示机器人已经移动了 10 cm。能解释这个区别，再进入 SE(3) 和逆运动学。

## 复习工具：三条线路，三张独立的数据链

P2 不是一条“VR→KDL→底盘”的串联控制器。复习时先选分支，再从输入一路追到实际输出：

```text
VR分支：手柄位置/朝向 → 相对初始位姿 → 坐标轴对齐C
       → 机器人腕部目标位置+朝向 → FrameTask/Jacobian/QP
       → 关节速度 q̇ → 小步积分 q_next → MuJoCo显示/仿真

主从/KDL分支：URDF质量/质心/惯量 + 关节状态
             → 重力模型 → 每个关节需要的保持力矩
             → Leader状态映射 → Follower命令/力矩接口

差速底盘分支：线速度/角速度目标 → 左右轮速度分配
             → ROS 2/驱动 → 轮反馈与里程计
```

每次复习，在图边注明“这是哪条分支、哪个坐标系、量的单位、谁消费输出”。不要把仿真关节速度说成实机电机电流，也不要把 KDL 重力补偿说成 VR 逆运动学。

### P2 易混概念对照

| 容易混在一起 | 应该怎样区分 |
|---|---|
| 位置与朝向 | 位置是三维点（m）；朝向是坐标轴方向（旋转矩阵/四元数等）。它们可合成位姿任务，但不能把米和弧度直接相加。 |
| 坐标变换与实体运动 | 旋转矩阵把向量从一个参考系换到另一个参考系；矩阵乘法本身不表示机器人真的动了。 |
| C与控制增益 | C是VR轴和机器人轴的方向对齐/标定，不是PID增益，也不是关节动作；变换左右顺序取决于明确的坐标约定。 |
| 正运动学与Jacobian | 正运动学给当前位置/朝向；Jacobian给当前姿势附近“关节速度→末端速度”的局部映射。 |
| (Jdot q) 与 (J^T F) | 前者把关节速度映射成末端速度；后者通过虚功把末端力映射为关节力矩，方向相反且物理量不同。 |
| Mink与MuJoCo | Mink构造/求解任务产生关节增量或速度；MuJoCo提供机器人模型、状态更新和可视化/动力学仿真。仿真显示不等于实机执行。 |
| QP代价与约束 | 代价是偏好之间的折中；硬约束限定必须满足的范围。阻尼项抑制过大关节步长，奇异附近以跟踪误差换稳定性。 |

### 自测题与检查要点

1. 手柄初始位置和当前位姿如何产生相对变化？检查点：初始值用于消去起始偏置；位置差与相对旋转分别处理。
2. VR 的 +x 为什么能映射成机器人基座 +y？检查点：由标定旋转矩阵的轴映射决定；不是“自然就相同”，要明确方向和乘法约定。
3. 机器人模型如何得到Jacobian？检查点：由当前关节姿态更新关节轴/末端位置，再用转轴叉乘力臂（旋转关节）或平移轴关系构造列；不是实机试动，也不要求MuJoCo才可在实机计算。
4. Mink如何使用Jacobian？检查点：FrameTask把位姿误差变成任务目标，QP选择一组尽量满足任务且不过度运动的关节速度；说明阻尼、权重和限值各扮演什么角色。
5. 为什么关节速度还要积分？检查点：δq≈q̇Δt，短周期内更新下一状态；再用新状态重算，是闭环迭代，不是一次求解到终点。
6. KDL分支中为什么静止时也可能需要力矩？检查点：重力矩随质量、质心力臂和关节姿态变化；补偿不是创造运动目标。
7. 主从两臂为何不能把关节数组直接复制？检查点：零位、轴方向、比例、限位、结构差异与时间同步都可能不同。

### 复习阶梯

先用纸画坐标系和机械臂几何，再手算一个纯 z 轴旋转、一个Jacobian列、一次阻尼QP的方向；然后在对应分支追到实际模型/调用和输出消费者。最后用英语讲 60 秒：**which branch, what is measured, what is transformed, what is solved, what moves, and what evidence confirms it**。当天复述、次日闭卷复述、一周后重算一次；若混淆分支，先退回三条数据链，不要继续叠公式。
