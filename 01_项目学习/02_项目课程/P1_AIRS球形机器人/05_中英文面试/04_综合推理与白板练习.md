# P1 综合推理、白板与源码追问

本页补充原25道主问，不重编号。每个场景按“中文理解→纸笔中间量→英语口述→源码追问”练；英文用客观源码/教学事实，个人经历句只按贡献证据填写。不要把参考答案当成自己已经完成的实验。

如果公式一眼看不懂，先不要硬算：把每个符号旁边写上“它代表什么、单位是什么、是谁给的”，用箭头画出数据变化，再用一个很小的数字手算。完成中文因果说明后，再练英文表达。综合主线可返回[项目白话总览](../00_项目全貌与学习路线/03_P1端到端闭环、数据时序与实时性.md)。

## 使用顺序

1. 用中文回答主问，画输入→计算→输出；写形状、单位、时刻。
2. 对照数字与原源码，指出假设和启用分支。
3. 用英语说45—90秒，回答第二层追问。
4. 记录卡住的是基础、项目、证据还是表达；下次只补对应环节。

## 场景1：坐标系与位置误差

**Interviewer:** The robot turns in yaw while the world position target remains fixed. What changes in the position loop?

### 先用中文把因果与中间量讲清

世界目标位置不随车身转；world2Body只做旋转。当前与目标都旋转后相减，Rᵀ(p*−p)等价于把世界误差旋到机身系，原点平移项相消。若机身yaw=90°、世界误差[1,0]m，用Rᵀ得到[0,−1]m，机身局部应朝负y修正。检查代码选择的是world-to-body矩阵，不能只看到函数名便认定主动旋转。

### Candidate：英语参考

I keep the target in the world frame and express the error in the body frame. The inspected function rotates both positions before subtraction, so their common origin offset cancels. For a ninety-degree yaw, a forward world error becomes a lateral body error. I would check the matrix direction with a basis-vector example.

**Follow-up:** What would happen if the inverse rotation were used?

中文追问答案：误差方向反转/混轴；记录yaw、世界误差与机身误差三者，用基向量查方向。

验收：能指出上述结论的源函数或教学假设；没有运行数据时，只说手算/静态所见，不补性能数字。

## 场景2：滤波与时间

**Interviewer:** Is the filtered IMU pose used by the controller?

### 先用中文把因果与中间量讲清

姿态四元数在此副本直接复制，角速度低通；不能把变量名filtered解释为所有分量都滤波。β=dt/(dt+1/(2πfc))，若dt=.01s、fc=.8Hz，β≈.04786，意味着本次新角速只占4.786%。dt来自控制freq，不一定等于IMU回调周期；过滤输出Header未在该函数复制。

### Candidate：英语参考

The orientation is copied directly in this snapshot, while angular velocity is low-pass filtered. The coefficient is based on a configured timestep, so I would compare it with actual callback timing. I would also preserve acquisition timestamps; a smooth value does not imply that it is current.

**Follow-up:** Could stronger filtering destabilize balance?

中文追问答案：可能因延迟增加；查传感器采样时刻、回调、滤波和控制输出时刻，不能只看曲线平滑。

验收：能指出上述结论的源函数或教学假设；没有运行数据时，只说手算/静态所见，不补性能数字。

## 场景3：前馈与限幅的顺序

**Interviewer:** How do feedforward and velocity limits interact?

### 先用中文把因果与中间量讲清

该路径先t2v缩放.75，再加入CoM补偿，又t2v缩放.75；所以前段控制项总乘.5625，补偿项乘.75，不能合成一次.75。随后向量L2限8，再输出低通。低通存在历史，完整数字例只算到命令滤波前；CoM速度字段没有被此控制链消费。

### Candidate：英语参考

I follow the active call order: one scaling, center-of-mass compensation, a second scaling, vector limiting, and output filtering. The two contributions therefore receive different effective gains. I separate the pre-filter hand calculation from a published command because the filter has memory.

**Follow-up:** Why not clip each axis independently?

中文追问答案：轴独立裁剪会改方向；L2统一缩放保留方向，但轮电机界还需单独映射后检查。

验收：能指出上述结论的源函数或教学假设；没有运行数据时，只说手算/静态所见，不补性能数字。

## 场景4：PID与LQR事实边界

**Interviewer:** Was LQR the deployed balance controller?

### 先用中文把因果与中间量讲清

现存实机路径为级联PID；LQR模型/教学对照分开。不能因论文式推导和SciPy程序存在便称原机运行LQR。四状态教学模型的A/B与新合成参数和连续CARE公式在实验中明确，运行K未核对。

### Candidate：英语参考

The inspected execution path uses cascaded PID. I can explain a separate LQR model and teaching comparison, but I do not present those as evidence of deployed LQR. A deployment claim would require a matched version, configuration and execution record.

**Follow-up:** What evidence would prove deployment?

中文追问答案：控制入口版本、启用配置、实机日志以及本人的具体改动记录，缺一个则描述范围降到已有证据。

验收：能指出上述结论的源函数或教学假设；没有运行数据时，只说手算/静态所见，不补性能数字。

## 场景5：保护不能只看名字

**Interviewer:** Does resetting the controller guarantee a zero motor command?

### 先用中文把因果与中间量讲清

源码跌倒分支reset/return不等价显式发零；等待使能超时仍继续。上次输出是否保留、下游是否有watchdog需要沿链追查。口述应说观察到的分支行为，不泛称安全机制完善。

### Candidate：英语参考

Resetting internal state and transmitting a stop command are different actions. The inspected return path does not itself prove that a zero command reaches the motors. I would trace the last command, the downstream timeout policy and the recovery transition.

**Follow-up:** Which log distinguishes reset from actual stop?

中文追问答案：reset事件、发布命令、驱动收到命令、轮反馈和超时事件，同一时间轴。

验收：能指出上述结论的源函数或教学假设；没有运行数据时，只说手算/静态所见，不补性能数字。

## 场景6：90秒综合口述

**Interviewer:** Explain one complete balance cycle without listing only libraries.

### 先用中文把因果与中间量讲清

从IMU/轮反馈开始，姿态直接与角速低通；统一状态/目标坐标，位置速度外环给有限姿态目标，姿态角速内环算虚拟动作，CoM补偿与两次缩放，球轮几何分配、限幅/滤波，反馈进入下一周期。指出yaw_angular_d平滑结果未作为YawLoop第四参数使用，避免按变量名补链。

### Candidate：英语参考

A cycle starts with the latest IMU and wheel feedback. I distinguish directly copied orientation from filtered angular rate, then express the tracking error in a consistent frame. The cascaded controller generates bounded balance references and virtual commands. Compensation and wheel geometry convert these into actuator targets. I trace the actual calls and limits, and I distinguish code behavior from hardware performance.

**Follow-up:** What did you personally decide?

中文追问答案：用贡献/材料映射中的已核实内容替换本人动作；不能把整条团队链都说成个人实现。

验收：能指出上述结论的源函数或教学假设；没有运行数据时，只说手算/静态所见，不补性能数字。
