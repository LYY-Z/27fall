# 02 AStarHybridAStar与运动基元

先修：[01_定位地图规划轨迹与跟踪](01_定位地图规划轨迹与跟踪.md)。相关项目：P5。目标：把本章算法接到输入、输出、手算和工程失败。

## 1. A*在Dijkstra上加“还多远”

节点评分f=g+h，g已走成本，h估计到终点剩余成本。四邻域单位格允许上下左右，曼哈顿h=|row-r_goal|+|col-c_goal|，不会超过无障碍最少步数。障碍只能让实际路径更长，所以它是可用下界。

手算3×3空图从(0,0)到(2,2)：初h=4。到(1,0)，g=1,h=3,f=4；到(0,1)也4。任一合理最短结果4步、5节点，具体平局顺序不唯一。别把节点数5误写距离5。

## 2. 车辆为何不能只走栅格邻居

车有姿态ψ和转弯半径，不能像点一样横移或在原地任意换方向。Hybrid A*保持连续[x,y,ψ]，每次选择转向/前后动作，用车辆运动方程生成短轨迹；用离散位置/角度桶管理访问与代价。

“Hybrid”在这里是连续运动状态与离散搜索的结合，不表示神经网络混合。运动基元是短段可行运动，不是把连续位置直接取整后随意邻接。

## 3. 手算运动基元

自行车模型轴距L=1m，转角δ=atan(.5)≈.46365rad，速度1m/s，角速v tanδ/L=.5rad/s，半径R=L/tanδ=2m。走.2s，yaw+.1rad，理想弧位移[2sin.1,2(1-cos.1)]≈[.19967,.00999]m。用小步积分近似并沿途检查车身，不仅终点。

搜索代价可加倒车、转向、切换惩罚；过大/不一致启发式可能影响最优性。角度桶分辨率与路径采样影响效率/近似；教学实现无解析Reeds-Shepp扩展，不称完整工业规划器。

## 4. 来源、实验和失败

见[Dolgov等原论文](https://ai.stanford.edu/~ddolgov/papers/dolgov_gpp_stair08.pdf)，查阅2026-10-02。基础[A*实验](../../03_代码实验/01_基础实验/12_搜索图像与协议/README.md)与[P5车辆实验](../../03_代码实验/02_项目实验/P5/README.md)分别实现两层。

失败：只测基元末点漏掉中途碰撞；没检查矩形足迹；角度不归一；无路径仍返回最后节点；将离散近似叫精确全局最优。

## 5. 英文与练习

“Hybrid A-star generates continuous vehicle motions but stores search states in discrete bins. It includes heading and feasible motion primitives, which a position-only grid search lacks.”

追问：Why sample each primitive? A collision can occur between its endpoints.

1. 概念：h代表已走还是剩余？答：剩余估计。
2. 计算：四邻域(1,2)到(4,6)曼哈顿？答：7步。
3. 代码：目标格占据？答：拒绝/报告失败。
4. 解释：点路径较短却无法转弯？答：车辆运动约束缺失。

## 精读补充：把中间步骤讲清楚

### A. A*为什么不能只挑离目标最近的点

候选A已走g=10、剩余h=1，总11；候选B已走g=3、剩余h=5，总8。只看h会选A，A*按g+h优先B。启发式是下界估计，不是已知真实剩余距离。

Hybrid A*从(x,y,ψ)推进基元，ψ=π/2时同样前进动作主要改变y；相同xy但不同ψ不能总合为同一状态，否则下一段可走方向不同。每段碰撞检查必须覆盖中间点和足迹。教学离散桶/有限采样会带来近似，不保证连续空间的精确最优。
