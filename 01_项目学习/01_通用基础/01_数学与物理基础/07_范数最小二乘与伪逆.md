## 1. 无解时为什么仍然想求一个结果

两个传感器测同一个x：x应该等于1，也应该等于3。两式不可能同时成立，但可以选一个折中值。误差向量r=Ax-b记录每条规则差多少。

若直接把误差相加，正负会抵消。选平方和：

\[
\|r\|^2=\sum_i r_i^2,
\qquad\min_x\|Ax-b\|^2.
\]

这里\(\|r\|\)是欧氏范数，表示整体长度；平方范数不需要开方，最小值位置相同，且求导方便。不同量单位不同时应先归一化或加权，不能直接把米误差与弧度误差混加后说物理总代价。

## 2. 一维最小二乘完整算

两条测量x=1、x=3，代价：

\[
E(x)=(x-1)^2+(x-3)^2=2x^2-8x+10.
\]

求导E'=4x-8，令0得x=2；二阶导数4>0，是最小值。残差[1,-1]，平方和2。若x=1，平方和4；若x=3也4。

矩阵写法A=[[1],[1]]，b=[1,3]，A是2×1，普通逆不存在。伪逆A^+=[.5,.5]，x=A^+b=.5×1+.5×3=2。

两个测量可信度不同时要加权，不是永远取算术平均。Kalman将在概率假设下推导权重。

## 3. 满列秩公式为什么是(A^TA)^{-1}A^T

把代价展开：

\[
E=(Ax-b)^T(Ax-b)
=x^TA^TAx-2b^TAx+b^Tb.
\]

对x求梯度：\(2A^TAx-2A^Tb\)。令0：

\[
A^TAx=A^Tb.
\]

这叫正规方程。A满列秩时A^TA可逆：

\[
x=(A^TA)^{-1}A^Tb,\qquad
\boxed{A^+=(A^TA)^{-1}A^T}.
\]

维度A=m×n，A^TA=n×n，A^+=n×m。这个公式要求独立列，不能对任何矩阵无条件使用。实际代码常用QR/SVD的lstsq，避免正规方程恶化条件数。

手算A=[[1,0],[1,1],[1,2]],b=[1,2,2]，A^TA=[[3,3],[3,5]]，A^Tb=[5,6]。解3c+3d=5，3c+5d=6：d=.5，c=7/6。拟合线c+d t对应三个测量的总体平方误差最小。

## 4. 多解时为什么选最小范数

只有一条任务：q̇1+q̇2=2。可以[2,0]、[1,1]、[3,-1]，都实现目标。

想让整体关节速度平方和最小：q̇2=2-q̇1，代价q̇1²+(2-q̇1)²。展开2q̇1²-4q̇1+4，求导4q̇1-4=0，得[1,1]。

这不意味着每个关节都最小；例如[2,0]第二关节更小，但整体平方和4>2。最小范数只按所选坐标尺度定义，不能自动保证避障、限位或最低能耗。

## 5. 满行秩公式A^T(AA^T)^{-1}是什么

A=m×n且m<n，独立任务少于输入，假设满行秩。为了同时满足Ax=b并最小化\(\frac12x^Tx\)，引入乘子λ：

\[
L(x,\lambda)=\frac12x^Tx+\lambda^T(Ax-b).
\]

对x求导：x+A^Tλ=0，所以x=-A^Tλ。代入约束：-AA^Tλ=b，λ=-(AA^T)^{-1}b。因此：

\[
\boxed{x=A^T(AA^T)^{-1}b},\quad
\boxed{A^+=A^T(AA^T)^{-1}}.
\]

它读成“先把任务b通过(AA^T)^{-1}组合，再用A^T分配到输入”。AA^T是m×m对称矩阵；A^+是n×m，通常不是对称矩阵。

A=[1,1]时，AA^T=2，逆=.5，A^+=[.5,.5]^T。目标2得到[1,1]。A=[1,2]时AA^T=5，A^+=[.2,.4]^T，目标5得到[1,2]，两输入共同贡献1+4=5。

## 6. 秩不足时怎么办

上述两种公式都需要相应满秩。一般矩阵用SVD：A=UΣV^T，将非零奇异值倒数、零保持0，再A^+=VΣ^+U^T。

Moore–Penrose伪逆在所有最小二乘解中选唯一最小欧氏范数解。**目标可实现时**精确满足Ax=b；**目标不可实现时**先让残差最小，再在这些解中让输入最小。

A=[[1,1],[0,0]]，目标b=[2,3]：第二行无论怎样输入都输出0，永远无法输出3。伪逆给[1,1]，实际输出[2,0]，残差[0,-3]。软件算出了有限解，不等于所有任务都实现。

## 7. 阻尼为什么多加λ²\|x\|²

接近奇异时，精确匹配可能需要巨大输入。用：

\[
\min_x\big(\|Ax-b\|^2+\lambda^2\|x\|^2\big).
\]

第一项扣输出误差，第二项扣输入大小。λ决定愿意为小输入牺牲多少输出精度。

求导：2A^T(Ax-b)+2λ²x=0，得到：

\[
(A^TA+\lambda^2I)x=A^Tb.
\]

这叫阻尼最小二乘/平方正则化。只看一维a=.01,b=1，普通逆x=100；取λ=.1，阻尼x=ab/(a²+λ²)=.01/.0101≈.9901，实际输出约.009901，明显牺牲任务精度。这个极端例子强调：阻尼不能凭空恢复不可控制方向。

## 8. 代码与项目

```python
import numpy as np
A = np.array([[1., 1.], [0., 0.]])
b = np.array([2., 3.])
x = np.linalg.pinv(A) @ b
achieved = A @ x
residual = achieved - b
```

P2速度IK常与约束/任务权重结合，不只是pinv一行；P7力矩映射使用J^T，不是本章速度反解J^+。四轮底盘若存在滚动一致性约束，也不能只因车体映射3×4就认为所有零空间轮速都是物理可执行动作。

失败：满秩公式套到秩不足；目标不可实现却只看返回值；输入/任务不同单位不设尺度；把最小范数当安全保证。

## 精读补充：把中间步骤讲清楚

### A. 一次手算2×3的伪逆

A=[[1,0,1],[0,1,1]]，目标b=[1,1]。约束是x₁+x₃=1、x₂+x₃=1，独立方程两条、未知量三个，满行秩。

先AAᵀ=[[2,1],[1,2]]，行列式3，逆为(1/3)[[2,−1],[−1,2]]。再左乘Aᵀ，得到A⁺=(1/3)[[2,−1],[−1,2],[1,1]]，形状3×2。

乘目标：x=[1/3,1/3,2/3]，代回得到[1,1]。为什么它最小？设x₃=z，则x₁=x₂=1−z，平方和2(1−z)²+z²=2−4z+3z²，求导−4+6z=0，z=2/3。与矩阵公式完全一致。

### B. 最小范数不是每个关节都最小

另一解[1,1,0]也精确实现目标，第三个关节为0，但整体平方和2；伪逆解平方和1/9+1/9+4/9=2/3，更小。若第三关节不允许移动，必须增加约束x₃=0，不能期待普通伪逆自动知道。

### C. 残差和输入同时写在报告里

最低要求报告Ax、b、Ax−b、输入大小和限幅。如果输出有不可能实现的方向，有限的伪逆解并不代表完成所有任务。P2与底盘分配特别要检查这一点。
