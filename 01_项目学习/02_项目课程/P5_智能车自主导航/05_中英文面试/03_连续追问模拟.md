# P5 连续追问模拟

训练方式：先不看答案口述，再看下面参考。每轮约10分钟，记录哪一步从理解变成背词。

**初学者练法：**第一遍只用中文讲清楚因果，不要求马上说出所有术语；卡住时停下来画对象、箭头和信号单位。第二遍再回答英文追问。先按定位→路线→跟踪→车辆命令讲过程，再说算法名。只有启动配置和调用能支持的算法才可称当前运行；历史配置和教学算法要另说。先用[项目白话总览](../00_项目全貌与学习路线/03_P5导航一趟路是怎样走出来的.md)把主线复述一遍。

## Round 1

**Interviewer:** What is the complete navigation chain?

**Candidate:** Sensors feed a timestamped estimator. The estimated pose is aligned with the planning frame, a feasible path is generated, and a tracker produces commands for the driver.

**Interviewer, deeper:** Which interface carries the tracking command?

**回答依据：** 传感器带时间戳进入估计，位姿转到规划坐标，规划路径，跟踪产生控制，驱动执行反馈；路径和带时间轨迹不同。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 2

**Interviewer:** What is the bicycle model?

**Candidate:** The rear-axle model uses position rates v cosine yaw and v sine yaw, yaw rate v tangent steering divided by wheelbase, and speed rate equal to acceleration. It is a kinematic approximation.

**Interviewer, deeper:** Why does the reference point matter?

**回答依据：** 后轴参考点下xdot=vcosyaw,ydot=vsinyaw,yawdot=v tan(delta)/L,vdot=a；低速几何假设，非完整动力学。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 3

**Interviewer:** What does an EKF do here?

**Candidate:** The EKF predicts the state with a nonlinear model and propagates uncertainty using local Jacobians. Measurement residuals then correct the prediction according to their uncertainty.

**Interviewer, deeper:** What happens if the initial estimate is very poor?

**回答依据：** 非线性运动预测均值，在估计点雅可比传播协方差，传感器创新修正；不是简单平均。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 4

**Interviewer:** Why separate map and odom frames?

**Candidate:** Odom provides local continuity but drifts. Map localization can introduce global corrections. The map-to-odom transform carries those corrections without treating them as instantaneous physical motion.

**Interviewer, deeper:** What happens if two nodes publish the same transform?

**回答依据：** odom短时连续但漂移；map可外部校正而跳变；map到odom承接校正，控制不能把全局跳变当真实速度。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 5

**Interviewer:** Why does Hybrid A-star include heading?

**Candidate:** A vehicle at the same position but with a different heading has different feasible next motions. Hybrid A-star simulates continuous vehicle primitives while organizing visited states in discrete bins.

**Interviewer, deeper:** What is lost when heading bins are too coarse?

**回答依据：** 同位置不同朝向的车可行动作不同；状态含x,y,yaw，连续运动积分，离散桶管理访问，不仅栅格邻点。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 6

**Interviewer:** What does TEB optimize?

**Candidate:** TEB optimizes poses and time intervals with objectives related to duration, smoothness, obstacles and kinematic limits. It is a local optimization method, so initialization and feasibility matter.

**Interviewer, deeper:** How does a path differ from a timed trajectory?

**回答依据：** 优化一串位姿与间隔时间，权衡时长、平滑、障碍和运动学；局部优化可能局部极值，不等于全局搜索。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 7

**Interviewer:** Why does MPC apply only its first input?

**Candidate:** Future inputs are a plan based on current information. Applying only the first input and replanning incorporates new observations and limits accumulated prediction error.

**Interviewer, deeper:** What should happen if the optimizer misses its deadline?

**回答依据：** 未来预测是当前信息下的计划，下周期用新状态重算，减少模型误差积累；可行性和计算截止期仍要处理。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 8

**Interviewer:** Which planner and controller does the available launch select?

**Candidate:** The available ROS2 configuration selects Navfn and regulated pure pursuit, with an additional L1-controller path. Older TEB files do not prove that TEB is active. Historical Hybrid A-star and MPC code remain unlocated in this snapshot.

**Interviewer, deeper:** How would you substantiate the historical CV description?

**回答依据：** 当前ROS2参数选Navfn和RegulatedPurePursuit，另有L1路径，旧TEB文件不证明正在启用；Hybrid/MPC实现未定位。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 9

**Interviewer:** Is every topic named cmd_vel a standard velocity command?

**Candidate:** A familiar message name does not prove SI semantics. The current L1 path uses device-scaled values around 1500 and a steering center around 90. Its driver protocol must be traced explicitly.

**Interviewer, deeper:** What failure could a unit mismatch cause?

**回答依据：** 标准Twist约定不代表此驱动遵守；当前L1路径linear约1500、angular90中心是设备尺度，需要协议转换，不能直接用m/s解释。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Contribution challenge

**Interviewer:** Which part did you personally implement, and what evidence supports that?

**Candidate template:** My own contribution was [verified module and decision]. The available source supports [specific function or interface]. A separate teaching experiment helps me understand the principle, but I do not use it as evidence of historical deployment.

## Evidence challenge

**Interviewer:** Did the available version actually run on the robot?

**Candidate:** The source snapshot and the deployed version must be matched using a commit, configuration and execution record. I would distinguish what I can trace in this snapshot from what I can substantiate with my own project records.

## 复盘答案标准

每问记录：公式/单位是否正确，能否指出函数，个人动作是否明确，验证是否有数据，限制是否诚实，英文是否可理解。不会则明确不知道的部分并解释已知部分。下次优先补一项，不改写成“已掌握”。
