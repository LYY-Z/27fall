# 03 限幅抗饱和微分与角度误差

先修：[02_PID三项离散实现与调参](02_PID三项离散实现与调参.md)。项目：P1、P2、P3、P7。目标：能按单位和周期算一轮控制，解释反馈的作用与限制。

## 1. 输入能力有限，积分为何会堆积

u_raw=12，电机限[-5,5]，实际u_sat=5。误差仍大，积分每周期增加；即使目标后来回来了，积累的输出还让机器人冲很久。这是积分windup，不是电机变得更强。

条件积分：不饱和时积；已上限且误差继续往上推时暂停，误差向下可继续让积分退出饱和。只判断“任何饱和都冻结”会阻止恢复方向的积分。

## 2. 回算状态的单位要统一

本库用Iu保存**积分项输出**，不是裸积分∫e：

\[u_{raw}=k_p e+I_u-k_d\dot y,\quad u=clip(u_{raw},u_{min},u_{max}),\]

\[I_{u,next}=I_u+[k_i e+k_{aw}(u-u_{raw})]dt.\]

Iu与u同单位，kaw单位1/s。若另用I=∫e，回算项要按该状态单位换算，不能直接把同一公式混用并再次乘ki。

完整手算：e=3,kp=4,Iu=0,kd=0，raw=12、sat=5。ki=1,kaw=2,dt=.1，Iu_next=0+[3+2(5-12)]×.1=-1.1。回算将不可能实现的输出拉回；负I不意味着错误，而是反映限幅差。

## 3. 微分为什么放大噪声

测量变化Δy=.001rad，dt=.001s，差分1rad/s；噪声很小也能变成大变化率。先对D滤波，如D_f=αD_prev+(1-α)D_raw；α大更平滑也更延迟。理想D没有无限带宽的实机实现。

目标突然跳变时ė含参考导数冲击；D用测量变化率可避免这一项，但参考仍需限速。不可把滤波输出滞后看成真正运动慢。

## 4. 角度跨界完整算

误差约定e=r-y。r=179°、y=-179°，普通差358°，归一化得-2°。相反r=-179、y=179，差-358°，最短+2°。

代码`(e+π)%(2π)-π`给[-π,π)，正180映成-180。恰好180两个方向长度相同，按接口选一支并保证一致。旧教材“r=179、y=-179得到+2”符号不对，已在此纠正。

## 5. 项目、排错与英文

P3云台跨界、P1姿态命令限幅、P7力矩限制都需要定义方向和模式切换。实验：[抗饱和](../../03_代码实验/01_基础实验/08_PID抗饱和与级联/README.md)。失败：积分仍无限增长；切换模式不重置/平滑；Ki重复乘；忽略输出变化率限制。

“Anti-windup makes the integral state reflect the actuator's actual limited output. I also filter derivative feedback and compute angular error using the shortest wrapped difference.”

追问：Does saturation preserve the original linear-controller guarantee? No. It changes the closed-loop dynamics.

1. 概念：限幅与抗饱和解决同一问题吗？答：限幅保护输入能力，抗饱和防积分积累导致恢复过冲。
2. 计算：e=2,kp=2,Iu=0,限5？答：raw=sat=4，回算差0。
3. 代码：裸I状态和Iu混用会怎样？答：单位/增益错，需固定一种。
4. 解释：目标到达后仍向前冲？答：查积分历史、惯性、延迟、限幅和参考，不只减kp。

## 精读补充：把中间步骤讲清楚

### A. 条件积分如何判断方向

上限5，raw=8，误差+1继续推高：暂停增加积分。下一次误差−1会拉低输出：应允许积分向回走。下限−5、raw=−8、误差−1时同理暂停，误差+1可恢复。这依赖Ki正且误差接口一致；不能只写“饱和就不积分”省掉方向。

回算用实际命令减原始命令：sat−raw=5−8=−3，会减积分输出。如果执行器还有限速，实际到达仅4，最好把实际实施的限制信息纳入抗饱和设计，而不是以为clip=5已经执行。

### B. 角度误差的符号从圆上判断

目标179°、当前−179°，当前位置等价181°，去179°应转−2°。目标−179°、当前179°，目标等价181°，应+2°。归一化只是选择最短差，不解决欧拉角三维姿态耦合。
