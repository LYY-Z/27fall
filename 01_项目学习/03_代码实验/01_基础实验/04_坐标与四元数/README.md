## 对照代码

`unit_quaternion`检查长度与有限性，再除范数；`quat_multiply`按标量、点积、叉积组合，不能逐分量乘。`rotate_vector`先嵌入[0,p]，两侧乘q与共轭。`slerp`处理负点积，截断浮点，近同向时归一化线性插值。

预期：绕z90°将[1,0,0]变[0,1,0]；q与-q结果相同。u=.5给[.923880,0,0,.382683]，物理角45°。四维夹角45°对应终点姿态差90°，不能混为一谈。零四元数报错。

输出`slerp.csv`列为插值比例、四元数、旋转后的单位向量、物理角rad。小的1e-16量可来自浮点舍入，不能当物理漂移。

练习：q1换绕x180°，观察z轴向量；q1全取负应保持短弧。让两个姿态接近，追踪程序进入线性分支。u超[0,1]拒绝，避免把外插当本实验插值。

故障：xyzw错当wxyz会产生不同旋转；单位化不能修复约定；非有限值拒绝。面试：Why does a quaternion use the half-angle? 见[推导](../../../01_通用基础/03_坐标_运动学与动力学/03_欧拉角四元数与半角.md)与[SLERP](../../../01_通用基础/03_坐标_运动学与动力学/04_四元数乘法双覆盖与SLERP.md)。
