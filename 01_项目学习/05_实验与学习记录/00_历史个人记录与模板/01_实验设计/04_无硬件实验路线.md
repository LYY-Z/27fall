# 无硬件实验路线

没有硬件时仍然可以形成完整的“理解—实现—验证—能讲”闭环。下面的路线优先使用 Python、NumPy、Matplotlib 和简单的状态模型；不要求先安装完整机器人系统。

## 第 1 层：手算

完成：

- 2×2 矩阵乘法、转置和逆；
- 向量点积、叉积和范数；
- 一次坐标变换；
- 一次 PID 更新；
- 一次一维 Kalman 更新；
- 一步离散状态方程。

验收标准：给出输入、每一步中间值和最终值。

## 第 2 层：最小代码

依次写出：

1. 二连杆正运动学；
2. 一阶低通滤波；
3. PID 与抗积分饱和；
4. 直线/圆弧轨迹跟踪；
5. A* 或 Hybrid-A* 的小地图搜索；
6. 阻尼最小二乘；
7. 一维或二维 Kalman 滤波。

每个程序至少画一张输入—输出曲线。

## 第 3 层：加入真实问题

逐个加入：

- 测量噪声；
- 采样周期变化；
- 时间延迟；
- 状态过期；
- 输出饱和；
- 坐标轴反向；
- 关节边界；
- 障碍物突然出现；
- 规划无解；
- 通信丢包。

每次只加入一种问题，先预测现象，再运行验证。

## 第 4 层：项目化组合

| 项目 | 无硬件组合实验 |
|---|---|
| P1 | 倒立摆 + 级联 PID + 三轮分配 + 质心扰动 |
| P2 | VR 相对位姿 + 二连杆阻尼 IK + 主从跟随 |
| P3 | 多电机闭环 + 云台/发射串级控制 + 功率限制 |
| P4 | 视觉置信度 + Agent 状态机 + 消息重试/去重 |
| P5 | 定位噪声 + Hybrid-A* + TEB 简化模型 + MPC/跟踪 |
| P6 | CAN 帧模拟 + 任务调度 + 看门狗和故障状态机 |
| P7 | 腿部 FK/IK + VMC 简化模型 + 腿长扰动下的轮速控制 |

## 第 5 层：口述

每个实验用 5 句话讲：

1. 机器人对象和问题；
2. 输入和输出；
3. 核心算法；
4. 我如何验证；
5. 如果失败我先查什么。
