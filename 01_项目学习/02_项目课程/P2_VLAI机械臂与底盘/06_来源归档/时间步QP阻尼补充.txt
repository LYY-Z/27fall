# 1. 小时间步具体是多少？根据控制周期来的吗？

## 1.1 文档里写的是多少？

你文档里，`XarmIKSolver.__init__` 写着：

```python
dt = 1/200s
```

也就是：

\[
dt = \frac{1}{200} = 0.005\text{ 秒} = 5\text{ 毫秒}
\]

这就是这个小时间步。

它的意思是：

> 每算一次 IK，只让关节走 5 毫秒那么久的一小步。

## 1.2 这个 5ms 是根据什么来的？

它是**这个求解器配置的控制周期**，不是 VR 手柄的数据周期，也不是真实电机的电流环周期。

文档特别提醒：

> VR 数据频率、低通延迟、机器人控制频率不是同一个量。

我们用一条时间线看：

```text
VR 手柄数据：可能 60Hz 或 90Hz，每 11ms 或 16ms 来一帧
低通滤波：可能再加几毫秒延迟
IK 求解器 dt：1/200 = 5ms
MuJoCo 仿真步：跟随 dt，也是 5ms
真实电机控制环：可能是 1kHz，甚至更高，例如电流环 20kHz
```

它们是不同层的周期。

## 1.3 为什么用 5ms 而不是 1ms 或 100ms？

你可以这样理解：

- 如果 \(dt\) 太大，比如 0.1s，一步走太多，手端可能走过头，甚至发散。
- 如果 \(dt\) 太小，比如 0.0001s，计算量变大，但精度提升有限。
- 5ms 是 200Hz，对仿真和遥操作来说是一个常见、合适的折中。

它不是唯一正确的值，只是这个求解器选的值。

## 1.4 小时间步在差分 IK 里怎么用？

差分 IK 的关系：

\[
\Delta q = \dot q \times dt
\]

- \(\dot q\)：求解器算出的关节速度，单位 rad/s。
- \(dt\)：小时间步，单位 s。
- \(\Delta q\)：这一步关节角变化，单位 rad。

文档里的例子：

\[
0.2\text{ rad/s} \times 0.005\text{ s} = 0.001\text{ rad}
\]

翻译：

> 求解器说“关节用 0.2 rad/s 转”，但一次只走 5ms，所以这一轮实际只转 0.001 rad。

下一轮重新算速度，再走 5ms，再更新。  
一步步累加，逐渐靠近目标。

## 1.5 关键句

> 小时间步 \(dt=1/200s=5ms\) 是 IK/MuJoCo 仿真这一层的控制周期。它不是 VR 数据频率，也不是真实电机控制周期。每算一次，只走这一步，然后重新计算误差，再走下一步。

# 2. QP 是什么？为什么叫“二次规划”？

## 2.1 先看一个最简单的“最小化”问题

假设你只有一个关节，需要决定它这一步动多少。

你希望末端靠近目标。  
如果雅可比是 \(J=2\)，末端误差目标是 \(b=1\)，那么：

\[
J\Delta q \approx b
\]

也就是：

\[
2\Delta q \approx 1
\]

理想解：

\[
\Delta q = 0.5
\]

但如果考虑多个关节、多个任务、多个限制，就没办法直接除一下得到答案。  
这时就需要一个“优化器”去找一组 \(\Delta q\)。

## 2.2 为什么目标函数是二次的？

误差平方和：

\[
\|J\Delta q - b\|^2
\]

把它展开，比如一维情况：

\[
(J\Delta q - b)^2 = J^2(\Delta q)^2 - 2Jb\Delta q + b^2
\]

你会看到：

- \((\Delta q)^2\) 是二次项；
- \(\Delta q\) 是一次项；
- 常数项不影响最小化。

只要目标函数里有平方，它就是二次函数。

“二次规划”意思就是：

> 目标函数是二次的，约束是线性的。

## 2.3 约束为什么是线性的？

约束写成：

\[
G\Delta q \le h
\]

比如：

- 关节角不能超过最大值：

\[
q + \Delta q \le q_{\max}
\]

这就是：

\[
\Delta q \le q_{\max} - q
\]

对 \(\Delta q\) 来说是线性的。

- 速度不能超过限制：

\[
|\dot q| \le \dot q_{\max}
\]

也就是：

\[
-\dot q_{\max} \le \dot q \le \dot q_{\max}
\]

对 \(\dot q\) 也是线性的。

所以整个问题就是：

> 找一个 \(\Delta q\)，让二次目标最小，同时满足线性不等式约束。

这就是 QP。

## 2.4 P2 里的 QP 长什么样？

概念形式：

\[
\min \sum_i \|W_i(J_i\Delta q - b_i)\|^2 + \lambda\|\Delta q\|^2
\]

约束：

\[
G\Delta q \le h
\]

逐项解释：

- \(i\)：第几个任务。比如左手位置任务、右手位置任务、姿态任务、Posture 任务。
- \(J_i\)：这个任务的雅可比。
- \(\Delta q\)：这一步关节变化。
- \(b_i\)：这个任务希望末端产生的小运动。
- \(W_i\)：权重。位置任务、姿态任务、Posture 任务谁更重要。
- \(\lambda\|\Delta q\|^2\)：阻尼项，防止 \(\Delta q\) 太大。
- \(G\Delta q \le h\)：线性约束，比如关节限位、速度限制。

求解器，比如 OSQP，会同时考虑这些任务和约束，找一组 \(\Delta q\)。

## 2.5 为什么不能直接解？

因为多个任务可能冲突：

- 左手要往左；
- 右手要往右；
- 关节有限；
- 姿态保持也想让关节别动。

没有一组 \(\Delta q\) 能完美满足所有任务。  
QP 的做法是：在所有可行解里，找一个让加权误差平方和最小的。

## 2.6 关键句

> QP 就是“目标函数是误差平方和、约束是线性不等式”的优化问题。它一次解出这一小步 \(\Delta q\)，不是一次性解出最终关节角。OSQP 是解这种问题的一个求解器。

# 3. 阻尼是什么？为什么要有它？

## 3.1 先看没有阻尼会怎样

假设机械臂快伸直了，接近奇异。

在奇异方向上，雅可比 \(J\) 的某个奇异值 \(\sigma\) 很小，比如：

\[
\sigma = 0.01
\]

如果你想让手端在那个方向速度为 1，普通伪逆会算：

\[
\dot q = \frac{1}{\sigma} = \frac{1}{0.01} = 100
\]

关节速度要 100 rad/s，非常夸张。

如果 \(\sigma = 0.001\)：

\[
\dot q = 1000
\]

直接爆炸。

问题是：

> 那个方向本来几乎就动不了，你硬要它动，关节速度就会爆炸。

## 3.2 阻尼怎么解决？

阻尼最小二乘的目标函数变成：

\[
\|J\dot q - v\|^2 + \lambda^2\|\dot q\|^2
\]

多了一项：

\[
\lambda^2\|\dot q\|^2
\]

它的作用是：

> 不光要让末端跟上目标，还要让关节速度别太大。

求导后：

\[
(J^TJ+\lambda^2I)\dot q = J^Tv
\]

在奇异值 \(\sigma\) 的方向上，增益从：

\[
\frac{1}{\sigma}
\]

变成：

\[
\frac{\sigma}{\sigma^2+\lambda^2}
\]

看几个数：

| \(\sigma\) | 普通伪逆 \(1/\sigma\) | 阻尼增益 \(\sigma/(\sigma^2+\lambda^2)\)，\(\lambda=0.1\) |
|---|---|---|
| 1 | 1 | 1/(1+0.01)≈0.990 |
| 0.1 | 10 | 0.1/(0.01+0.01)=5 |
| 0.01 | 100 | 0.01/(0.0001+0.01)≈0.990 |
| 0.001 | 1000 | 0.001/(0.000001+0.01)≈0.0999 |

结论：

- \(\sigma\) 很小时，普通伪逆增益趋近无穷。
- 阻尼增益趋近 0。
- 关节速度不会爆炸。

## 3.3 代价是什么？

代价是：

> 那个方向手端可能暂时跟不准。

文档里的例子：

\[
J=\operatorname{diag}(1,0.01)
\]

\[
v=[0,1]
\]

普通逆：

\[
\dot q=[0,100]
\]

阻尼 \(\lambda=0.1\)：

第二分量：

\[
\frac{0.01}{0.0001+0.01} \approx 0.990099
\]

末端该方向速度：

\[
0.01 \times 0.990099 \approx 0.009901
\]

目标速度是 1，实际只有 0.0099。  
残差大约 0.99。

翻译：

> 阻尼选择“这一步没完全跟上，也不让关节暴冲”。

## 3.4 阻尼不是什么？

文档强调：

- 阻尼不是硬速度上限。
- 阻尼不是关节位置限位。
- 阻尼不是避障。
- 阻尼不是碰撞检测。

它只是一个软惩罚项，让求解器倾向于选择更小的关节速度。

文档里的：

```python
FrameTask.lm_damping = 0.05
```

就是这个 \(\lambda\) 的一部分。

## 3.5 关键句

> 阻尼是在目标函数里加一项 \(\lambda\|\Delta q\|^2\)，让求解器在“跟目标”和“关节别动太快”之间折中。它让奇异附近不爆炸，但会产生跟踪残差。它不是硬限制。

# 4. 限位是什么？为什么和阻尼不是一回事？

## 4.1 限位是硬约束

限位是“绝对不能超过”的边界，比如：

- 关节角不能小于 \(q_{\min}\)。
- 关节角不能大于 \(q_{\max}\)。
- 关节速度不能超过 \(\dot q_{\max}\)。
- 不能碰撞。

这些写成约束：

\[
q_{\min} \le q + \Delta q \le q_{\max}
\]

\[
|\dot q| \le \dot q_{\max}
\]

在 QP 里就是：

\[
G\Delta q \le h
\]

这类约束是硬性的，求解器必须满足。  
如果满足不了，就叫“不可行”。

## 4.2 阻尼和限位的区别

| | 阻尼 | 限位 |
|---|---|---|
| 形式 | 加在目标函数里 \(\lambda\|\Delta q\|^2\) | 加在约束里 \(G\Delta q \le h\) |
| 性质 | 软惩罚 | 硬约束 |
| 作用 | 让速度别太大，避免爆炸 | 绝对不能超过边界 |
| 违反后果 | 可以违反，只是代价大 | 不允许违反，否则不可行 |
| 是否等于避障 | 不是 | 如果显式写了碰撞约束，才是 |
| 是否等于关节限位 | 不是 | 如果显式写了关节角约束，才是 |

## 4.3 P2 文档为什么特别提醒“本地调用未显式传 limits”？

因为在 `XarmIKSolver` 里，调用 Mink 求解时**没有显式传 `limits` 参数**。

这意味着什么？

文档说：

> 2026-10-02 查上游 `solve_ik`：`limits=None` 默认 configuration limit；空 list 关闭；显式速度/碰撞限制需配置。

翻译：

- 如果 `limits=None`，Mink 可能会用机器人配置里的默认关节限位。
- 如果你传空 list，就关闭限位。
- 如果你想加速度限制、碰撞限制，要显式配置。

但关键是：

> 当前上游行为不能替代项目当时安装版本证据。

也就是说：

- 你现在去看 Mink 最新代码，它可能默认有 configuration limit。
- 但 P2 项目当时安装的是哪个版本，不确定。
- 没有锁定版本，就不能说“这个项目已经证明碰撞和速度全受约束”。

## 4.4 四层不同的东西

文档强调：

> 配置姿态约束、任务软权重、求解器选项、最后电机限幅是四层不同东西。

翻译：

1. **配置姿态约束**：比如关节角范围，属于硬约束。
2. **任务软权重**：比如 position_cost、orientation_cost、posture_cost，属于软目标。
3. **求解器选项**：比如 lm_damping、solver=osqp，影响怎么解。
4. **最后电机限幅**：真实电机还有自己的位置、速度、力矩上限，和 QP 无关。

这四层不能混。

## 4.5 关键句

> 限位是硬约束，必须显式写进 QP 或配置里；阻尼是软惩罚，只是让速度别太大。文档未锁定 Mink 版本，所以不能声称碰撞和速度限制都已生效。

# 5. 把四件事串起来

用一句话总结整个差分 IK 每一步：

1. **当前状态**：MuJoCo 给出当前关节角 \(q\)。
2. **目标**：VR 给出末端目标 SE3。
3. **误差**：当前手端和目标差多少，变成希望速度 \(b\)。
4. **雅可比**：\(J\) 告诉关节速度怎么影响手端速度。
5. **QP**：找一组 \(\Delta q\)，让加权误差平方和最小。
6. **阻尼**：目标函数里加 \(\lambda\|\Delta q\|^2\)，防止奇异附近爆炸。
7. **限位**：约束 \(G\Delta q \le h\)，如果显式配置了，就必须满足。
8. **小时间步**：\(\Delta q = \dot q \times dt\)，\(dt=1/200s=5ms\)。
9. **积分**：把 \(\Delta q\) 加到 \(q\) 上。
10. **MuJoCo 更新**：`mj_forward` 算新的手端位置和朝向。
11. **下一轮**：重复。

再压缩成三句话：

- **小时间步**：\(dt=5ms\)，是 IK/仿真层的控制周期，不是 VR 频率也不是电机频率。
- **QP**：目标函数是误差平方和，约束是线性的，解出这一小步 \(\Delta q\)。
- **阻尼 vs 限位**：阻尼是软惩罚，防止速度爆炸；限位是硬约束，必须显式配置，未锁版本不能声称已生效。
