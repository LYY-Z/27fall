# P3 先修知识与学习验收

## 先知道这台机器人同时在做几件事

先读[从遥控输入到电机电流](03_P3端到端任务与反馈链.md)，把云台、发射机构和底盘分开。它们共用 MCU、传感器和 CAN，但不是同一个控制环。随后按[源码地图](../02_源码阅读与运行/01_源码版本与文件地图.md)确认当前代码分支和调用路径。

## 进入各章节前的必要直觉

| 主题 | 先会什么 | 最容易混淆的地方 |
|---|---|---|
| 传感器与姿态 | 加速度、角速度、角度、编码器计数 | SPI/DMA 收到的是传感器原始寄存器数据；四元数和姿态角由后续姿态解算计算 |
| FreeRTOS | 任务、优先级、系统 tick、中断 | 延时配置不是实测周期；任务变为可运行也不代表立刻拿到 CPU |
| 云台级联 PID | 角度、角速度、误差、反馈 | 外环通常给期望角速度，内环输出的是电机接口命令；不能未核协议就称为 N·m 或安培 |
| 摩擦轮/拨盘控制 | RPM、编码器累计角、PID、饱和 | 变比例 PID、滑模控制是控制律；必须追版本和实际调用，不能见到函数就说它正在运行 |
| 麦轮底盘 | 车体前进/横移/转动、轮序、正负号 | 轮速组合依赖几何和轮序；换轮顺序或坐标方向，矩阵符号会改变 |
| 堵转与功率 | 电流/速度反馈、功率、缓冲能量 | 堵转判断是“命令有动作但反馈没有相应变化”的检测；功率限制还要沿电机输出继续追踪 |
| CAN 与状态 | 报文、设备 ID、反馈更新时间 | 收到 CAN 报文不自动证明数据新鲜、字段单位正确或电机已执行 |

## 推荐学习路线

1. **先搭系统图**：遥控/视觉/裁判/IMU/电机反馈分别进入哪里；命令最终走哪个 CAN 输出。
2. **先学传感和任务**：原始 IMU、DMA 完成回调、姿态解算、任务周期和共享状态。
3. **再学云台闭环**：目标角 → 角度环 → 期望角速度 → 速度环 → 电机命令 → 编码器/陀螺反馈。
4. **单独学发射机构**：摩擦轮转速、拨盘角/速度、发射状态机、堵转判断与处理；将 PID/SMC 的定义和活动版本分开。
5. **之后学底盘**：车体速度与四轮速度换算、轮速反馈、功率缓冲和输出缩放。
6. **最后回到并发问题**：任务优先级、阻塞、中断负载、周期抖动和数据快照会怎样影响闭环。

## 必做的三个时间与单位检查

- 600 RPM 换成角速度：\(600\times2\pi/60\approx62.83\ \mathrm{rad/s}\)。若减速比为 10:1，输出轴约为 \(6.283\ \mathrm{rad/s}\)，前提是齿比方向定义清楚。
- 若某任务每轮计算 \(0.4\ \mathrm{ms}\)，再相对延时 \(1\ \mathrm{ms}\)，理想化循环约 \(1.4\ \mathrm{ms}\)，约 \(714\ \mathrm{Hz}\)；这不是源码实测值。
- PID 的给定和反馈必须同单位、同坐标方向。角度用度还是弧度、速度用 RPM 还是 rad/s、命令是协议整数还是物理量，都要从转换代码确认。

## 每章验收：不只背算法名字

1. **画出实体链**：传感器/遥控输入 → 状态估计 → 控制环/状态机 → 限幅与协议 → 电机 → 新反馈。
2. **写清每个量**：实际对象、单位、符号约定、缓存更新时间和下游使用者。
3. **手算一次**：转速换算、轮速矩阵、PID 一个周期或堵转判据，至少重算一项。
4. **核源码调用**：指出哪个任务调用了哪个函数；区分定义、注释、条件分支和当前活动分支。
5. **分析异常**：反馈过期、任务延迟、编码器跨圈、输出饱和、堵转或 CAN 失联时，代码具体做什么；没有证据的保护不能说成已有。
6. **分清证据级别**：源码静态阅读只能说明实现路径；实测频率、发射成功率、跟踪误差要有日志或实验记录。

详细复习入口：[历次问题归纳与完整讲解](../05_中英文面试/05_历次问题归纳与完整讲解.md)。未学、能解释、会手算、能追源码和经过实测是不同掌握阶段。

## 复习工具：先辨认任务，再读控制律

P3 的重点不是把所有算法揉成一个“总控制器”，而是理解多个 RTOS 任务怎样共享传感器、CPU和CAN：

```text
IMU原始数据 → SPI/DMA接收 → 标定/姿态解算 → 云台角度与角速度反馈
编码器/CAN反馈 → 解码与状态更新 → 云台/发射/底盘各自控制
遥控/视觉/裁判输入 → 目标或状态机 → PID/SMC/运动学/功率约束
                                    ↓
                         协议命令 → CAN电机 → 新反馈
```

云台、发射机构、底盘是不同子系统；任务优先级、tick、中断和通信会影响它们读写数据的时间。每次复习都标清：输入是在中断还是任务更新、控制函数在哪个任务调用、输出何时发CAN、反馈何时回来。

### P3 易混概念对照

| 容易混在一起 | 应该怎样区分 |
|---|---|
| SPI/DMA数据与姿态 | DMA搬运传感器寄存器数据；AHRS再融合陀螺/加速度等更新姿态四元数，四元数不是BMI088原始输出。 |
| 配置延时与控制频率 | `vTaskDelay`/`osDelay`给任务等待请求；执行耗时、tick相位、抢占、中断与阻塞都会改变真实周期。实测要打时间戳。 |
| 角度环与速度环 | 角度环通常产生期望角速度；速度环根据角速度误差生成电机接口命令。协议整数不自动等于A或N·m。 |
| 变比例PID与SMC | 都可能用于转速控制，但控制律、参数意义、切换/饱和行为不同。要追当前配置/调用，不能只看到函数定义就认定活动。 |
| 堵转与普通误差 | 堵转要看“已有有效驱动命令而反馈长期不符合预期”等证据；单次速度低不够，需结合持续时间、电流/速度与状态。 |
| 发射逻辑与电机控制 | 状态机决定何时预热、允许发射、推进/停止；底层速度环负责转速。命令被发出不证明弹丸已成功通过。 |
| 轮速、车速、功率 | 麦轮运动学在车体速度和各轮速度间换算；功率限制另受电机负载、裁判状态和缓冲能量约束。 |

### 自测题与检查要点

1. 从BMI088读数到yaw/pitch角，中间经过哪些阶段？答题检查：原始采样、DMA完成/数据解码、标定与滤波、姿态融合、四元数转欧拉角；写明坐标系和单位。
2. `vTaskDelay(1)`是否证明1 kHz？检查点：否；算周期须加执行时间及调度延迟，并以运行时间戳验证。
3. 云台的角度目标怎样变成电机命令？检查点：角度误差→期望角速度→速度误差→协议命令→电机→新反馈。
4. 堵转判据需要哪些观测？检查点：给定/实际转速、实际电流或负载、持续时间、状态机状态、最后命令/反馈时间；阈值需由硬件和实验定，不背一个通用数。
5. 麦轮逆运动学输出是什么？检查点：四个轮的目标速度/角速度（具体单位看接口）；不是直接得到电机扭矩，也不应跳过轮序和符号验证。
6. 如何区分“算法卡住”和“任务没按期运行”？检查点：同时记录循环开始/结束、执行耗时、反馈时间戳、命令时间戳、队列/阻塞状态和限幅标记。

### 复习阶梯

选云台、发射、底盘各画一条小链；然后分别手算RPM↔rad/s、一个角度环误差、一个轮速映射。回源码时至少找到任务创建、控制调用、命令发送三处。最后能解释“配置值≠实测表现”，并用日志证据说明一次堵转/延时/丢反馈如何定位。当天复述、次日闭卷画链、一周后重算一个单位换算。
