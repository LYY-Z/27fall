# 最终文件格式与推荐信签署流程

## 文件格式

申请提交时使用 PDF，不使用 Markdown。当前每个授课型项目包中的 `02_PS/最终PDF_修正版` 和 `03_推荐信/最终PDF_信头修正版_2026-09-07_白底` 已完成统一排版，并与对应 Markdown 正文保持一致。

- Personal Statement：英文 PDF 用于正式提交，中文 PDF 用于本人核对和面试准备。
- Recommendation Letter：英文 PDF 用于推荐人审核和后续提交，中文 PDF 用于本人核对。
- Markdown：保留为源稿，方便在学校名称、项目名称、日期或推荐人提出修改时快速更新。
- 推荐信 PDF 已生成日期为 2026 年 9 月 7 日的待签署版本。AIRS 版本采用申请人提供的 AIRS 录用通知书页眉作为信头来源；学校版本采用申请人提供的深圳技术大学专业排名证明页首校徽和中英文校名作为信头来源，并已处理为纯白背景。两类版本都仍需推荐人确认内容，并由推荐人按学校或机构要求签名后，才形成最终上传件。
- 深圳技术大学页眉仅提取了学业证明的校徽和中英文校名，没有使用排名证明的正文、公章、日期或教务部落款；若学院或推荐人能提供正式推荐信用信纸，应优先替换页眉，正文无需改动。

## 推荐信签名原则

推荐信是否由申请人上传、是否由推荐人直接提交，取决于目标项目的申请系统：

1. **申请人上传推荐信**：推荐信应由推荐人确认内容，并使用机构信头，包含推荐人姓名、职务、单位、联系方式、日期和签名。签署后的 PDF 才是可上传版本。
2. **系统向推荐人发送链接**：申请人只填写推荐人信息，推荐人通过邮件链接在线填写、上传或确认。申请人不应代替推荐人点击提交；如系统要求上传附件，附件仍应由推荐人确认并签名。
3. **保密推荐信**：若系统标明 confidential，申请人应把当前排版版发送给推荐人审核，之后由推荐人按系统要求直接提交或回复学校。

## 操作顺序

1. 将对应项目的英文推荐信 PDF 发给导师/企业导师确认。
2. 推荐人修改或确认正文，并补充正式机构信头、日期和签名。
3. 申请人在网申中填写推荐人姓名、职务、单位、邮箱等信息；不填写推荐人的电话，除非目标系统明确设为必填。
4. 需要直接提交的项目，确认推荐人收到系统邮件，并在截止时间前完成在线提交。
5. 需要申请人上传的项目，上传推荐人确认并签署后的 PDF；不要上传带有空白签名栏的版本。
6. 最终上传前检查项目名称、申请人姓名、推荐人身份和申请编号是否对应，避免把另一所学校的版本上传到当前项目。
