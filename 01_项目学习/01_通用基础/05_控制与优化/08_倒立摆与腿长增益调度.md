# 08 倒立摆与腿长增益调度

先修：[07_未来代价P与Riccati逐步计算](07_未来代价P与Riccati逐步计算.md)、[二次型](../01_数学与物理基础/09_特征值二次型与稳定性.md)。项目：P1、P7。目标：从模型到成本、P和K逐步手算。实验：[LQR](../../03_代码实验/01_基础实验/09_LQR与Riccati/README.md)。

## 1. 平衡模型为何包含倾角和角速度

只看位置，无法知道身体是否快要倒；只看倾角，不知道正往哪边倒。简化四状态可是[位置,速度,倾角,倾角速度]。倒立摆顶端直立附近重力会使小倾角继续增大，线性式含+g/l θ，不像下垂摆的恢复项。

电机驱动轮/底座运动会改变倾角，A/B由质量、质心高度、惯量、轮半径和耦合方程得到。P1实际linear_model用四状态连续模型，再调用连续LQR；本教材基础实验用离散双积分，两者不可混为同一计算。

## 2. 手算长度改变自然动态

简化倒立摆θ̈=(g/l)θ，l=.5m时g/l=19.62/s²；l=1m时9.81/s²。相同小倾角.05rad时角加速度分别.981与.4905rad/s²。真实轮腿模型耦合更多，但例子说明长度改变动态系数，固定K不一定覆盖所有长度。

## 3. 增益调度如何设计

选一组合法腿长L_j→各自建立/线性化模型A(L_j),B(L_j)→统一状态/输入和Q/R→求K_j→插值或拟合K(L)。运行时测/估当前L，取对应K；范围外有明确降级或钳制策略，不能无限外推。

P7源码用每个增益c₀L³+c₁L²+c₂L+c₃，12个数对应两个输出×六状态。多项式计算函数存在，只能证明运行时求值路径；离线模型、Q/R与拟合脚本尚需证据。

教学手算系数[2,-1,.5,.1]、L=.2，K=2×.008-.04+.1+.1=.176。系数教学合成，不是P7实际增益。用Horner形式((2L-1)L+.5)L+.1计算相同值。

## 4. 调度不是自动稳定保证

每个冻结长度下稳定，不自动意味着快速变长度的整体时变系统稳定。K切换、噪声、延迟、模型拟合误差、输入饱和都会影响。需要检查调度范围、变化率、闭环极点/仿真和实际记录；仅看某点K不能断言整机稳定。

变高度还改变接触几何、质心和电机能力；LQR处理身体状态，VMC把虚拟力与力矩映射到关节，轮腿共同反馈。

## 5. 代码、失败与英文练习

[LQR实验](../../03_代码实验/01_基础实验/09_LQR与Riccati/README.md)包含多项式接口；[P7课程](../../02_项目课程/P7_轮腿机器人/README.md)追踪真实数组顺序。失败：系数顺序倒；mm当m；调度超范围；状态符号左右不一致。

“Leg length changes the model, so the feedback gain can be scheduled over that parameter. I must preserve the state and input conventions and check the transition dynamics, not only stability at fixed lengths.”

追问：Does a polynomial prove how the gains were designed? No. It shows runtime evaluation, while the offline model and fitting process need separate evidence.

1. 概念：调度变量L是误差状态吗？答：可另作模型参数，不等同六状态之一的固定定义。
2. 计算：教学L=.3的K？答：.054-.09+.15+.1=.214。
3. 代码：系数[k,4]表示什么？答：每行一增益，列依次三次、二次、一次、常数。
4. 解释：固定长度仿真稳定，变腿长实机也稳吗？答：不能直接推出，需时变/接触/饱和与实际验证。

## 精读补充：把中间步骤讲清楚

### A. 腿长改变时，不能只改图上的高度

简化θ̈=(g/l)θ，l变短使倾倒增长更快；同一K对应的闭环模型也改变。调度把当前l映射到K(l)，再用同一状态顺序计算u。l=.2m和200mm物理相同，但若系数按米拟合却代入200，三次项放大10⁹，输出会荒谬。

在两点K(.2)=1、K(.3)=2之间作线性插值，l=.25得到1.5；在.5用这两个点外推得到4，并不代表该长度经过设计。P7原代码采用三次多项式，必须区分“求值公式存在”和“拟合/稳定范围已经证明”。
