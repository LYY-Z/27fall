# 虚拟腿长、方向角和变化速度

## 1. 为什么把多根杆看成一条虚拟腿

真实腿由定长连杆组成，没有一根金属杆真的伸缩。为了让控制器能表达“机身离轮轴多远、腿指向哪里”，可以选机身参考点 O 和轮轴中心 C，用连线当作虚拟腿：

        O（机身参考点） o
                        \  L
                         \
                          o C（轮轴）

虚拟腿长是 O 到 C 的距离，不等于五连杆中任何一根杆长。

若 \(r=(x,y)=C-O\)，则：

\[
L=\sqrt{x^2+y^2},\qquad \phi=\operatorname{atan2}(y,x)
\]

角度从哪条轴开始量、正方向如何定义，要以具体课程变量为准。不同课次中的 theta、phi 不应未经核对直接等同。

## 2. 腿长变化率从哪里来

\(\dot L\) 表示腿长每秒变化多少。由 \(L=\sqrt{x^2+y^2}\) 对时间求导：

\[
\dot L=\frac{x\dot x+y\dot y}{L}
\]

向量 \((x,y)\) 指向腿，速度 \((\dot x,\dot y)\) 中沿腿方向的部分会让腿伸缩；点积正好取出这种同方向分量，再除以长度得到 m/s。垂直于腿的运动主要改变腿方向，不直接改变长度。

## 3. 腿方向变化率

若 \(\phi=\operatorname{atan2}(y,x)\)，则：

\[
\dot\phi=\frac{x\dot y-y\dot x}{x^2+y^2}
\]

分子反映 C 的运动有多少是在绕 O 转动；除以 \(L^2\) 得到 rad/s。它是虚拟腿方向变化速度，不是电机轴速度。

## 4. 关节运动怎样进入

两个主动关节角决定闭链形状。模型先由正运动学算出 C 的位置；如果关节速度也已知，当前姿态下的几何雅可比可给出：

\[
\begin{bmatrix}\dot x_C\\\dot y_C\end{bmatrix}=J_C(q)\dot q
\]

\(J_C\) 的一列表示对应关节以单位角速度转动时，C 会朝哪个方向、以多大速度移动。然后再把 C 的速度换成 \(\dot L,\dot\phi\)。

实机不需要为了求雅可比而试转电机。可以由闭链约束求导，或由运动学软件在当前姿态计算。第十课的 calJacobian.m 体现了推导方向，但文件有未定义符号，应作为讲义草稿阅读，不能宣称它已是可运行实现。

## 5. 单位与数值问题

如果 x 用毫米、速度用毫米/秒，算出的腿长速度也是毫米/秒；接入米制模型前需除以 1000。角度差分应处理从 \(+\pi\) 到 \(-\pi\) 的环绕。L 接近零时分母使计算不稳定；连杆共线附近几何雅可比也可能病态。有限差分估速时，小时间间隔会放大传感器噪声。

## 6. 对照新指定的 Gaint 第十一课：O、B、y 和虚拟腿长

前面用 O、C 作一般记号；在当前五连杆课里，腿端/轮轴点记作 B，上方两个固定电机轴是 O、D，几何计算在机身安装架坐标系进行。代码先由主动角求 B=`(x,y)`，随后：

- `B.y` 被用于 `nowRighty/nowLefty`，是这份控制器的高度反馈坐标；图示 y 向下，属于机身局部几何坐标，不是直接相对房间地面的高度。
- `radius=sqrt((B.x-L5/2)^2+B.y^2)` 是从固定轴中点 `(L5/2,0)` 到 B 的虚拟腿长。
- `polarAngle=atan2(B.y,B.x-L5/2)` 是这条虚拟腿在该局部坐标里的方向角。

因此“腿高”“虚拟腿长”“几何方向角”是相关但不同的量。完整主动角→A/C→两圆交点 B→高度/长度算例见[新源码视频完整讲解](../05_中英文面试/05_历次问题归纳与新源码视频完整讲解.md)第二节。

## 历次疑惑归纳：从腿端坐标到腿长速度和角速度

几何符号、雅可比数值和完整例子见 [P7 历次问题归纳](../05_中英文面试/05_历次问题归纳与新源码视频完整讲解.md)。

- **虚拟腿是 O 到轮轴/腿端 C 的连线。**若 r=(rₓ,rᵧ)，则 L=√(rₓ²+rᵧ²)，方向角由选定坐标轴下的 atan2 得到；它是控制用几何量，不是新增实体连杆。
- **腿长变化率是速度沿腿方向的投影。**L̇=(rₓ ṙₓ+rᵧ ṙᵧ)/L；它只取向外/向内的分量。
- **腿角速度是垂直于腿的切向运动除以 L²。**ϕ̇=(rₓ ṙᵧ−rᵧ ṙₓ)/L²，正负取决于坐标轴和角度正向。
- **关节速度到腿端速度的 J_C 随姿态变化。**它是 x_C、y_C 对主动关节角的偏导组成的矩阵；约束方程/解析导数直接算，不需要让实机试转。
