# 七项目系统学习与英文面试

适合有编程基础、正在从头补数学/物理/机器人理论的学习者。当前材料按“现实对象→问题→输入输出→公式逐项解释→完整手算→实际源码→错误边界→英文面试”组织，不默认读者已经会推导机器人公式。先看[当前基础与白话学习办法](00_总导航/06_零基础学习说明.md)。教材不能替代实际练习，也不能预知所有面试问题。

## 第一天从这里开始

1. 读[当前基础与白话学习办法](00_总导航/06_零基础学习说明.md)，知道自己先补哪些地基、每章怎样算学会。
2. 读[学习系统总览](00_总导航/00_学习系统总览.md)，区分材料、源码、教学示例和实测证据。
3. 从[单位与三角函数](01_通用基础/01_数学与物理基础/01_单位三角函数与物理量.md)→[向量](01_通用基础/01_数学与物理基础/02_向量点积与叉积.md)→[矩阵](01_通用基础/01_数学与物理基础/03_矩阵乘法转置与维度.md)。每次只学一个概念：看图/直觉、手算，再核对答案。
4. 选一个项目，先读README里的“白话总览”，再读完整数据链并跟一个周期；看不懂一个字母时回对应基础章，不要跳着背结论。
5. 用中文讲通后练英文，再练面试官追问；[面试入口](04_面试训练/00_面试训练总览.md)。

## 一个主题怎样学

现实中发生什么→这一步要解决什么→认清输入和输出→逐个看懂符号→一小步一小步手算→追到源码函数和消息字段→理解故障原因→中文复述→英语回答。没有中间步骤的公式推导视为未完成；读不懂时退到一维或二维例子。

建议项目顺序P1→P7→P2→P3→P5→P4→P6；CS方向可先P6/P4，控制方向先P1/P7。路线按验收推进，不预设每天时长。[项目能力地图](00_总导航/02_七项目能力地图.md)。
