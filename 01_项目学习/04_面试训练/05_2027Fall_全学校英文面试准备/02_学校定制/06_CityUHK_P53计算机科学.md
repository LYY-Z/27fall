# 06｜香港城市大学：MSc Computer Science（P53）

## 官方项目理解

CityUHK 的 2027/28 P53 项目页列出三门核心课：Computer Networks and Internets、Software Engineering、Data Engineering；学生可通过选修发展 AI、Data Science 或 Information Security 方向，也有项目/Guided Study 等选项。官网说明项目目标包括增强软件开发能力并拓展计算机科学领域知识。[P53 官方招生页](https://www.cb.cityu.edu.hk/en/pg/programme/program-list/2027/college-of-computing/department-of-computer-science/p53)

## 45–60 秒：Why CityUHK P53?

> I am applying to CityUHK’s MSc in Computer Science, P53, because reliable robotics depends on strong software foundations as much as on control algorithms. At Kaihong, I have worked on capability abstraction, command mapping, state synchronization and task dispatch for an OpenHarmony robot platform. My smart-gardening project also showed me how software engineering, data quality and safety rules affect a vision-driven physical system. The programme’s core courses in Software Engineering, Data Engineering and Computer Networks and Internets match concrete problems I have encountered. I hope to use the AI-related electives and project options to apply these foundations to robotics software and mobile-robot systems.

## CityUHK vs CityUHK(Dongguan)：不要混为一谈

CityUHK P53 是香港城市大学本部的 CS 项目；CityUHK(Dongguan) 的 MSc CS 是另一申请项目和招生系统。面试中要说出申请信上的正确校区与课程，不用“CityU”一个简称糊过去。

## 可能追问与英文答法

### Why not apply only to a robotics programme?

> My career goal is robotics, but my experience has shown that platform software and data handling are major sources of robot failures. P53 gives me a broader computer-science foundation that can transfer across different robot types. I want to combine that training with my existing control and navigation experience.

### How would Software Engineering help your work?

> It can help me make interfaces, state handling and failure behaviour more systematic. For a robot platform, software quality is not just code style. It includes clear contracts, error handling, testability, maintainability and safe behaviour when a component is delayed or unavailable.

### Which AI courses would you consider?

> I am interested in Machine Learning: Principles and Practice and the AI-related electives, because I have deployed computer vision but want a stronger understanding of model training and evaluation. I would confirm the courses offered in my intake and plan my choices around the programme requirements.

### What would your project be?

> I would be interested in a project on dependable software for mobile robots, such as evaluating how state freshness and frame validation affect navigation performance. I would first agree on a narrow research question, build a reproducible test setup and measure both task performance and failure cases.

### How do you handle multiple possible electives?

> I would build a coherent plan rather than selecting courses only because their titles sound interesting. My first priority would be software and data foundations, followed by a machine-learning or computer-vision option that connects to robotics. I would verify prerequisites and actual course offerings before finalizing the plan.

## CityUHK P53 英语面试条件补充

CS 系官方页写明：IELTS 总分 6.0 或 2026-01-21 后新版 TOEFL iBT 总分 4 的申请者需要通过英语能力面试；TOEFL 79 或以上可豁免该英语面试；其他申请者可能不需要面试。你的材料记录 IELTS 6.5，因此不触发这条低分条件；但不能保证没有其他学术面试。[P53 admissions](https://www.cs.cityu.edu.hk/academic-programmes/msc-computer-science/admissions)。

如受邀参加英语评估，练清晰介绍CV、学习动机和项目。技术面试另练算法/数据结构、系统接口和AI/机器人项目取舍；以个人邀请为准。
