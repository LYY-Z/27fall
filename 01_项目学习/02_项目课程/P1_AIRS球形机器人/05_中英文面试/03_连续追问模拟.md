# P1 连续追问模拟

训练方式：先不看答案口述，再看下面参考。每轮约10分钟，记录哪一步从理解变成背词。

**初学者练法：**第一遍只用中文讲清楚因果，不要求马上说出所有术语；卡住时停下来画对象、箭头和信号单位。第二遍再回答英文追问。先把这一题改说成一个真实动作：谁提供状态，控制器算出什么，电机收到什么。LQR、PID等词必须能指向项目中的具体调用或明确标作教学模型。先用[项目白话总览](../00_项目全貌与学习路线/03_P1端到端闭环、数据时序与实时性.md)把主线复述一遍。

## Round 1

**Interviewer:** What does the position loop output?

**Candidate:** The outer loop generates bounded roll and pitch references. It does not directly send motor current. The sign conventions differ for roll and pitch and must match the body frame.

**Interviewer, deeper:** Why limit the tilt reference?

**回答依据：** 有界roll/pitch参考，不是电机电流；源码roll_d=-YLoop,pitch_d=XLoop。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 2

**Interviewer:** Why include angular-rate feedback?

**Candidate:** Angular-rate feedback tells the controller how quickly the body is rotating and provides damping. Attitude error alone does not describe whether the robot is already moving toward or away from the target.

**Interviewer, deeper:** What happens if the gyro axis is reversed?

**回答依据：** 角速提供运动趋势/阻尼；只有角度可能来回摆。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 3

**Interviewer:** How are wheel commands limited?

**Candidate:** This controller scales the complete wheel-command vector using its Euclidean norm. It preserves the linear allocation direction, but the limit must still be related to each motor's capability.

**Interviewer, deeper:** How does this differ from a maximum-absolute-value limit?

**回答依据：** 源用L2整体范数，不是逐轮clip；方向比例保持。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 4

**Interviewer:** Does this controller directly command wheel torque?

**Candidate:** The variable names include torque-like terms, but this output path sends wheel velocity references. I would trace the actual message fields and driver mode rather than infer the actuator command from a variable name.

**Interviewer, deeper:** Which field reaches the driver?

**回答依据：** 不是，该路径字段v_des；tau变量后经分配缩放。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 5

**Interviewer:** Why does CoM displacement affect balance?

**Candidate:** Gravity acts at the center of mass. A horizontal offset relative to the support reference creates a moment through the cross product of lever arm and gravity force. Feedforward attempts to counter that predictable effect.

**Interviewer, deeper:** Which axis receives a positive compensation term?

**回答依据：** 重力作用质心，支撑点力臂r×mg；水平偏移导致倾倒矩。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 6

**Interviewer:** Was LQR the same controller as the runtime PID?

**Candidate:** The source contains a continuous LQR design for a simplified four-state model. That analytical design must be distinguished from the cascaded PID runtime path described in the material.

**Interviewer, deeper:** What is the input of the four-state model?

**回答依据：** 区分连续模型LQR分析与实机PID候选描述。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 7

**Interviewer:** What happens in the fall branch?

**Candidate:** The inspected branch resets controller state and returns, but does not explicitly publish zero or disable the motors there. The hardware stop behavior must be established through the downstream driver and timeout logic.

**Interviewer, deeper:** Could the driver retain the last command?

**回答依据：** 大倾角reset再return，没有显式零/disable，停机继续查driver。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Evidence challenge

**Interviewer:** Did the available version actually run on the robot?

**Candidate:** The source snapshot and the deployed version must be matched using a commit, configuration and execution record. I would distinguish what I can trace in this snapshot from what I can substantiate with my own project records.

## 复盘答案标准

每问记录：公式/单位是否正确，能否指出函数，个人动作是否明确，验证是否有数据，限制是否诚实，英文是否可理解。不会则明确不知道的部分并解释已知部分。下次优先补一项，不改写成“已掌握”。
