## P5-Q02 为什么车辆不能横移？

## 追问答案补全：P5-Q01–Q25

以下补齐每道正式题后的追问。算法性答案说明的是一般原理；当前仓库活动实现仍以启动配置、插件加载和实际调用链为准。

- **P5-Q01：Which interface carries the tracking command?** 一般ROS导航输出会通过 `geometry_msgs/Twist` 或 `TwistStamped` 一类接口向底盘发送；但此仓库的消息字段是否采用m/s、rad/s，需沿控制器到驱动协议核实。不能只凭话题名 `cmd_vel` 假设单位。
- **P5-Q02：What changes when tire slip becomes significant?** 自行车无侧滑假设失效，轮速/转角预测的位姿会和真实运动分离；需要加入侧偏/轮胎模型或把视觉、IMU、定位反馈用于纠偏，并降低速度、保守规划。仅调大过程噪声不能修复系统性模型错误。
- **P5-Q03：Why does the reference point matter?** 同一刚体不同点的线速度不同，偏航时有 \(v_P=v_O+\omega\times r_{OP}\)。若状态以后轴中心定义、命令/定位以质心定义，运动方程、转弯半径和误差都要做对应换算。
- **P5-Q04：Would a differential-drive conversion be valid here?** 通常不可以。汽车式转向由前轮角形成曲率，低速也不能原地自转；差速模型把左右轮速差当偏航来源，非完整约束不同。只有把底盘改成差速驱动并重做运动学和接口后才适用。
- **P5-Q05：Which sensor could constrain long-term drift?** 视环境可用GNSS、激光SLAM、视觉里程计/标记或外部定位；IMU可改善短时姿态和动态，但单独积分也会漂。传感器需有明确坐标变换和时间同步。
- **P5-Q06：What happens if the initial estimate is very poor?** EKF局部线性化可能落在错误的工作点，创新大、数据关联错或协方差不再代表真实误差；先用全局定位/多假设初始化，再逐渐进入局部滤波，并设创新门限和重定位路径。
- **P5-Q07：Can a position measurement also correct estimated velocity?** 可以，若预测协方差中位置与速度存在非零交叉项，Kalman增益会把位置残差同时映射到速度状态。若模型设成完全独立或交叉项为零，这种修正就不会发生。
- **P5-Q08：When would cross terms also be needed?** 当误差通过运动模型耦合，例如加速度噪声同时影响位置和速度，或坐标/传感器误差相关时，Q或P应有非零非对角项。独立白噪声假设不成立时，不能机械地把Q设为对角阵。
- **P5-Q09：Why can global localization have multiple hypotheses?** 对称走廊、重复房间或相似激光几何会让多个位置都能解释观测；粒子滤波保留多个候选，直到后续运动/观测把错误候选压低。单高斯EKF通常只维护一个局部峰值。
- **P5-Q10：What happens if two nodes publish the same transform?** TF树会出现竞争、时间戳不一致或父子关系冲突，消费者可能收到跳变、重复数据或报错。每条变换应只有清晰的权威发布者，并统一frame命名。
- **P5-Q11：How would you measure sensor-to-controller latency?** 在可同步时钟下记录传感器采样时刻、消息发布/接收时刻、估计完成和控制器使用时刻；区分采样延迟、网络排队和计算耗时。跨时钟域先估计偏差，不能直接相减。
- **P5-Q12：How would you detect overconfidence in residuals?** 记录创新 \(r=z-H\hat x\)、创新协方差 \(S\)，检查归一化创新平方 \(r^TS^{-1}r\) 和残差时间相关性；若残差长期大于协方差预期，说明噪声模型/关联/时序可能失配。
- **P5-Q13：What makes a heuristic admissible?** 对任一节点，启发式估计到目标的剩余代价不能高于真实最小剩余代价；这样 \(f=g+h\) 才不会因启发值过高过早排除最优路。启发式一致性和是否允许重开节点也会影响实现条件。
- **P5-Q14：What is lost when heading bins are too coarse?** 不同朝向被合并，车辆可能把本来不能互相等价的状态当成同一节点；可行窄通道、转弯质量和到达姿势精度下降，搜索也可能错误去重。桶太细则状态量和算时上升。
- **P5-Q15：Why check intermediate points along the primitive?** 一条短弧的起点和终点都空闲，弧线中段仍可能穿过障碍。对整车足迹沿运动基元采样碰撞，采样间距还要与地图分辨率、速度和安全余量相配。
- **P5-Q16：How could clearance margins address uncertainty?** 把障碍物按车身足迹膨胀，再按定位误差、地图误差和动态障碍不确定度加安全余量；或直接在代价/约束中考虑概率净空。余量过大可能让窄路无解，须结合误差分布验证。
- **P5-Q17：How does a path differ from a timed trajectory?** 路径是几何上的点/姿态序列，不规定何时到达或速度；轨迹还带时间、速度/加速度等动态量。跟踪器收到路径后还需时间参数化或在线生成速度。
- **P5-Q18：What should happen if the optimizer misses its deadline?** 丢弃过期解并触发预先定义的安全回退，例如限速停车/保持；是否能沿用上一条解取决于其年龄、障碍和状态变化。记录求解时长、截止期违约和回退原因。
- **P5-Q19：Where would collision constraints enter the optimization?** 对预测时域每个状态/足迹加入与障碍距离约束或安全代价，并处理动态障碍预测。若求解器只优化跟踪误差和控制输入，没有障碍约束，不能声称MPC本身避障。
- **P5-Q20：What changes when an input bound becomes active?** 最优解被限制在边界上，状态误差可能无法在预测时域内消除；需看饱和后的残差、可行性和后续恢复，并避免积分/参考继续要求不可实现动作。活跃约束不是求解错误。
- **P5-Q21：Can holding the previous input always be safe?** 不能。障碍、定位、速度或执行器状态可能已改变，旧转向/加速度可能继续把车推向危险。保持动作只能在经过验证的短时安全包络内使用；否则走独立的安全停车策略。
- **P5-Q22：How would you substantiate the historical CV description?** 找到当时的提交、分支、实验记录、地图/配置、日志或演示视频，并逐一映射到简历中的算法和个人职责。当前快照缺失时说明证据缺口，不用新教学程序补写历史部署。
- **P5-Q23：What failure could a unit mismatch cause?** 把RPM当rad/s、设备百分比当m/s或角度当弧度，会使速度/转向量相差倍数或方向错误，造成过快、过慢、转向过度甚至超出舵机范围。每个接口要写明字段、单位、范围和转换。
- **P5-Q24：How would localization error contaminate a tracking metric?** 若“真值”也来自同一个有偏定位器，计算出的跟踪误差会把估计误差混入控制误差；应使用独立外部真值或报告相对指标、定位不确定度，并让所有数据时间对齐。
- **P5-Q25：Which record would you retrieve first?** 先锁定项目提交/源码版本和启动配置，再找对应的运行日志、地图/参数与实验记录；它们能回答“什么实现被启用、如何运行、测到了什么”。简历句子本身不能替代实现证据。
