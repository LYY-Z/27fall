# 先修知识与学习验收：按课程代码学习 P7

本项目按以下课程源码学习：第五课五连杆运动学、第六课 PID 平衡、第八课 LQR 推导、第九课变腿高部署、第十课 VMC 雅可比草稿、第十一课 VMC 实现。源码位置见[课程代码地图](../02_源码阅读与运行/01_源码版本与文件地图.md)。

这些课程前后衔接，但不是一个已经验证的统一固件。读每一课时都标注“教学模型”“当前代码”“待核对硬件接口”。

## 学习顺序

1. 认结构和单位：腿是五连杆闭链，轮子在地面滚动，机身由两侧机构支撑。第五课长度为毫米；后续代码有些继续用毫米，有些用米。
2. 学几何：给两个主动角，按闭链约束求轮轴/输出点；反过来给目标点，求主动角。
3. 学平衡：第六课用 PID 入门；第八课将轮加倒立摆简化，按视频从能量、拉格朗日方程推到连续 LQR。
4. 学变腿高：第九课将不同腿高对应的反馈系数拟合成二次函数；第十一课按腿高计算轮反馈系数，并独立计算腿部 VMC。
5. 学数据和执行：追踪 IMU、关节、轮速、遥控器如何进入计算，轮子和腿关节的命令如何发出。

## 进入公式前的基础

- 角度：度和弧度不同，三角函数输入单位必须确认。
- 向量：二维位置由 x、y 两个分量组成；距离由平方和开根号求。
- 圆交点：闭链关节点同时受两根定长连杆约束。
- 速度：位置对时间的变化率；加速度是速度对时间的变化率。
- 力和力矩：力导致平移，力臂使力产生转动效果。
- 反馈：比较目标和当前测量，按误差产生下一条命令。
- 模型：公式是对真实机构的近似；单位、假设和可用范围必须清楚。

## 学完一节的验收

每个公式都能回答四件事：它描述哪个真实部件？输入来自哪里、单位是什么？输出是什么、谁使用？什么情况下会失效，例如目标几何不可达、连杆共线、轮子打滑或电机饱和？

## 必须分开的三种控制量

- 第八课 LQR 模型中的输入是简化模型的一个驱动力矩。
- 后续轮控制函数输出轮电机目标，底层单位由电机库接口决定。
- VMC 根据腿端虚拟力和几何关系计算腿关节力矩。

它们作用对象不同，不能因为都叫控制量就当成同一种力矩或速度。

源码只能证明仓库里存在什么，不能自动证明个人做过设计、调参或实机验证。个人贡献要由本人记录支持；教学推导和新增实验应标为学习或复现。

## 复习工具：闭链几何、虚拟腿、轮平衡分层理解

按课程源码和视频的教学顺序，把每个量放回真实机构：

```text
两个主动关节角 α、β + 五连杆尺寸
       → 闭链几何求轮轴/腿端 B(x,y)
       → 对关节角求导得到 Jacobian：Ḃ = J q̇
       → 由 O→B 得虚拟腿长与方向及其速度
       → 腿端期望位置/速度经弹簧-阻尼生成虚拟力
       → 虚功关系 τ_joint = Jᵀ F_end 得关节力矩

轮速/IMU/腿状态 → 简化倒立摆状态 → LQR轮侧控制量
腿高变化 → 对应反馈系数/增益调度
```

两条控制支路要分开：轮侧平衡控制（课程LQR/腿长增益调度）和腿部虚拟弹簧阻尼（VMC）。它们最终共同作用于机器人，但状态、输出、执行器和计算路径不同。

### P7 易混概念对照

| 容易混在一起 | 应该怎样区分 |
|---|---|
| (B(x,y)) 与虚拟腿 | B是由五连杆几何得到的轮轴/端点位置；虚拟腿是从机身参考点O连到B的等效长度和方向，不是新增的实体杆。 |
| 几何正解与Jacobian | 正解从关节角求位置；Jacobian从关节小速度求端点速度。每列是“单个主动关节转速对B速度的局部影响”。 |
| (J) 与 (J^T) | (Ḃ=Jq̇) 把关节速度映射到端点速度；(	au=J^TF) 把端点力映射到关节力矩，来自虚功相等。 |
| VMC虚拟力与实测地面力 | 弹簧/阻尼先算控制器希望虚拟腿产生的力；经雅可比转成电机力矩。它不是直接传感到的地面力。 |
| LQR状态反馈与“直接输出最终轮速” | LQR输入取决于建模定义；课程推导中反馈矩阵作用于六状态，生成模型控制输入（常写轮侧控制量/力矩相关量）。还需经过代码规定的执行映射，不能仅凭K就称最终电机转速。 |
| 腿高调度与重新设计LQR | 用腿长选取/拟合一组反馈系数，是增益随工作点变化；不等于每周期在线重解Riccati。 |
| 几何单位 | 课程不同课次可能混用mm和m；三角函数角度通常要求rad。把长度单位统一后再将力、速度或力矩代入。 |

### 自测题与检查要点

1. 给定 α、β，怎样求B？检查点：先求固定基座点A/C，再用两根定长杆的圆交/闭链约束求交点，选择符合机构装配的分支。
2. Jacobian每一列表示什么？检查点：固定当前姿态，只看一个主动关节角变化率，求B的x/y速度对它的偏导；形状2×2，单位m/rad。
3. 为什么接近两杆共线时Jacobian可能不稳定？检查点：几何约束的方程组趋于相关/分母趋近0，某些端点运动方向需要很大的关节速度。
4. VMC的期望腿端位置/速度如何变成关节力矩？检查点：位置误差经弹簧项、速度误差经阻尼项得到虚拟力；用当前Jacobian转成关节力矩；检查正负方向和单位。
5. LQR输出如何与VMC配合？检查点：先说清两个控制器各自的输入状态、产生的控制量和作用对象，再追代码里的左右分配与电机接口；不要把两个输出直接当同一单位。
6. 如何从两关节角求左右腿高度？检查点：分别按左右侧各自的机构坐标和关节角求轮轴/腿端坐标，再投影到明确的竖直轴；左右镜像导致符号/角度定义可能不同。
7. 什么时候教学公式不能直接用于硬件？检查点：单位不一致、结构参数不准、装配分支错、Jacobian奇异、执行器饱和、传感器延迟或接口量纲未校准。

### 复习阶梯

先画出基座O、固定铰点A/C/D、活动点B、关节角正方向和全局x/y；然后手算一次端点坐标与Jacobian单列，再手算一个 (J^TF)。最后追课程代码的数值单位、输出接口和活动课次。当天闭卷讲五连杆到电机力矩，次日对左右腿各算一个高度，一周后对比LQR与VMC的对象和单位。
