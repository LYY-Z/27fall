## P3-Q04 AHRS是什么？

**Question:** What does an AHRS provide?

**中文理解与答法：** BMI088 经 SPI+DMA 给的是加速度计/陀螺仪寄存器字节，不是四元数。驱动换算和轴校正后，AHRS 用陀螺积分、加速度重力方向校正来更新四元数，再转为 yaw/pitch/roll。六轴惯性信息不能仅靠重力确定绝对 yaw；没有有效磁力计时航向可能漂移。

**English reference:** An AHRS estimates orientation from inertial measurements. It remains affected by gyro bias and motion-induced acceleration. Gravity alone does not observe absolute yaw.

**中文理解与答法：** 通用系统可把低速、高电流和持续时间组合判断；但此源码的 `Trigger_Finish_Judge` 主要比较拨盘目标累计编码与当前累计编码的差，并结合约 1000 ms 的动作时间。误差大于 5000 counts 且单发超时会转入 BLOCK，再将目标改为约反向 120° 的位置进入 BLOCK_BACK；再次失败进入 FAIL。它不是“电流大就堵转”。还要注意 FAIL 分支是否清零电流，不能仅凭状态名断言已经安全停机。

## P3-Q36 源码中的功率二次式从哪里来？

**Question:** Why does the source form a quadratic power prediction?

- **P3-Q01：Which subsystem did you own personally?** 只讲能由提交、实验记录、任务分工或可复现产物支持的具体子模块。可以说“我分析/复现了某控制链”，但不要把仓库里整个机器人系统都说成个人独立开发。
- **P3-Q02：What happens if the outer loop is too aggressive?** 角度环会给出过大的角速度目标，内层速度环反复追赶，可能产生超调、振荡、输出饱和和积分累积。应先检查环路带宽、限幅与周期，再分层调参。
- **P3-Q03：How would you verify the gyro sign?** 固定云台并在安全状态下沿已知正方向缓慢转动，记录原始陀螺轴值、源码映射后的反馈、误差和电机输出方向；确认映射、安装方向和电机正方向后再闭环测试。
- **P3-Q04：How would yaw drift affect aiming?** 若目标使用世界/绝对航向，陀螺偏置积分会使估计角逐渐漂移，瞄准方向也随之偏。要区分短时陀螺稳定性与长期绝对航向；磁力计/视觉等校正源及其有效性要有实现证据。
- **P3-Q05：Would this work for a joint with a mechanical stop?** 角度跨越 ±180° 的最短差算法适合连续旋转轴；对有机械限位的关节，必须同时检查允许范围，不能为了取最短角度跨过限位。关节类型和限位应进入控制约束。
- **P3-Q06：Where would you inspect that sign in the source?** 逐段查 IMU 轴到控制变量的映射、目标减反馈的误差定义、PID输出、轴向/电机符号、CAN命令打包，必要时追到驱动器定义。一个负号无法单独解释完整方向。
- **P3-Q07：What should happen when visual data becomes stale?** 先按消息时间戳与允许年龄判定过期；随后停止用旧目标持续修正，依策略切换到遥控、保持或安全降级，并记录原因。当前源码是否有 watchdog 和具体 fallback 必须核对，不能因“视觉目标缓存”就断言会自动停。
- **P3-Q08：How would you separate noise from real vibration?** 同步记录未滤波与滤波后的陀螺/编码器、姿态、命令和采样时间；对比频谱/幅值、与电机命令的相干性，并在固定支架与实际运动条件下分别测试。只看滤波曲线变平不能判定振动消失。
- **P3-Q09：Which measurements would establish shooting consistency?** 在固定弹速设定、弹丸/供电和环境下记录每发摩擦轮速度、拨盘进度、发射间隔、卡弹率及弹着散布；报告样本数、均值和离散度，并区分仿真、台架和实战数据。
- **P3-Q10：Could a different deployed version use PID?** 可以，版本或分支可能改变控制器。回答当前实现时要锁定提交/配置和活动调用；不能把另一个历史版本的 PID 参数套到当前调用，也不能把初始化了 PID 对象当作实际使用证据。
- **P3-Q11：What determines the sliding surface?** 先定义误差方向和量纲，再定滑模面，例如 \(s=\dot e+c e\)。系数 \(c\) 决定位置误差与速度误差在滑面上的比例，需结合对象动态、单位和闭环速度选择；若源码另有状态定义，应按源码重写，不能只背标准式。
- **P3-Q12：How would you choose the boundary-layer width?** 边界层越窄，趋近项越像符号函数，跟踪更硬但更易抖振；越宽则切换更平滑但稳态误差可能增加。用噪声水平、执行器分辨率和误差统计选取，并同时看抖振和误差，不凭感觉调到最小。
- **P3-Q13：What would make the comparison misleading?** 不同硬件/负载/电压/初始转速、不同采样周期、限幅或滤波、不同指标/数据段，都会造成不公平。对照实验应锁定版本、设定与数据记录，并报告多次运行分布。
- **P3-Q14：How would you distinguish a completed shot from a jam?** 用拨盘编码器的角度/进度和状态机时间窗判断是否完成一次预期步进，结合电机速度/电流和发射传感信号做交叉核验。只看电机电流高或命令发出不能说明弹丸已经射出。
- **P3-Q15：How could a normal start transient create a false alarm?** 电机从静止升速时，速度暂时低于目标且电流较大，看起来像堵转。应使用启动宽限期、连续满足条件的计时/计数、速度进度条件和状态上下文；具体门槛须从实现与测试确定。
- **P3-Q16：How would you verify pure lateral motion?** 低速、安全架或空旷场地给定 \(v_y\) 且 \(v_x=\omega_z=0\)，同步测四轮目标/反馈和外部位移；检查车体横移、前进和偏航分量。先确认坐标轴、轮序和正负定义。
- **P3-Q17：What symptom would a wheel-order mismatch cause?** 期望直行可能斜行或旋转，横移也可能混入前进；正运动学回算与外部测量方向不一致。查每行矩阵对应的物理轮、CAN ID、反馈轮序和符号，不要只改一个“看着不对”的负号。
- **P3-Q18：Does uniform scaling preserve the absolute speed?** 不保留绝对幅值：若四轮向量整体乘 \(k<1\)，方向比例不变而所有目标幅值降低。这样避免独立截断改变合成运动方向，但执行速度会减小。
- **P3-Q19：How would you integrate measured power into energy?** 按同步采样求 \(E\approx\sum_k P_k\Delta t_k\)，功率单位W、时间秒，结果J；区分正负功率、充电/回馈和测量偏置，并对照裁判/电容定义。单点功率不能直接当能量。
- **P3-Q20：How would you validate the model coefficients?** 用独立的电流、RPM、电压和功率测量拟合或检验系数，在未参与拟合的数据上看残差和边界覆盖；覆盖不同速度、负载和温度。若模型只是在一段工况吻合，不应泛化为全工况保证。
- **P3-Q21：What would you change to enforce a strict bound?** 把实测或保守上界和真实执行限制纳入约束优化/限幅器，明确不可行时的安全降级；不要在求根后向放宽方向把比例重新推过边界。再用功率仪同步验证，软件估算本身不是硬件保证。
- **P3-Q22：How would you measure scheduling jitter?** 每次周期任务记录计划唤醒、实际开始、计算结束和发送时间，统计周期均值、最大值、分位数、deadline miss及任务执行时间；同时记录中断和高优先级任务负载。`osDelay`参数或优先级不是实测周期。
- **P3-Q23：Can a valid frame still contain unusably old data?** 可以。数据格式有效只表示消息可解析，不表示采样新鲜；用可信采样时间/单调时钟计算年龄，并检查传输队列、传感器缓存和回调延迟。
- **P3-Q24：What must be checked before re-enabling?** 确认故障原因已消除、反馈有效且新鲜、姿态/转速处于允许范围、输出与积分状态复位、模式和通信恢复，并要求明确的重新使能动作。哪些条件已在源中实现要逐条指出。
- **P3-Q25：Can you show one function or record supporting your claim?** 给出文件/函数/配置或提交，再说明输入、输出、调用者和下游消费者；若只读了源码，要准确说是“源码中可见”，不要声称自己历史上实现或测得性能。
- **P3-Q26：What does `vTaskDelayUntil` improve?** 它按上次的绝对唤醒节拍推进目标唤醒时刻，避免每轮“计算耗时再加完整相对延时”造成累计漂移；超时执行、抢占和中断仍会产生抖动，不能保证准时。
- **P3-Q27：How would you prove the task met its deadline?** 先给出deadline定义，再记录实际开始/结束和计划释放时间，计算执行时间、响应时间、最大抖动和超期次数；覆盖最坏通信/中断负载与长时间运行，单看平均频率不够。
- **P3-Q28：What limits yaw estimate without valid magnetometer data?** 陀螺仪偏置和噪声随积分积累，重力加速度可约束roll/pitch但通常不能提供绝对yaw；若没有有效磁航向/外部参考，长期偏航会漂移。
- **P3-Q29：Do you need to derive every Euler-angle formula in an interview?** 不必逐行推导，但要说清四元数来源于融合估计、欧拉角是表示转换、轴/顺序/弧度约定，以及角度绕回和pitch接近奇异时的限制；若被追问，再解释公式来源。
- **P3-Q30：What numerical edge cases are visible in the implementation?** 检查四元数归一化、`asin`输入浮点越界、接近欧拉角奇异、角度±π绕回、无效/NaN传感器值、时间步过大及除数接近零等。只把实际在所选版本观察到的情况说成源码事实，其余列为检查项。
- **P3-Q31：What would you log to investigate the implementation?** 记录原始加速度/陀螺、融合四元数、换算角度、滤波角速度、目标与误差、PID/SMC中间量、输出限幅、任务时间戳、CAN发送与反馈年龄，并给相同采样序号便于对齐。
- **P3-Q32：How many reverse retries are implemented?** 从状态变量和计数器的递增、比较条件、复位位置及 `switch` 转移逐条数；不能根据“有退弹状态”推断尝试次数。报告具体版本里的上限和超限去向。
- **P3-Q33：What else must you inspect before claiming safe shutdown?** 追到状态分支是否写零/relax、命令是否实际发送、驱动队列是否保留旧命令、设备/固件watchdog、掉线行为及恢复锁存。状态名 `FAIL` 不等于执行器已经断电。
- **P3-Q34：What does an RPM value of 2,000 mean here?** 它表示被测轴每分钟转2000圈；换算为 \(2000\times2\pi/60\approx209.44\) rad/s，前提是该字段确为此轴RPM。轮轴/电机轴要再按轮半径和减速比换算，协议单位也要核对。
- **P3-Q35：Why use a common scale instead of clipping each wheel separately?** 共同比例缩放保留四轮目标的相对比例，因此尽量保留原本的车体运动方向；逐轮截断会改变轮速向量方向，进而改变合成平移/旋转。两者都限制幅值，但后者不是同一运动。
- **P3-Q36：Does solving for a root guarantee a hard power bound here?** 不保证。根的选择、模型误差、积分项、低缓冲分支、后续向1放松和驱动执行都可能让实测功率越界；需检查完整代码并用同步功率数据验证。
- **P3-Q37：Which two buffer-related values are involved?** 当前记录区分电容侧的 `esr_v`/传入 `buffer_limit` 与裁判侧的 `buffer_energy`；一个是电压相关输入，一个是能量字段，名字相似也不是同一量。须从调用参数和单位逐项追。
- **P3-Q38：What should be logged to judge the effect?** 记录根比例、`k_param`、最终 `k_c`、缩放前后轮目标、测得RPM、电机电流、预测功率、同步实测功率、缓冲能量和分支标志。
- **P3-Q39：How would you determine whether this affects the running controller?** 搜索 `sum_err` 全部读写，沿活动调用路径看其是否参与当前输出/功率多项式，再在受控仿真或台架中做有/无该项对照。代码中的可疑赋值不等于已证明造成运行故障。
