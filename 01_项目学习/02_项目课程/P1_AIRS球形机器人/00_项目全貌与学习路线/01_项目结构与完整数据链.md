# 项目结构与完整数据链

|模块|输入→输出|现存入口|
|---|---|---|
|状态反馈|IMU/三轮→滤波缓存|imuCallback、jointCallback|
|局部运动|轮角速→球角速→水平速度/积分位置|controlLoop+fk|
|位置控制|目标/当前位置速度→roll/pitch参考|XLoop/YLoop|
|姿态控制|角与角速→虚拟轴控制量|RollLoop/PitchLoop/YawLoop|
|手臂补偿|双臂角→URDF系统CoM→重力前馈|CompensationNode、comPosCallback|
|执行分配|轴控制量→三轮v_des→驱动|ik、limitVector、setVelocityCommand|

正常闭环详见[完整周期](../02_源码阅读与运行/02_一个周期的调用与数据流.md)。脚本linear_model是模型/参数生成入口，会写配置，不是此实机周期在线优化。双臂episodes提供固定动作，不据此声称复杂自主双臂规划。

当前源快照能支持实现阅读，不能单独证明个人所有贡献、已部署版本及性能。材料版本与文件SHA在证据表对应。

## 从模块表走到整机运行

上表按“模块”拆开看。若要理解它们怎样在一个真实时间轴上协作，先读[端到端闭环、数据时序与实时性](03_P1端到端闭环、数据时序与实时性.md)：它把 IMU、轮反馈、cmd_vel、双臂 CoM、PID、LQR分析和驱动器连成一条链，并区分配置频率与实测周期。

随后读[一个控制周期](../02_源码阅读与运行/02_一个周期的调用与数据流.md)跟源代码。简记为：

**收到不同步的传感器/目标消息 → 更新各自缓存 → 100 Hz 配置的控制定时器读取最近数据 → 状态计算与位置积分 → 外环倾角参考 → 内环姿态控制与 CoM 前馈 → 三轮分配/限幅/输出滤波 → ROS/CAN → 新反馈。**

LQR 另有一条离线分析链：物理参数 → 四状态线性模型 → Q/R 权重 → 连续 LQR 求候选增益。当前检查的 C++ 控制周期实际调用级联 PID；不要把离线分析画成电机每一帧运行的 LQR。

## 第一次学习怎么读？

先读[端到端闭环、数据时序与实时性](03_P1端到端闭环、数据时序与实时性.md)建立整体印象，再用[一个周期的小白详解](../02_源码阅读与运行/02_一个周期的调用与数据流.md)第0—4节区分目标、测量、估计和命令；第5—10节跟着轮速、坐标、PID与前馈计算；第11节把完整数字链算一遍；最后再读驱动、异常和英文回答。该教程补充了滤波更新时钟、位置旋转不含平移、Yaw目标速度未传入D项以及Pose2D字段实际语义。读完再回各子系统细节，不要求先把全部理论看完。
