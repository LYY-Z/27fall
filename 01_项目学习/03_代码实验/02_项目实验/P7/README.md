# P7 离线教学实验

## 实验定位

这里的 Python 程序是为了帮助理解课程中的几何、LQR 和虚功关系而单独写的离线教学例子。它们不是仓库原始固件，也不连接电机或传感器。本次只更新代码和说明，没有运行程序或验证输出。

所有几何实验统一使用第五课尺寸：L1=150 mm、L2=L3=250 mm、L4=150 mm、L5=108 mm。Python 中先换成米。所有关节角用弧度。

## 三个程序分别做什么

1. five_bar.py：给两个主动关节角，按圆交点求闭链点，展示两种分支；再求虚拟腿长度、方向和中心差分雅可比。
2. lqr_balance.py：根据第八课的倒立摆耦合方程构造四状态、单输入连续模型，用 SciPy 解连续 Riccati 方程，生成一段小角度线性模型轨迹。它同时把方程消元得到的 B 与 MATLAB 文件当前 B 写法导出对照。
3. vmc_virtual_work.py：把五连杆关节速度映射为虚拟腿长/角速度，再用虚功检查 \(J^\mathsf TF\) 的力矩映射。

第十课的 MATLAB 雅可比文件是推导草稿；这里的雅可比采用本教学程序的几何差分，不宣称复现了第十课脚本的可执行实现。轮目标电机单位、完整硬件模型、通信和安全状态机均不在这些教学程序范围内。

## 环境

Python 3.10 或更新版本、NumPy；lqr_balance.py 另需 SciPy。环境安装方式见[通用实验环境说明](../../00_环境与运行/README.md)。本目录代码没有执行记录，不要把输出预期说成实际结果。

## 建议顺序

先画五杆和圆交点，再核对 FK/IK 概念；然后读第八课视频对应的物理模型和状态空间；最后理解虚拟腿速度和力矩映射。每次把输入、输出、单位、坐标系和假设写在同一页。

## LQR 实验中的方程与代码差异

第八课的两条耦合运动方程直接消元，得到 \(B_{4}=(I+mh^2)/(Dr)\)。课程 MATLAB 文件 B 的最后一项写成另一种表达。lqr_balance.py 为学习比较同时保存两种数值，不会隐去差异。若之后确认视频或课程版本的约定，应先更新推导依据，再讨论仿真采用哪一个模型。
