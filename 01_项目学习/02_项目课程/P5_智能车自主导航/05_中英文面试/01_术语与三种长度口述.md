# P5 术语与三种长度口述

## 使用边界

这是可练习的参考答案，不替用户确认个人职责。只有本人确实完成的动作才能用I implemented/I designed。现存团队/平台代码用the implementation；新教学用a separate learning experiment。结果数值需日志，没有则解释验证方法。

## 常用术语：先用中文讲动作，再说英文词

|中文|英文|先在脑中想成什么|
|---|---|---|
|车辆运动学|vehicle kinematics|车速、前轮转角和车头方向怎样一起决定车辆路径|
|后轴中心|rear-axle center|模型中用来代表汽车位置的后轮轴中点|
|定位|localization|传感器根据运动和环境信息估计车辆在地图上的位置|
|运动基元|motion primitive|车辆短时间能做的一种基本动作，例如小幅转弯前进|
|碰撞检测|collision checking|检查整辆车的外形扫过路线时会不会碰障碍|
|滚动时域|receding horizon|预测一段未来，只执行第一个动作，然后再看新状态重新计划|
|坐标变换树|transform tree|保存地图、里程计、车身和传感器坐标之间的关系|
|跟踪误差|tracking error|车辆当前状态与规划给出的参考状态相差多少|

把英文答案建立在一趟具体行程上：车在哪里→计划怎么走→当前应怎样转→命令是否真正到达车轮。P5白话总览见[这里](../00_项目全貌与学习路线/03_P5导航一趟路是怎样走出来的.md)。

公式读法与澄清句见[技术英语](../../../04_面试训练/01_技术英语/01_术语单位公式与矩阵读法.md)。

## 30秒：先让面试官听懂问题

This project concerns autonomous navigation for a car-like robot. The main learning chain is state estimation, coordinate alignment, feasible path planning, local trajectory generation and constrained tracking.

中文主线：系统是什么→要解决什么→关键方法。实际速度因人而异，30秒是训练目标，需自己计时。

## 90秒：加入方法和实现边界

This project concerns autonomous navigation for a car-like robot. The main learning chain is state estimation, coordinate alignment, feasible path planning, local trajectory generation and constrained tracking.

A car-like vehicle cannot move sideways directly. Its steering and speed must be included in planning and tracking. EKF provides a model-based state estimate, while AMCL can use a known map and range observations to constrain localization.

Before claiming deployment, I would match the original launch, parameters, commit and logs. Device-scaled commands in the current source must not be described as standard SI velocity without conversion.

中文主线：问题→数据链→方法理由→一个实现点→证据边界。讲到复杂术语后留一句直觉解释，不一次报完技术栈。

## 3分钟：模型、实现、验证与反思

This project concerns autonomous navigation for a car-like robot. The main learning chain is state estimation, coordinate alignment, feasible path planning, local trajectory generation and constrained tracking.

A car-like vehicle cannot move sideways directly. Its steering and speed must be included in planning and tracking. EKF provides a model-based state estimate, while AMCL can use a known map and range observations to constrain localization.

The available launch files select Navfn and regulated pure pursuit. They also contain an L1-controller path and older TEB configuration. I have not located the historical Hybrid A-star or MPC implementation in this source snapshot, so I keep those material claims separate from current source evidence.

I would measure position and heading error, minimum clearance, replanning latency, constraint violations and stopping behavior. The teaching vehicle examples make the algorithms concrete but are not records of the historical competition system.

Before claiming deployment, I would match the original launch, parameters, commit and logs. Device-scaled commands in the current source must not be described as standard SI velocity without conversion.

中文主线：模型输入输出/假设→一个实际函数链→一个已能解释的限制→怎样量化→个人贡献。不要将教材里的“会做”变成历史“做过”。

## 在口述中插入自己的贡献

确认职责后用：“My responsibility was [specific module]. I chose [method] because [reason]. I checked it using [actual data and metric]. The main limitation was [observed limitation].”

方括号必须用本人事实替换。没有记录则说：“I can explain the design, but I do not have a verified measurement for that performance claim.”
