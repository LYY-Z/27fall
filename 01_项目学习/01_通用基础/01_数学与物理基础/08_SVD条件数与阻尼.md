# 08 SVD、条件数与阻尼

> 先修：[矩阵](03_矩阵乘法转置与维度.md)、[伪逆](07_范数最小二乘与伪逆.md)。项目：P2、P7；实验：[矩阵方程与伪逆](../../03_代码实验/01_基础实验/01_矩阵方程与伪逆/README.md)。
> 学习目标：手算一个秩1矩阵的SVD，解释小奇异值为何放大误差。下章：[特征值与二次型](09_特征值二次型与稳定性.md)。

## 1. 本章要解决的问题

本章不把 SVD 当成一条需要死记的公式，而是回答同一条主线中的几个问题：

```text
矩阵 A 到底对输入做了什么？
怎样找到 A 最重要、最薄弱的方向？
为什么要出现 AᵀA、U、Σ、Vᵀ？
怎样尽可能把 A 的作用反过来？
反解为什么会放大传感器噪声？
```

本章最后应能用自己的话说清楚：

```text
SVD 是一种矩阵分解方法；
vᵢ 是输入空间中的特殊方向；
uᵢ 是对应的输出方向；
σᵢ 是该方向的缩放倍数；
伪逆是尽可能反向恢复；
小奇异值会导致反解放大噪声。
```

### 先纠正旧笔记中的几个词

U、V 是**正交矩阵**，不是正定矩阵。正交表示列向量互相垂直且各自长度为1，所以 VᵀV=I。正定表示 xᵀAx>0，是另一个概念。Vᵀx 才给出输入向量在 v₁、v₂ 等方向上的坐标；不能把 v₁x 当作未定义的普通矩阵乘法。AᵀA 的特征值是 σᵢ²，奇异值是这些非负数的平方根。

---

## 2. 先把矩阵看成一台机器

矩阵接收一个输入向量，输出一个向量：

```text
输入 x → 矩阵 A → 输出 y
```

写成公式：

```text
y = Ax
```

例如：

```text
A = [[1,1],
     [0,0]]
```

它的作用是：

```text
[x₁,x₂] → [x₁+x₂, 0]
```

因此：

```text
[3,1] → [4,0]
[2,2] → [4,0]
[5,-1] → [4,0]
```

这个矩阵把二维输入压到了一个方向上，因此有一个输入方向的信息被丢失。

SVD 的目标就是把这种复杂作用拆清楚：

```text
哪些输入方向有效？
哪些输入方向被压缩？
每个方向被放大或缩小多少？
输出分别指向哪里？
```

---

## 3. SVD 的核心结果

任意实矩阵都可以分解为：

```text
A = UΣVᵀ
```

这不是一条把 `A` 直接代入就能算出答案的普通公式，而是一个分解结果的形式。

它表示原矩阵的作用可以等价地看成三步：

```text
原输入 x
  ↓ Vᵀ
换成特殊输入方向下的坐标
  ↓ Σ
在每个特殊方向上分别缩放
  ↓ U
换成输出空间中的实际方向
  ↓
得到 Ax
```

因此：

```text
Ax = UΣVᵀx
```

这里的“旋转”更准确地说是“改变坐标方向”。它不一定表示机器人真的先旋转、再缩放、再旋转，而是把同一个线性变换用一套更合适的坐标来表达。

---

## 4. 输入方向和输出方向不是一回事

SVD 中最容易混淆的是 `vᵢ` 和 `uᵢ`：

```text
vᵢ：输入空间中的方向·
uᵢ：输出空间中的方向
```

它们通过下面的关系连接：

```text
Avᵢ = σᵢuᵢ
```

逐项解释：

```text
vᵢ：输入一个特殊方向
A vᵢ：矩阵真正产生的输出向量
σᵢ：这个输出向量的长度
uᵢ：把输出向量单位化后得到的方向
```

当 `vᵢ` 是单位向量且 `σᵢ>0` 时：

```text
uᵢ = Avᵢ/σᵢ
```

这不是新规定，而是把 `Avᵢ` 的长度去掉，只保留方向。

如果：

```text
Avᵢ = [0,0]
```

那么这个方向的信息已经完全丢失，不能用 `Avᵢ/σᵢ` 计算输出方向，因为这会变成 `0/0`。此时对应的 `uᵢ` 只是为了补齐正交坐标系而选取，不是矩阵真正产生的方向。

## 5. 点积与方向分量

### 5.1 点积怎么算

两个二维向量：

```text
a = [a₁,a₂]ᵀ
b = [b₁,b₂]ᵀ
```

点积定义为：

```text
aᵀb = a₁b₁ + a₂b₂
```

也就是：

```text
对应位置相乘，再相加
```

例如：

```text
a = [2,3]ᵀ
b = [4,5]ᵀ
```

则：

```text
aᵀb = 2×4 + 3×5 = 23
```

`aᵀ` 是行向量，`b` 是列向量，所以结果是一个数。

### 5.2 点积为什么能得到方向分量

点积的几何意义是：

```text
aᵀb = ||a|| ||b|| cosθ
```

如果 `a` 是单位向量：

```text
||a||=1
```

就有：

```text
aᵀb = ||b||cosθ
```

右边正是 `b` 在 `a` 方向上的有符号投影长度。

所以，对于单位方向 `v₁`：

```text
v₁ᵀx
```

就是 `x` 在 `v₁` 方向上的分量。

例如：

```text
v₁ = [1/√2, 1/√2]ᵀ
x  = [3,1]ᵀ
```

则：

```text
v₁ᵀx
= [1/√2,1/√2][3,1]ᵀ
= 3/√2 + 1/√2
= 2√2
```

如果方向向量不是单位向量，则投影系数要写成：

```text
(vᵀx)/(vᵀv)
```

SVD 把方向向量单位化，因此可以直接使用 `vᵢᵀx`。

## 6. `V` 和 `Vᵀ` 为什么能改变坐标

把特殊输入方向放成矩阵的列：

```text
V = [v₁ v₂]
```

例如：

```text
v₁ = [ 1/√2, 1/√2]ᵀ
v₂ = [ 1/√2,-1/√2]ᵀ
```

于是：

```text
V = [[ 1/√2,  1/√2],
     [ 1/√2, -1/√2]]
```

### 6.1 `V` 的作用

假设特殊坐标是：

```text
z = [a₁,a₂]ᵀ
```

那么：

```text
Vz = a₁v₁ + a₂v₂
```

所以：

```text
V：特殊坐标 → 原坐标中的实际向量
```

### 6.2 `Vᵀ` 的作用

由于 `v₁、v₂` 是互相垂直的单位向量：

```text
Vᵀx = [v₁ᵀx,
       v₂ᵀx]
```

这两个数就是：

```text
x 在 v₁ 方向上的分量
x 在 v₂ 方向上的分量
```

所以：

```text
Vᵀ：原坐标中的向量 → 特殊坐标
```

它不是把物理向量凭空改变，而是换一种坐标描述同一个向量。

### 6.3 为什么转置等于逆变换

因为 `V` 的列向量正交且单位化，所以：

```text
VᵀV = I
```

因此：

```text
Vᵀ = V⁻¹
```

也就是：

```text
V：特殊坐标 → 原坐标
Vᵀ：原坐标 → 特殊坐标
```

注意，只有这种正交矩阵才有“转置等于逆矩阵”。一般矩阵不满足这个关系。

## 7. 为什么要计算 `AᵀA`

我们想知道某个输入方向 `v` 经过 `A` 后长度变化多少。

先计算输出：

```text
Av
```

输出长度平方为：

```text
||Av||² = (Av)ᵀ(Av)
```

把转置展开：

```text
(Av)ᵀ(Av) = vᵀAᵀAv
```

所以：

```text
||Av||² = vᵀAᵀAv
```

这说明 `AᵀA` 能够描述 `A` 对输入方向造成的长度变化。

还要注意空间关系：

```text
v       ：输入空间
Av      ：输出空间
AᵀAv    ：输入空间
```

因此 `AᵀA` 最终又回到了输入空间，可以和原来的 `v` 比较。

这里的“回到输入空间”只表示维度和所属空间一致，不代表恢复了原来的向量。

---

## 8. `AᵀAv=λv` 为什么出现

我们希望找到一些方向 `v`，使得 `AᵀA` 对它的作用最简单：

```text
AᵀAv = λv
```

这就是特征向量和特征值的定义：

```text
v：经过 AᵀA 后方向不变的特殊方向
λ：该方向被放大或缩小的倍数
```

它不是说：

```text
Av = λv
```

因为 `Av` 在输出空间，而 `v` 在输入空间；而且 `A` 可能会改变方向。

`AᵀAv=λv` 的作用是：

```text
先观察 A 对输入方向的作用
→ 再用 AᵀA 分析这种作用带来的长度变化
→ 找到长度变化分析中方向保持不变的输入方向
```

由于 `AᵀA` 是对称矩阵，它的特征向量可以选成互相垂直、长度为 1 的向量。这些向量就是 SVD 中的 `v₁、v₂、……`。

---

## 9. 为什么 `λ` 开平方就是奇异值

假设 `v` 是单位向量，并且满足：

```text
AᵀAv = λv
```

左乘 `vᵀ`：

```text
vᵀAᵀAv = λvᵀv
```

因为 `v` 是单位向量：

```text
vᵀv=1
```

所以：

```text
vᵀAᵀAv = λ
```

左边就是：

```text
(Av)ᵀ(Av) = ||Av||²
```

因此：

```text
λ = ||Av||²
```

输出长度是：

```text
||Av|| = √λ
```

定义奇异值：

```text
σ = √λ
```

所以：

```text
λ：输出长度的平方
σ：输出长度
```

这就是为什么奇异值是 `A` 对特殊单位输入方向的缩放倍数。

## 10. 一个完整的 SVD 手算例子

仍然使用：

```text
A = [[1,1],
     [0,0]]
```

### 10.1 计算 `AᵀA`

```text
Aᵀ = [[1,0],
      [1,0]]
```

因此：

```text
AᵀA = [[1,1],
        [1,1]]
```

### 10.2 求特征值

设特征值为 `λ`，要求：

```text
det(AᵀA-λI)=0
```

有：

```text
AᵀA-λI = [[1-λ,1],
           [1,1-λ]]
```

二维行列式计算规则：

```text
[[a,b],      det = ad-bc
 [c,d]]
```

因此：

```text
det(AᵀA-λI)
= (1-λ)(1-λ)-1
= (1-λ)²-1
= λ²-2λ
= λ(λ-2)
```

所以：

```text
λ₁=2
λ₂=0
```

### 10.3 求特征向量 `v₁、v₂`

对于 `λ₁=2`：

```text
(AᵀA-2I)v₁=0
```

得到：

```text
-v₁₁+v₁₂=0
```

所以：

```text
v₁₂=v₁₁
```

方向是：

```text
[1,1]
```

单位化后：

```text
v₁ = [1/√2,1/√2]ᵀ
```

对于 `λ₂=0`：

```text
AᵀAv₂=0
```

得到：

```text
v₂₁+v₂₂=0
```

所以方向是：

```text
[1,-1]
```

单位化后：

```text
v₂ = [1/√2,-1/√2]ᵀ
```

### 10.4 求奇异值

```text
σ₁=√λ₁=√2
σ₂=√λ₂=0
```

所以：

```text
Σ = [[√2,0],
     [0, 0]]
```

### 10.5 求第一个输出方向 `u₁`

先计算：

```text
Av₁
= [[1,1],
   [0,0]]
  [1/√2,
   1/√2]
= [√2,0]ᵀ
```

它的长度是：

```text
||Av₁||=√2=σ₁
```

所以：

```text
u₁ = Av₁/σ₁
   = [√2,0]ᵀ/√2
   = [1,0]ᵀ
```

这说明：

```text
输入方向 v₁=[1/√2,1/√2]
→ 输出方向 u₁=[1,0]
→ 长度变成 √2 倍
```

对于 `v₂`：

```text
Av₂=[0,0]ᵀ
```

它的奇异值为 0，表示该方向的信息完全丢失，没有真正的输出方向。为了补齐 `U`，可以选：

```text
u₂=[0,1]ᵀ
```

于是：

```text
U = [[1,0],
     [0,1]]
```

最终：

```text
A = UΣVᵀ
```

其中：

```text
U = [[1,0],
     [0,1]]

Σ = [[√2,0],
     [0, 0]]

Vᵀ = [[ 1/√2,  1/√2],
       [ 1/√2, -1/√2]]
```

## 11. 用 `x=[3,1]` 验证三步分解

直接计算：

```text
Ax = [4,0]ᵀ
```

再使用 SVD。

### 第一步：`Vᵀx`

```text
Vᵀx = [v₁ᵀx,
       v₂ᵀx]
```

前面已经算过：

```text
v₁ᵀx=2√2
v₂ᵀx=√2
```

所以：

```text
Vᵀx=[2√2,√2]ᵀ
```

这表示：

```text
x 在 v₁ 方向上有 2√2
x 在 v₂ 方向上有 √2
```

### 第二步：`ΣVᵀx`

```text
ΣVᵀx
= [[√2,0],
   [0, 0]]
  [2√2,
   √2]
= [4,0]ᵀ
```

因为第二个方向的奇异值为 0，所以其中的信息被清零。

### 第三步：`UΣVᵀx`

本例中 `U=I`，所以：

```text
UΣVᵀx=[4,0]ᵀ
```

与直接计算的 `Ax` 完全相同。

因此：

```text
Vᵀ：读取输入在特殊方向上的分量
Σ ：分别缩放这些分量
U ：把结果组合成实际输出
```

## 12. 为什么伪逆是 `A⁺=VΣ⁺Uᵀ`

正向过程是：

```text
x → Vᵀx → ΣVᵀx → UΣVᵀx
```

伪逆尽量把它倒过来：

```text
输出
  ↓ Uᵀ
特殊输出坐标
  ↓ Σ⁺
尽可能反向缩放
  ↓ V
输入估计
```

所以：

```text
A⁺ = VΣ⁺Uᵀ
```

为什么顺序反过来？因为复合操作倒放时顺序必须相反：

```text
先做 Vᵀ，再做 Σ，最后做 U
```

反过来就是：

```text
先做 Uᵀ，再做 Σ⁺，最后做 V
```

### 12.1 `Σ⁺` 怎么得到

对每个奇异值：

```text
σ≠0 → 取 1/σ
σ=0 → 仍然写 0
```

本例中：

```text
Σ = [[√2,0],
     [0, 0]]
```

所以：

```text
Σ⁺ = [[1/√2,0],
      [0,    0]]
```

最终：

```text
A⁺ = [[1/2,0],
      [1/2,0]]
```

如果目标输出为：

```text
y=[4,0]ᵀ
```

则：

```text
A⁺y=[2,2]ᵀ
```

验证：

```text
A[2,2]ᵀ=[4,0]ᵀ
```

但 `[3,1]` 也能得到 `[4,0]`。因为一个输入方向已经丢失，所以伪逆无法恢复唯一的原输入，只能选择一个误差最小、通常长度最小的合理解。

## 13. 奇异值、条件数与噪声放大

### 13.1 奇异值的含义

```text
奇异值大：该方向作用强
奇异值小：该方向被严重压缩
奇异值为0：该方向信息完全丢失
```

### 13.2 条件数

对于可逆矩阵：

```text
cond(A)=σmax/σmin
```

例如：

```text
σmax=10, σmin=2     → cond(A)=5
σmax=10, σmin=0.001 → cond(A)=10000
```

条件数很大，说明不同方向的缩放差异很大，反向求解对噪声敏感。

### 13.3 测量噪声、测量误差和结果误差

```text
真实值 → 传感器测量 → 算法计算结果
```

测量噪声：

```text
传感器读数中的随机波动
```

例如真实角度不变，但 IMU 读到：

```text
10.0°、10.1°、9.9°、10.2°
```

测量误差：

```text
测量值 - 真实值
```

结果误差：

```text
算法计算结果 - 真实结果
```

考虑：

```text
A = [[10,    0],
     [0, 0.001]]
```

真实状态：

```text
xtrue=[1,2]ᵀ
```

真实输出：

```text
ytrue=Axtrue=[10,0.002]ᵀ
```

如果传感器测得：

```text
ymeasured=[10,0.003]ᵀ
```

那么第二个测量误差只有：

```text
0.003-0.002=0.001
```

但是反解时：

```text
A⁻¹ = [[0.1,0],
        [0,1000]]
```

所以恢复结果为：

```text
xestimated=[1,3]ᵀ
```

结果误差变成：

```text
[1,3]ᵀ-[1,2]ᵀ=[0,1]ᵀ
```

这就是：

```text
很小的测量误差
→ 被小奇异值对应的倒数放大
→ 形成较大的结果误差
```

## 14. 阻尼最小二乘

普通伪逆对小奇异值取倒数，可能造成巨大输出。

例如：

```text
σ=0.001
```

普通反解系数为：

```text
1/σ=1000
```

阻尼最小二乘使用：

```text
σ/(σ²+λ²)
```

它不会完全追求精确反解，而是允许少量误差，换取有限的输出。

### 14.1 一维例子

假设：

```text
0.1q̇ ≈ 1
```

普通最小解是：

```text
q̇=10
```

如果加入阻尼，优化问题写成：

```text
min (0.1q̇-1)² + λ²q̇²
```

第一项要求尽量完成目标，第二项不希望 `q̇` 太大。

求导并令其为零：

```text
2×0.1(0.1q̇-1)+2λ²q̇=0
```

整理：

```text
(0.1²+λ²)q̇=0.1
```

因此：

```text
q̇=0.1/(0.1²+λ²)
```

例如 `λ=0.1`：

```text
q̇=0.1/(0.01+0.01)=5
```

结果从普通解的 `10` 降到 `5`。

所以阻尼的含义是：

```text
少追求一点精确跟踪
换取更小、更稳定、更可执行的关节速度
```

在机械臂中，阻尼最小二乘常用于接近奇异位形时的速度逆运动学。

## 15. 机器人中的奇异性

机械臂末端速度和关节速度常写成：

```text
v = Jq̇
```

其中：

```text
v：末端速度
J：雅可比矩阵
q̇：关节速度
```

如果根据末端速度求关节速度：

```text
q̇ = J⁺v
```

当机械臂接近奇异位形时：

```text
J 的某个奇异值接近0
→ 某个末端运动方向很难实现
→ 伪逆对该方向取很大的倒数
→ 关节速度突然变大
```

常见处理方法：

```text
阻尼伪逆
```

## 16. 为什么实际少直接求逆

理论上可以写：

```text
x=A⁻¹b
```

但工程中常用：

```python
x = np.linalg.solve(A, b)
```

最小二乘问题常用：

```python
x = np.linalg.lstsq(A, b, rcond=None)
```

需要查看奇异性时：

```python
U, S, Vt = np.linalg.svd(A)
condition_number = S.max() / S.min()
```

原因是：

```text
显式计算逆矩阵通常没有必要；
分解求解通常数值更稳定；
SVD 还能直接显示秩、弱方向和条件数。
```

注意：`solve` 不能修复矩阵本身的病态性。如果最小奇异值接近 0，仍然需要阻尼、截断或其他约束。

实际数值库也不一定按照“先计算 `AᵀA` 再求特征值”的方式实现 SVD。这个过程适合学习原理；工程库通常使用更稳定的双对角化、QR 迭代等算法。

## 17. 与特征值的区别

特征值问题通常写成：

```text
Av=λv
```

它要求输入和输出方向是同一个空间中的同一个方向。

SVD 使用：

```text
Avᵢ=σᵢuᵢ
```

输入方向和输出方向可以不同。

SVD 通过：

```text
AᵀA vᵢ=λᵢvᵢ
```

找到输入方向，再用：

```text
σᵢ=√λᵢ
uᵢ=Avᵢ/σᵢ
```

得到输出方向。

因此：

```text
特征值：研究某个矩阵是否保持某个方向
奇异值：研究 A 对输入方向造成的长度缩放
```

两者有关，但不是同一个概念。

## 19. 本章复习卡

```text
A：输入到输出的线性映射

vᵢ：输入空间中的特殊单位方向

Avᵢ：该输入方向经过 A 后的实际输出

uᵢ：Avᵢ 归一化后的输出方向

σᵢ：||Avᵢ||，该方向的缩放倍数

AᵀA：用来分析输入方向长度变化的矩阵

AᵀAvᵢ=λᵢvᵢ：寻找特殊输入方向

σᵢ=√λᵢ：特征值开平方得到奇异值

A=UΣVᵀ：把复杂映射写成坐标变换、缩放和坐标变换

A⁺=VΣ⁺Uᵀ：尽可能把映射反向恢复

小奇异值：该方向信息弱，反解容易放大噪声

阻尼：牺牲一点精确跟踪，换取有限稳定的输出
```

## 21. 自测题参考答案与代码练习

1. Ax 是任意输入经过矩阵；Avᵢ 是特殊输入方向经过矩阵，满足 Avᵢ=σᵢuᵢ。
2. 对单位方向 v，vᵀx 是 x 沿该方向的带符号投影长度。
3. 若方向向量长度不统一，输出长度同时混入输入长度。统一为1才能比较矩阵的缩放能力。
4. A 可以是长方形；AᵀA 是对称半正定方阵，可以选一组正交单位特征向量，构成输入基。
5. A 有 n 列、m 行，vᵢ 属于 n 维输入空间，Avᵢ 属于 m 维输出空间。
6. ||Avᵢ||²=vᵢᵀAᵀAvᵢ=λᵢvᵢᵀvᵢ=λᵢ，所以 σᵢ=√λᵢ。
7. 非零输出除以其长度 σᵢ 得单位输出方向 uᵢ。σᵢ=0 时不能这样除，补齐正交输出基。
8. V 的各列长度1且互相垂直，所以 VᵀV 的对角元素1，非对角元素0。
9. 只有正交方阵才有逆等于转置；一般矩阵 Aᵀ 不等于 A⁻¹。
10. σ=0 表示某个输入方向映射成零，方向信息丢失，对应降秩。
11. 反解要除以 σ；当 σ 很小，输出中的小误差也被相同比例放大。
12. 阻尼用较小的输出代价换较小的输入范数；它不能恢复已丢失的信息，也不自动满足关节限位。

**计算练习：**J=diag(1,0.01)，目标速度[1,1]。无阻尼解[1,100]。取 λ=0.1，阻尼每个方向的系数为 σ/(σ²+λ²)，得[1/1.01,0.01/0.0101]≈[0.9901,0.9901]。第二方向实际速度只有0.009901，说明稳定输出与精确跟踪存在代价。

**代码练习：**在实验中改变 tolerance，使0.01被保留或截断。答案：保留时该方向取倒数100，截断时取0；检查残差和输入范数同时变化。

**结果解释练习：**如果求出的关节速度很小，就一定跟踪得好吗？答案：不一定，可能截掉了弱方向；还需报告 ||Jq̇-v||。

## 精读补充：把中间步骤讲清楚

### A. 极小与恰好零，不是连续相同的反解行为

A=diag(1,ε)，目标b=[1,1]。ε=.1时普通解[1,10]；ε=.001时[1,1000]。ε恰好0时，数学伪逆设零奇异值倒数为0，解[1,0]，实际输出[1,0]，第二目标没有实现。

输入看起来从1000“突然回到0”，是反解规则切换到不可实现方向被舍弃，不是那个方向突然更容易控制。数值库还使用阈值决定何时当作零，所以需要报告阈值与尺度。

### B. 阻尼是在弱方向做什么？

每个奇异方向将1/σ换成σ/(σ²+λ²)。σ=.001、λ=.1时约.09999，不再1000；对应目标1只能产生约.00009999。阻尼抑制大动作，也拒绝精确完成这一弱方向，不能把“输入小了”单独当作效果更好。

### C. 条件数也受单位影响

把一个输出从m换成mm，矩阵对应行会乘1000，奇异值与条件数可能变化，即使物理系统没变。先按任务允许尺度定义D_y、按关节速度尺度定义D_q，再分析归一化矩阵D_y⁻¹ A D_q。比较不同机器人或位置/角度混合任务时，先说明度量。
