# 01 坐标点向量与主动被动变换

先修：[数学](../01_数学与物理基础/README.md)。项目：P1、P2、P5、P7。学习目标：能解释本章几何/物理关系，完成手算并识别失败条件。

## 1. 同一个杯子，两个观察者

把杯子放在桌上不动。你站在桌子左边，朋友站在右边。两人都指同一个杯子，但说“左边1米”“右边1米”的数字不同。**物理点没有动；描述它的原点和轴不同。**坐标变换计算两种描述之间的关系。

另一方面，你把杯子挪走，仍以桌子左下角为原点描述。此时参考系相同、点的物理位置变了。这叫主动移动。两者都能出现矩阵R和t，所以仅看矩阵乘法不能判断是否真的移动，要看输入输出的语义。

## 2. 把符号固定下来

本教材统一`p_b=R_ab p_a+t_ab`，下标ab意思从a表达转到b表达。其他资料可能反着定义下标，先读等式。

|量|形状|含义|
|---|---|---|
|p_a,p_b|3维|同一个点相对各系原点的位置坐标，m|
|R_ab|3×3|把a表达的方向转换为b表达|
|t_ab|3维|a原点在b中的位置，m|

坐标系包含原点与轴方向；位姿是两系之间的位置与姿态关系。R的每一列是a的一根单位轴用b坐标写出的分量。

## 3. 为什么t是a原点在b的位置

取物理点就是a原点。它在a的坐标p_a=[0,0,0]。代入：p_b=R_ab×0+t_ab=t_ab。因此t不是猜出来的含义，而是由变换等式直接确定。

假设b是世界系，a是车体系，车体原点在世界[2,1]，车头朝世界+x，点在车头前方1m：p_a=[1,0]，p_b=[1,0]+[2,1]=[3,1]。车与点都可以静止，公式照样有效。

如果车真的向前动1m，新的t变成[3,1]；车上固定点的p_a仍[1,0]，新的世界坐标[4,1]。**坐标变换用于描述运动前后的关系；它本身不是运动命令。**

## 4. 点与方向为什么不同

点相对原点量距离，所以换原点要加t。两点差d=p₂-p₁表示方向/位移：

`d_b=(Rp₂a+t)-(Rp₁a+t)=R(p₂a-p₁a)=R d_a`。

平移相消，因此方向向量不加t。世界速度与机身速度转换若涉及运动坐标系和不同参考点，还会出现旋转速度/运输项，不能把“方向旋转”当完整速度变换。

## 5. 主动与被动手算对比

物理向量世界坐标[1,0]；a系相对世界逆时针90°，a的x轴沿世界y。这个不动向量在a是[0,-1]，用R(-90°)变换描述。

主动将世界向量逆时针转90°，固定世界坐标，得到[0,1]，用R(+90°)。相同“转90°”语言会有相反数字，必须说明转的是物体还是坐标轴。

## 6. 项目、实验与失败

P2 VR数据先明确VR参考系和机器人base系；P5激光安装外参先把观测转到base；P7足端力与J必须同系。[四元数实验](../../03_代码实验/01_基础实验/04_坐标与四元数/README.md)也采用固定世界系的主动旋转。

失败：下标反用让运动镜像；把点与方向混用造成速度加上位置平移。排错用“a原点应转成t”和“单位x轴应转成R第1列”两条具体例子。

## 7. 英文与练习答案

“A coordinate transformation can describe the same physical point in two frames. The translation is the origin of the input frame expressed in the output frame. Physical motion changes that relationship over time.”

追问：Does a transformation matrix imply a commanded motion? No. It can simply express an existing relationship.

1. 概念：坐标改变一定点动吗？答：不一定。
2. 计算：R=I,t=[2,1],p_a=[-1,2]？答：p_b=[1,3]m。
3. 代码：方向输入齐次最后分量？答：0，不加t。
4. 解释：VR不动但目标漂移？答：查相对参考/校准、外参、时间和基座状态，不先调IK。

## 精读补充：把中间步骤讲清楚

### A. 坐标系“整体动了”和坐标转换可以同时存在

设世界系w固定，车体系b绑在车上。车原点在世界[2,1] m、车头朝世界y方向。车上固定点在车系[1,0]，世界坐标是R(90°)[1,0]+[2,1]=[2,2]。

车往世界x方向移动1 m后，车系原点变[3,1]，车上点的车系坐标仍[1,0]，世界坐标变[3,2]。物理上确实是车系整体随车移动；数学上每个时刻仍要计算“车系表达→世界表达”。因此这两句话并不冲突，必须分清当前是在描述系间关系还是下运动指令。

若桌上另一个固定点世界坐标[4,1]，车移动前它在车系为Rᵀ([4,1]−[2,1])=[0,−2]；移动后变[0,−1]。桌上点没动，却因为车系动了而改变坐标。

### B. 平移为何不加到方向向量？

车上两个点[0,0]与[1,0]，世界坐标分别[2,1]与[2,2]，差为[0,1]。两次相同平移抵消，位移只被旋转。点、两点差、速度分量、扭转速度要按各自定义转换，不能全都用同一种加t公式。
