# 结果判读与错题复盘

## 1. 先看数据流，不先改参数

排查顺序通常是：

```text
参考是否正确
→ 传感器数值/单位/时间戳
→ 坐标和符号
→ 状态估计
→ 控制器输入
→ 输出限幅/分配
→ 通信帧
→ 执行器反馈
```

如果输入就是错的，继续调控制增益只会把错误放大。

## 2. 现象到假设

| 现象 | 优先假设 | 下一步 |
|---|---|---|
| 整体方向反了 | 坐标轴、符号或电机方向 | 做单轴正负输入 |
| 输出高频抖动 | 测量噪声、微分放大、时间步长 | 画原始/滤波/控制输出 |
| 反应明显慢 | 滤波、通信或计算延迟 | 标记时间戳并算延迟分布 |
| 误差持续存在 | 偏置、摩擦、饱和或模型误差 | 查积分、前馈和限幅 |
| 只在大动作失败 | 输出饱和、约束不可行或功率限制 | 画饱和标志和约束状态 |
| 偶发失控 | 状态过期、竞态或异常恢复不完整 | 注入同样故障并记录状态机 |

## 4. 结论分级

- **确定**：有重复实验或日志直接支持；
- **较可能**：有现象支持，但还存在替代解释；
- **待验证**：只是理论推测。

面试时应明确分级，专业回答不是把猜测说成确定事实。
