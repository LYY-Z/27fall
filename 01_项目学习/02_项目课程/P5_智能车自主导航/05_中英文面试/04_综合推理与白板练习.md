# P5 综合推理、白板与源码追问

本页补充原25道主问，不重编号。每个场景按“中文理解→纸笔中间量→英语口述→源码追问”练；英文用客观源码/教学事实，个人经历句只按贡献证据填写。不要把参考答案当成自己已经完成的实验。

如果公式一眼看不懂，先不要硬算：把每个符号旁边写上“它代表什么、单位是什么、是谁给的”，用箭头画出数据变化，再用一个很小的数字手算。完成中文因果说明后，再练英文表达。综合主线可返回[项目白话总览](../00_项目全貌与学习路线/03_P5导航一趟路是怎样走出来的.md)。

## 使用顺序

1. 用中文回答主问，画输入→计算→输出；写形状、单位、时刻。
2. 对照数字与原源码，指出假设和启用分支。
3. 用英语说45—90秒，回答第二层追问。
4. 记录卡住的是基础、项目、证据还是表达；下次只补对应环节。

## 场景1：规划器版本

**Interviewer:** Which navigation stack is active in this snapshot?

### 先用中文把因果与中间量讲清

当前ROS2 Navfn/RPP配置与L1源可追；旧ROS1 TEB文件不证明当前启用。Hybrid/MPC历史材料有提及但对应实机源未定位；独立教学只能解释算法。源码中订阅legacyplan话题还需实际remap证据。

### Candidate：英语参考

I distinguish the current configuration from historical files and application claims. Navfn and regulated pure pursuit are visible in the current snapshot, while the complete historical Hybrid A-star and MPC deployment chain has not been located.

**Follow-up:** What would match a launch file to a binary?

中文追问答案：CMake target、安装路径、launch executable、运行进程和commit；当前命名差异需核对。

验收：能指出上述结论的源函数或教学假设；没有运行数据时，只说手算/静态所见，不补性能数字。

## 场景2：路径与轨迹

**Interviewer:** Why can a valid grid path be undrivable?

### 先用中文把因果与中间量讲清

点栅格A*不限制转向/足迹；Hybrid连续姿态扩展车型并检查足迹，但输出x/y/yaw无时间。MPC需要带速度/时间参考；当前教学Hybrid与MPC未直接串联。

### Candidate：英语参考

A path describes geometry, while a trajectory also describes timing and velocity. A vehicle must satisfy steering and footprint constraints. The separate teaching planner and tracker are not automatically a complete integrated navigation system.

**Follow-up:** What is needed between planning and tracking?

中文追问答案：参考点一致、曲率与速度界、方向切换、时间参数化、障碍更新与失败策略。

验收：能指出上述结论的源函数或教学假设；没有运行数据时，只说手算/静态所见，不补性能数字。

## 场景3：Twist字段不是单位证明

**Interviewer:** What does linear.x mean in this device-facing message?

### 先用中文把因果与中间量讲清

原协议转换linear.x乘1500，angular.z按90/45…135舵机尺度，使用Twist消息不证明仍为m/s/rad/s；停止分支0/115/1500不同语义待驱动证据。L1输出steering约3.94°、p_gain−1→设备93.94例只描述转换。

### Candidate：英语参考

I inspect the publisher and driver before assigning units. A message type alone does not prove that its fields contain SI velocities; this device-facing path applies motor and steering scales. The stop convention also needs to match the driver.

**Follow-up:** How would two publishers affect this?

中文追问答案：要查控制权仲裁/话题映射，不能默认RPP和L1自动协调。

验收：能指出上述结论的源函数或教学假设；没有运行数据时，只说手算/静态所见，不补性能数字。

## 场景4：状态估计的时间

**Interviewer:** Why does a position jump not necessarily imply planner failure?

### 先用中文把因果与中间量讲清

定位、TF、时间戳、坐标系或轮滑都可造成跳变。速度1m/s时100ms旧数据已有.1m运动差；KF按旧测量当当前融合会错。map/odom/base角色与外参必须一致。

### Candidate：英语参考

Before changing a planner, I inspect localization innovations, transform consistency and timestamps. A delayed pose can be internally smooth but still inappropriate for current control. Wheel slip also changes how much encoder odometry should be trusted.

**Follow-up:** What diagnostics separate them?

中文追问答案：原传感/TF链、创新、covariance、控制参考/反馈和时间年龄同轴记录。

验收：能指出上述结论的源函数或教学假设；没有运行数据时，只说手算/静态所见，不补性能数字。

## 场景5：带约束MPC

**Interviewer:** Why is the previous applied input part of MPC?

### 先用中文把因果与中间量讲清

Δu约束首步以真实上一动作起算；a_rate2/dt.1→Δa≤.2。故障若执行−1则previous=−1，而不能保留上次正常+.2。教学失败制动可违反正常率界且无碰撞约束。

### Candidate：英语参考

Rate constraints start from the input actually applied. After a fallback, I store that fallback input for the next optimization. This teaching example checks input and speed bounds, but it does not include collision constraints or guarantee safety for every failure.

**Follow-up:** Does solver success alone suffice?

中文追问答案：还查finite、输入/速度/率残差、模型有效性和计算截止时间；本轮未运行优化器。

验收：能指出上述结论的源函数或教学假设；没有运行数据时，只说手算/静态所见，不补性能数字。

## 场景6：综合与验证

**Interviewer:** Give a complete navigation explanation with honest gaps.

### 先用中文把因果与中间量讲清

传感/估计/TF→全局规划→局部跟踪→速度到设备尺度→驱动与反馈；逐层指出输入输出。历史完整算法部署缺口如实说明；教学bicycle/Hybrid/MPC是新构造，不当本人历史结果。

### Candidate：英语参考

I explain the chain from sensing and localization through planning, tracking, command conversion and feedback. I identify the active version of each module and separate it from the independent teaching algorithms. Deployment and performance require matched execution records.

**Follow-up:** Which metric would you use?

中文追问答案：定义跟踪横向/航向误差、成功率、最小障碍距离、周期/饱和；数值待实际记录。

验收：能指出上述结论的源函数或教学假设；没有运行数据时，只说手算/静态所见，不补性能数字。
