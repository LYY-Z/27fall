## 四个计算怎样衔接

double_integrator_matrices按恒加速度精确更新生成A/B，状态[e(m),v(m/s)]、输入a(m/s²)。scalar_riccati_step展示剩余步数增加的设计递推。discrete_lqr调用DARE得P，再解线性方程得K；默认Q=diag(10,1),R=.1。多项式用Horner法，列顺序三次、二次、一次、常数，与P7源码求值顺序一致，系数是教学合成。

预期标量A=B=Q=R=1,P0=0，P1=1,P2=1.5,P3=1.6，极限约1.618034，无限时域K约.618034。第一步“剩1步”K=0因为终端代价0，不与无限时域K混淆。教学多项式L=.2得.176。

二状态P/K以实际库输出另填，不能把以前聊天中的P矩阵无条件复制为本环境已运行结果。查看闭环A-BK特征值模<1与DARE残差属于后续核对步骤，当前未执行。

## 数据与观察

`P.csv`、`K.csv`给设计矩阵；`scalar_riccati.csv`给剩余步数、P与对应首步K；`lqr.csv`给时间、状态误差、速度、原始/实际加速度与本步两项代价。设计权重指定了教学成本尺度，不是Kalman方差。

修改Q位置项与R，观察输入/误差权衡；dt改变须重算K；限幅改小会改变原无约束闭环。教学仿真没有真实摩擦/接触，也不证明P1/P7实机部署。

失败：SciPy缺失提示依赖；Q/R非对称/非正性拒绝；不可稳定模型可能DARE失败；control-limit≤0拒绝。数值求解失败必须解释，不把任意P替代最优解。
