# 技术英语：从符号到一句可听懂的话

## 先说量，再读式子

面试时先说“输入是关节速度，输出是末端速度”，再说公式。逐个读全部矩阵元素往往更难听懂；先说明shape和物理意义。

|符号或单位|读法|中文意义与用法|
|---|---|---|
|x dot, x double dot|x dot; x double dot|一阶、二阶时间导数；velocity, acceleration|
|q|joint configuration / quaternion|先说明此处关节量还是四元数，不能共用含义|
|A transpose|A transpose|行列交换；不是inverse|
|A inverse|A inverse|逆；必须方阵可逆|
|J plus|J pseudoinverse|伪逆；least-squares/minimum-norm条件需解释|
|x hat, x hat minus|estimated state; predicted state before the update|估计与更新前预测|
|partial x over partial q|partial derivative of x with respect to q|局部变化率|
|Δt|delta t / sampling interval|seconds，不是频率|
|rad/s; m/s²|radians per second; metres per second squared|角速度；加速度|
|N; N·m; W; J|newtons; newton metres; watts; joules|力、力矩、功率、能量|
|n×m|n by m|n行m列|
|positive semidefinite|positive semidefinite|二次型不小于零，不是所有元素正|

## 六个常用公式的口头解释

**速度映射**：\(\dot{\mathbf{x}}=J(q)\dot q\)。

“The Jacobian maps joint velocities to task-space velocity at the current configuration.” 补一句：“Each column describes how one joint affects all task components.”

**力映射**：\(\tau=J^\mathsf T F\)。

“The transpose maps a consistently defined task force to generalized joint force through virtual work.” 力方向、坐标系和作用对象要先定义；速度反解用pseudoinverse。

**动力学**：

\[M(q)\ddot q+C(q,\dot q)\dot q+g(q)+\tau_f=\tau+\tau_{\mathrm{ext}}.\]

“Motor and external torques must account for inertia, velocity coupling, gravity and friction.” 不逐字符读C，而说velocity-dependent coupling。

**LQR**：\(u=-Kx\)。

“The gain matrix converts state error into corrective input.” x为n×1，K为m×n，输出m×1。\(x^\mathsf TQx\)：“a scalar weighted quadratic state cost”。

**Kalman**：\(\hat x=\hat x^-+Kr\)。

“The innovation is measured output minus predicted output. The gain maps that residual into a state correction.” 增益可以有不同单位、负元素，不一概说全部between zero and one。

**MPC**：“At each cycle, I predict a finite horizon, optimize under constraints, apply the first input, and solve again using the next estimate.” 列出真正实现的constraints，再说求解失败怎么办。

## 读矩阵的完整例子

\[
x=\begin{bmatrix}e\\v\end{bmatrix},\qquad
A=\begin{bmatrix}1&0.1\\0&1\end{bmatrix},\qquad
B=\begin{bmatrix}0.005\\0.1\end{bmatrix}.
\]

“There are two states: position error in metres and velocity in metres per second. The control input is acceleration. With a sampling interval of 0.1 seconds, A propagates the current position and velocity, and B accounts for constant acceleration over one sample.”

如果追问0.005：“It is one half times the sampling interval squared, the extra displacement caused by acceleration.”

## 练习与答案

1. J是2×3，qdot是3×1，结果？答案：two-dimensional task velocity，2×1。
2. “rad每秒”怎么说？答案：radians per second。
3. Q在LQR和KF一样吗？答案：“No. In LQR it weights state cost; in Kalman filtering it describes process-noise covariance.”
4. 不知变量单位？答案先查接口，不用“it is just a number”。
