## 1. 导数问的是“现在变化多快”

位置x随时间变化。两次记录分别x(t)、x(t+Δt)，平均速度：

\[
\frac{x(t+\Delta t)-x(t)}{\Delta t}.
\]

把时间间隔缩得越来越小，得到瞬时变化率：

\[
\dot x=\frac{dx}{dt}
=\lim_{\Delta t\to0}\frac{x(t+\Delta t)-x(t)}{\Delta t}.
\]

上面的点叫时间导数记号。x是m，ẋ是m/s。q是关节角rad，q̇是rad/s。两者不是不同写法的同一数。

假设q(t)=2t²，q̇(t)=4t。t=1s时q=2rad，q̇=4rad/s。只知道q=2，通常不能确定q̇：机器人可以在这个角度静止，也可以经过这里高速运动。

## 2. 为什么t²的导数是2t

把定义代进去：

\[
\frac{(t+\Delta t)^2-t^2}{\Delta t}
=\frac{2t\Delta t+(\Delta t)^2}{\Delta t}
=2t+\Delta t.
\]

Δt趋近0，剩2t。导数不是神秘规则，是很小区间的变化除以区间长度。规则能让我们不用每次展开极限。

常用规则：常数导数0；t的导数1；c f的导数c f'；f+g的导数f'+g'；sin q对q导数cos q；cos q对q导数-sin q，角度用rad。

## 3. 一层函数套另一层，为什么相乘

设末端位置x=f(q)，关节角q=g(t)。时间影响q，q再影响x：

\[
t\to q\to x.
\]

很小时间dt内，关节变化dq≈q̇dt；很小关节变化dq内，末端变化dx≈f'(q)dq。代进去：dx≈f'(q)q̇dt。除以dt：

\[
\boxed{\dot x=f'(q)\dot q}.
\]

**一个转换比例接另一个转换比例，比例相乘。** 如果末端每1rad关节变化产生2m变化，而关节每秒变化3rad，末端每秒变化6m。

具体x=q²，q=3t：x=9t²，直接导数18t；链式法则f'=2q、q̇=3，所以ẋ=2×3t×3=18t，两种方法一致。

## 4. 偏导是什么

如果x=f(q1,q2)，有两个输入。\(\partial x/\partial q_1\)问：**保持q2不变，只微小改变q1，x每单位改变多少**。\(\partial x/\partial q_2\)同理。

例x=q1²+3q2：偏q1导数2q1，偏q2导数3。这些偏导依赖当前q。q1=1时第一项比例2，q1=5时比例10。

但真实运动两个关节可以同时动，因此两份贡献相加：

\[
\dot x=\frac{\partial x}{\partial q_1}\dot q_1
+\frac{\partial x}{\partial q_2}\dot q_2.
\]

不是随意把q̇写在后面，而是每条输入影响路径都有“局部比例×输入变化率”，再把所有路径加起来。

## 5. 雅可比为何按行输出、列输入

假设还输出y=f2(q1,q2)：

\[
\dot y=\frac{\partial y}{\partial q_1}\dot q_1
+\frac{\partial y}{\partial q_2}\dot q_2.
\]

两条规则叠起来：

\[
\begin{bmatrix}\dot x\\\dot y\end{bmatrix}
=\underbrace{\begin{bmatrix}
\partial x/\partial q_1&\partial x/\partial q_2\\
\partial y/\partial q_1&\partial y/\partial q_2
\end{bmatrix}}_{J(q)}
\underbrace{\begin{bmatrix}\dot q_1\\\dot q_2\end{bmatrix}}_{\dot q}.
\]

q̇是列向量。比如[.2,-.1]^T rad/s：第一关节朝正方向.2，第二朝负方向.1。J每行说明一个输出怎样组合两个输入，每列说明一个关节怎样影响全部末端分量。

## 6. 二连杆完整代入

\[
x=l_1\cos q_1+l_2\cos(q_1+q_2),\quad
y=l_1\sin q_1+l_2\sin(q_1+q_2).
\]

对q1，第二项内层q1+q2导数1；对q2也导数1。因此：

\[
J=\begin{bmatrix}
-l_1\sin q_1-l_2\sin(q_1+q_2)&-l_2\sin(q_1+q_2)\\
l_1\cos q_1+l_2\cos(q_1+q_2)&l_2\cos(q_1+q_2)
\end{bmatrix}.
\]

l1=l2=1m，q1=0，q2=π/2：J=[[-1,-1],[1,0]]m/rad。q̇=[.2,-.1]：ẋ=-.2+.1=-.1m/s，ẏ=.2m/s。

位置(1,1)m与速度(-.1,.2)m/s是不同量。不是求完J机器人就到了(-.1,.2)，这是当前位置的运动趋势。

## 7. 有限差分接到代码

```python
import numpy as np
def position(q):
    return np.array([np.cos(q[0]) + np.cos(q[0]+q[1]),
                     np.sin(q[0]) + np.sin(q[0]+q[1])])
q = np.array([0.0, np.pi/2])
h = 1e-5
columns = []
for j in range(2):
    dq = np.zeros(2)
    dq[j] = h
    columns.append((position(q+dq)-position(q-dq))/(2*h))
J_numeric = np.column_stack(columns)
```

每次只改变一个关节，所以得到一列。中心差分不是实际控制命令，是检查局部敏感度的方法。h太大偏离局部，太小浮点相减会丢精度。

## 8. 项目、假设与失败

P2用J反求速度，P7闭链几何也可以对主动关节求导，EKF对状态函数求导构造局部传播。必须说明“对哪个变量求导”，不是所有雅可比都叫关节雅可比。

上式假设几何f不显式随时间变化。若移动基座、连杆长度由另一个执行器改变，或f(q,t)，还需\(\partial f/\partial t\)或补上相关变量贡献。

失败：角度deg当rad，导数比例错；解析J列顺序不符关节数组；用一个姿态的J做很大位移，局部近似失效。

## 9. 英文与练习

English: “The Jacobian contains the partial derivatives of each output with respect to each input. The chain rule turns these local sensitivities into a velocity mapping.”

追问：What is q dot? Why does the Jacobian depend on configuration?

练习：①x=q1²+3q2，q=[2,1]，q̇=[.5,-1]，ẋ？②上面二连杆若q̇=[0,1]，末端速度？③增大差分h观察何种误差？④移动基座为什么不能只用关节J？

答案：①2q1×.5+3×(-1)=2-3=-1。②[-1,0]m/s。③大h包含曲率，小h受浮点消减影响。④基座本身的运动也贡献末端速度，要加入基座变换/速度。

## 精读补充：把中间步骤讲清楚

### A. 两个关节同时改变，为什么贡献相加？

设x=q₁²+3q₂，当前q=[2,1]，小时间dt=.01 s、qdot=[.5,−1]。关节增量为dq=[.005,−.01]，位置变化的一阶预测为(2q₁)dq₁+3dq₂=4×.005−.03=−.01。因此预测速度−.01/.01=−1。

直接算新函数：x_old=7，x_new=2.005²+3×.99=6.990025，真实函数变化−.009975；与−.01相差.000025，来自dq₁²。这个小差正是局部导数忽略的二阶项。

### B. q和qdot是两张不同的表

q=[0,π/2] rad说明关节现在在哪；qdot=[.2,−.1] rad/s说明当前怎样变化。dt=.1 s时，q_next≈[.02,π/2−.01]。qdot不是“下一关节角”，也不固定由q确定：同一角度可以静止或快速经过。

### C. 偏导没有时间单位，为什么乘qdot后有？

位置对角度的偏导单位m/rad；关节速度rad/s。相乘为m/s。每列先把某个关节速度转换成末端各分量的贡献，再把关节贡献相加。对时间求导时改变的是所有随时间变化的q；偏导则暂时只改变一个q，这就是两种导数的不同任务。
