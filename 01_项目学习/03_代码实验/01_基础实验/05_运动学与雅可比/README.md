## 按代码推

FK按绝对方向q1、q1+q2求端点；J每列是FK对对应关节偏导。IK先检查距离，再取acos并按elbow±选择支，目标原点退化情况明确报非唯一。差速函数输出[left,right]线速度，不能直接当电机角速度。

预期l1=l2=1、q=[0,π/2]得位置[1,1]m，J=[[-1,-1],[1,0]]m/rad；qdot=[.1,.2]得[-.3,.1]m/s。dt=.01的线性近似[.997,1.001]，更新FK与它有小非线性差异。直腿q2=0时rank=1，无法瞬时实现x方向速度。q2接近零，反解范数可能变大；恰好零时伪逆输出有限但残差非零。

输出`singularity.csv`为q2(rad)、秩、最小奇异值(m/rad)、关节速度范数(rad/s)、末端残差(m/s)。所有是新教学数据。

练习：用[有限差分实验](../02_协方差与有限差分/README.md)的函数核对J；修改长度、目标与elbow支，重新FK。把target设[3,0]应不可达；轮距≤0应拒绝。将q2=-.01解释关节速度方向为何变化。
