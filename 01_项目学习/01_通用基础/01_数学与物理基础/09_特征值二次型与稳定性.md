# 9. 特征值、二次型与稳定性

先修：[矩阵](03_矩阵乘法转置与维度.md)、[平方代价](07_范数最小二乘与伪逆.md)。项目：P1/P7的LQR，P5优化。实验：[LQR](../../03_代码实验/01_基础实验/09_LQR与Riccati/README.md)。下一章：[概率与协方差](10_均值方差与协方差.md)。

## 1. 有些方向经过矩阵不改变方向

A=[[2,0],[0,.5]]。输入[1,0]变[2,0]，仍沿x；输入[0,1]变[0,.5]，仍沿y。对某非零向量v，如果Av=λv，v叫特征向量，λ叫特征值。

λ=2表示每次沿这个方向放大2倍；λ=.5表示缩小一半；λ负还会反方向。特征向量可以任意非零倍缩放，所以通常归一化来方便比较。

不是所有方向都如此。[1,1]变[2,.5]，比例不一样，方向改变。

## 2. 为什么求det(A-λI)=0

Av=λv等价(A-λI)v=0。若A-λI可逆，唯一解v=0，但特征向量不允许零。因此必须不可逆，即行列式0。

手算A=[[2,1],[1,2]]：

\[
\det(A-\lambda I)=(2-\lambda)^2-1=0
\Longrightarrow\lambda=3,1.
\]

λ=3时(2-3)v1+v2=0，v2=v1，方向[1,1]。λ=1时v1+v2=0，方向[1,-1]。除以√2成为单位向量，两方向垂直。

实对称矩阵有实特征值且能选正交特征向量。一般矩阵可能有复特征值或缺少完整特征向量，不能把对称矩阵结论无条件套用。

## 3. 稳定性为什么看重复作用

离散系统x_next=Ax，没有输入。若x0沿特征方向v，x1=λx0，x2=λ²x0，k步λ^k x0。因此：

- |λ|<1：逐渐趋近0；
- |λ|>1：误差沿这个方向放大；
- |λ|=1：边界情况，要进一步分析，不保证趋近0。

例如λ=-.5，符号来回翻转，大小衰减；λ=-1.1，来回翻且放大。所有特征值严格在单位圆内，有限维离散线性系统才渐近稳定。

连续系统ẋ=Ax的条件不同：解沿特征方向按e^{λt}变化，要求实部Re(λ)<0。别把连续条件“负”与离散条件“绝对值小于1”混用。

反馈u=-Kx使x_next=(A-BK)x。LQR用模型和代价求K，闭环应分析A-BK，而不是只分析开环A。饱和后不再完全符合此线性闭环。

## 4. 二次型为什么能表示误差大小

\[
V(x)=x^TQx.
\]

x是n维误差，Q是n×n权重。Q=diag(4,1)时V=4x1²+x2²，第一误差同样数值受到4倍处罚。

正定：对任何非零x，x^TQx>0；半正定：≥0，可能某个非零方向代价为0。实对称Q正定等价所有特征值>0。

对Q=[[2,1],[1,2]]：V=2x1²+2x1x2+2x2²。交叉项表示两个误差相关组合也影响代价。写成特征方向坐标，V=3a²+b²，a是[1,1]方向分量，b是[1,-1]方向分量。

x=[1,1]时V=6；x=[1,-1]时V=2。两向量欧氏长度相同，但这个权重更介意共同偏移方向。

## 5. U/V正交与Q正定不同

正交矩阵满足V^TV=I，意味着保长度、列正交单位化。正定是对x^TQx的正性要求，两者不是同一概念。

90°旋转R=[[0,-1],[1,0]]是正交矩阵，但x^TRx=0，不正定，也不是对称矩阵。SVD的U/V是正交基变换，不能称“正定矩阵”；A^TA则是对称半正定。

## 6. 单位和权重

若x1是m、x2是m/s，原始平方不能无说明相加。可以用允许误差尺度归一化：

\[
V=\left(\frac{e}{e_{scale}}\right)^2+
\left(\frac{v}{v_{scale}}\right)^2.
\]

这等价Q=diag(1/e_scale²,1/v_scale²)。例如允许位置尺度.1m、速度尺度.5m/s，Q=diag(100,4)。这些是设计偏好，不是传感器方差。

## 7. 代码、项目和失败

```python
import numpy as np
A = np.array([[2., 1.], [1., 2.]])
eigenvalues, eigenvectors = np.linalg.eigh(A)
x = np.array([1., -1.])
cost = x @ A @ x
```

对对称矩阵用eigh，输出列是特征向量；列符号可相反而表示同一方向。P7腿长变化使A/B改变，固定K的闭环性质也可能变化；P1连续LQR分析不能拿离散模型权重直接断言部署效果。

失败：把一个特征值当整体稳定性；混淆连续/离散条件；非正定R使控制优化没有唯一有限最小值；把局部线性稳定当任意大倾角实机稳定。

## 精读补充：把中间步骤讲清楚

### A. 负反馈不是“所有K元素都必须正”

模型xdot=−u，说明正输入反而减少状态。若希望xdot=−2x，需u=2x。在写u=−Kx的记号下K=−2。负号来自统一控制律表达，实际方向还取决于B与坐标约定。

### B. 稳定也可能先出现很大的瞬态

离散A=[[.5,10],[0,.5]]，两特征值都.5，最终衰减。但x₀=[0,1]，第一步Ax₀=[10,.5]，第一分量先很大。因为第二状态耦合到第一状态，单看特征值不能保证峰值、限幅或安全范围满足要求。

因此LQR/MPC比较除了是否收敛，还要记录峰值、恢复时间与输出限幅。局部稳定结论与全过程能力约束分别检查。

### C. 二次型中的非对角项不是装饰

Q=[[2,1],[1,2]]，x=[a,b]，逐项乘得到2a²+2ab+2b²。a,b同号时交叉项增加分数，反号时减少；仍不会产生负总代价，因为特征值3和1均正。不能仅因某个非对角元素为负就判断权重非法，要看完整二次型。
