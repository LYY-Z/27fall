# P2 VLAI 机械臂与底盘：目标怎样变成机器人动作

## 先分清项目中的三条线

P2 的资料涵盖 VR 机械臂仿真/遥操作、主从机械臂的重力补偿与跟随、差速底盘控制。它们可放在同一个项目背景下学习，但要分别追踪各自的入口、模型和执行器，不能把三套代码自动拼成一条已部署链。

```mermaid
flowchart TB
  subgraph VR[VR → 仿真机械臂]
    H[手柄位置/朝向] --> R[相对位姿与坐标映射]
    R --> T[手腕目标位姿]
    T --> M[Mink任务 + IK求关节速度]
    M --> S[积分小步 → MuJoCo状态]
    S --> Q[读取下一周期qpos]
    Q --> M
  end
  subgraph Arms[Leader / Follower]
    L[Leader反馈/人手推动] --> G[KDL重力补偿与主臂控制]
    L --> F[Follower关节参考映射与反馈控制]
    F --> FQ[Follower电机反馈]
    FQ --> F
  end
  subgraph Base[差速底盘]
    C[底盘目标速度] --> W[左右轮速度分配]
    W --> CAN[板端 / CAN接口]
    CAN --> FB[编码器反馈与里程计]
    FB --> PID[速度环是否调用须查版本]
    PID --> CAN
  end
```
