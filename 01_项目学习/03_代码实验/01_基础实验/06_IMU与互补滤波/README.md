## 逐步代码

比力函数检查R为正旋转，减body偏置再旋转加world重力。互补函数先θ+ωdt，再按α融合重力倾角。main先记t=0初始状态，此时未采集/积分，gyro/acc读数与gyro_sample_time_s写NaN。第k段用start=(k−1)dt的陀螺角速.1cos(.5start)预测到t=kdt；在终点生成truth=.2sin(.5t)、加速度角与5≤t<7污染标记，再融合。真值、acc角与更新后估计均对应t；陀螺采样对应start并显式记录。剩余差异是离散近似与噪声，不再混入一整步时间错位。

预期静止f=[0,0,9.81]算世界a=0；θ=.1、ω=.2、dt=.01、acc=.09、α=.98融合.10176rad。只积分长期偏置漂移，互补通常减小长期漂移但受污染；这里所有观察都待实际运行记录。

`imu.csv`列为时间s、真roll rad、陀螺rad/s、重力角rad、只积分角rad、融合角rad、污染标志、陀螺采样起点gyro_sample_time_s。默认0…20秒含初始行按代码推算为2001行，未运行确认；初始行未有的传感器字段为NaN。用真值算RMSE与最大误差，分别观察正常和污染区间，不只看曲线平滑。

练习：α改.9和.999，比较污染/漂移；偏置改0与.05；手动构造roll30°静止比力，转到世界应0。α越大不保证越好；α=1永远不使用加速度参考。dt≤0、R镜像、输入NaN均需拒绝。
