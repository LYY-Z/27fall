# 个人陈述（中文版）— 香港城市大学 计算机科学理学硕士

在我基于 OpenHarmony 搭建的智能园艺系统里，一个运行在 RK3588 板上的 YOLOv5 检测器决定水泵何时启动。让这个闭环可信，靠的不是模型本身，而是它周围的一切：每条观测所附带的置信度与时间戳，在极端状态下覆盖 Agent 的规则快速路径，以及在决策层不确定时保证水泵安全的 Hi3861 端状态机。此后我做过的每一台机器人都重复了同一规律：可靠的实体运动依赖于连接感知、算法与执行器的计算机系统，依赖于可靠的接口、统一的状态表达，以及在运行条件异常时仍能保持安全的执行链路。因此我申请香港城市大学计算机科学理学硕士，希望系统提升软件工程、数据工程与人工智能方面的能力，并将其继续用于机器人算法与智能系统开发。

我是深圳技术大学计算机科学与技术专业的大四学生，专业排名 6/156。除计算机专业课程外，我还修读了自动控制原理与现代控制理论。在深圳市人工智能与机器人研究院的实习中，我负责一台带双臂上肢的三全向轮球形机器人的底盘平衡控制：基于 IMU 与轮速反馈构建控制状态，设计并部署位置—姿态级联 PID 控制器，通过三轮运动学分配控制量；同时将球形底盘建模为四状态倒立摆，以 LQR 分析控制增益、稳定性与执行器输出之间的关系，并利用 URDF/Pinocchio 估计双臂运动造成的质心变化，接入重力前馈。

我目前在开鸿 M-Robots 团队的实习进一步强化了我对机器人软件系统的理解。我参与面向异构机器人的 OpenHarmony 平台开发，围绕设备能力抽象、ROS/ROS2 运动指令与底层驱动映射，以及传感器和执行器状态同步等问题开展工作，并接触基于 M-DDS 的设备发现、能力注册与任务分发。这些工作不只是把接口接通：它们要求在不同硬件、不同时间尺度和不同运行状态之间建立可复用的软件边界，同时确保任务规划经过检查后再进入物理执行。这段经历也让我意识到，机器人平台规模扩大后，网络、数据一致性、安全策略和软件工程方法会与控制算法同样重要。

我的其他项目则从算法侧补充了这一认识。在车式移动机器人上，我搭建了从 EKF/AMCL 定位、Hybrid-A* 全局规划、TEB 局部轨迹优化到 MPC 跟踪控制的自主导航链路，让车辆能够在实机上定位、绕开障碍并跟踪规划路径；在双臂机器人项目中，我用 MuJoCo/Mink 求解约束逆运动学，让 VR 手柄的运动驱动末端执行器而不在奇异位形附近产生速度放大，并搭建了带重力补偿的主从控制器用于手持示教。连同园艺系统，这些经历让我能够从控制、规划、视觉和平台软件多个层面理解机器人，也清楚看到自己在机器学习原理、数据处理和可扩展软件设计方面仍需要系统训练。

该计算机科学理学硕士项目以计算机科学基础为核心：核心课程为 Software Engineering、Data Engineering 与 Computer Networks and Internets，选修方向涵盖人工智能、数据科学与信息安全，并设有 Project 或 Research/Internship Project 课程。Software Engineering 与 Data Engineering 是我希望补足大型软件系统设计与验证方法的地方；Artificial Intelligence Stream 从 Machine Learning: Principles and Practice 开始，是我希望把对机器学习的实践性熟悉替换为原理性理解的地方。之后我会用 Project 课程完成一个机器人感知、导航或平台软件项目。与直接限定于某一种机器人机构的课程相比，该项目的计算机科学训练更适合我建立可以迁移到不同机器人平台的算法与软件基础。

毕业后，我希望在粤港澳大湾区从事机器人算法与智能系统开发，重点关注移动机器人的感知、导航和运动控制，并逐步成长为能够连接算法、软件平台与真实执行系统的机器人工程师。我的准备结合了真实硬件上的控制、导航与机器人平台实践；我希望通过该计算机科学理学硕士项目，获得支撑下一阶段机器人算法工作的系统性、可扩展基础。
