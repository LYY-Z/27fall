# 数据曲线与量化模板

## 1. 指标先定义再计算

| 指标 | 定义 | 适用场景 |
|---|---|---|
| MAE | 平均绝对误差，平均的 `|e|` | 位置、角度、速度 |
| RMSE | `sqrt(mean(e²))`，更重视大误差 | 跟踪和估计 |
| 峰值 | `max(|e|)` 或 `max(|u|)` | 安全和执行器 |
| 稳态误差 | 进入稳定区间后的平均误差 | 控制 |
| 超调量 | 首次超过目标的最大幅度 | 阶跃响应 |
| 调节时间 | 进入误差带后不再越出的时间 | 控制 |
| 延迟 | 输入事件到输出响应的时间差 | 控制、通信 |
| P95 | 95% 样本不超过的值 | 周期和延迟抖动 |
| 饱和比例 | 输出处于上下限的样本占比 | 控制器健康度 |

## 2. 推荐曲线

控制类至少画：

- 参考值与实际值；
- 误差；
- 控制输出与上下限；
- 关键传感器原始值与滤波值；
- 状态机和异常标志。

导航类再加：

- 地图、全局路径、局部轨迹和实际轨迹；
- 速度、曲率和规划耗时；
- 定位协方差与重规划事件。

通信类再加：

- 发送/接收时间戳；
- 序号、丢帧、错误码；
- 看门狗状态和恢复耗时。

## 3. 防止误导

- 不把滤波后的曲线当成真实精度；
- 不把一次最好结果当成普遍结果；
- 不混用不同单位；
- 不在不同初始条件下直接比较；
- 不用“看起来更平滑”替代指标；
- 写清样本数、实验时长和异常次数。

## 4. 结果表达

```text
在相同初始状态、参考输入和噪声条件下，
方法 A 的 [指标] 为 [值/待测]，
方法 B 的 [指标] 为 [值/待测]。
差异可能来自 [原因]；仍需通过 [下一实验] 区分。
```
