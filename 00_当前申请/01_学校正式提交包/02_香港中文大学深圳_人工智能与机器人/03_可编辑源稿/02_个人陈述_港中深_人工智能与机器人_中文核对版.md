# 个人陈述（中文版）— 香港中文大学（深圳） 人工智能与机器人理学硕士（MAIR）

我在 AIRS 参与的球形机器人，必须在双臂于其上运动、质心持续变化的情况下保持平衡。在实机上做到这一点让我看清了两件事：每一个模型、状态估计和控制输出都必须经受真实约束的检验；而我所依赖的工具——线性模型和手工设定的增益——有其上限，不补上更多的数学、优化与学习方法就无法突破。我申请人工智能与机器人理学硕士，正是为了建立这些基础，把工程实践提升为系统的算法设计能力。

我是深圳技术大学计算机科学与技术专业的大四学生，专业排名 6/156，在计算机课程之外修读了自动控制原理与现代控制理论。在深圳市人工智能与机器人研究院，我负责一台搭载双臂上肢的三全向轮球形机器人的平衡控制。我设计并部署了级联 PID 控制器，随后把系统建模为线性化的四状态倒立摆，用 LQR 理解各状态权重在稳定性与控制量之间的权衡，这解释了我在实机上看到的增益整定现象与执行器饱和。我用 URDF/Pinocchio 估计双臂的质心偏移，并作为重力补偿前馈接入。底盘在双臂沿固定轨迹运动时保持了动态平衡。

两个实验室项目把我从平衡带到了运动与导航。在可变腿长的轮腿机器人上，我通过闭链腿部运动学实现了腿长调度 LQR 与虚拟模型控制，并在实车上整定。在车式移动机器人上，我搭建了从 EKF/AMCL 定位、Hybrid-A* 与 TEB 规划到 MPC 跟踪的链路，并在车上运行。在未来动力，我转向了操作：双臂机器人的 VR 遥操作，用 MuJoCo/Mink 求解约束逆运动学，让双臂跟随操作者并抑制奇异位形附近的速度放大；以及基于 URDF/KDL 动力学、带重力补偿的主从控制器，用于手持示教。更早之前，我负责一台进入 2025 年全国赛的 RoboMaster 英雄机器人的嵌入式控制，并独立完成了一个 OpenHarmony 个人项目，把边缘视觉推理、LangGraph 决策链与执行器闭成一环。

这些项目的共同点是：我针对不同机器人分别建立模型，并根据真实硬件分别整定控制器。我还没有系统地学过操作、作为设计工具的优化以及强化学习，而我希望能用优化与概率的语言来推理这些系统。这就是我选择 Robotics 方向的原因。Robot Manipulation 与 Math Fundamentals for Robotics 正是我双臂工作所缺的基础；Artificial Intelligence 与 Machine Learning 两门核心课会为我迄今只是"部署过"的学习型感知提供原理基础；Mobile Robotics、Reinforcement Learning 与 Optimization 三门选修课则直接对应我的导航与控制经验。

我的目标是在粤港澳大湾区成为一名机器人算法工程师，专注移动与双臂机器人的导航、控制与学习，并成长为能够掌握一款机器人产品完整算法栈的人。该项目将数学基础、机器学习与具身智能结合起来，又处在深圳的机器人产业之中——我曾在这里的一家研究院和两家公司实习——因此与我的发展目标高度契合。我的准备主要来自实践：我曾把控制、导航与操作模块推进到硬件验证阶段，也清楚自己仍需补上哪些理论。我打算用这两年系统地建立这部分基础。
