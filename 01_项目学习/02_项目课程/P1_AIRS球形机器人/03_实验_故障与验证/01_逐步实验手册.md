# 三个教学实验

## 先看懂实验想回答的问题

这些实验是独立的教学算例：一个检查球速和轮速能否互相换算，一个比较简化平衡控制，一个看手臂移动如何改变质心与重力矩。它们不连接真实机器人，也不能证明历史实机表现。每个例子先预测输入变化会让结果往哪个方向变，再按README记录数据；当前程序尚未运行核对。


全部环境A，无硬件，代码/完整命令见[P1实验README](../../../03_代码实验/02_项目实验/P1/README.md)，当前未运行核对。

若要单独完整实践 LQR（安装 Python 科学计算依赖、从项目参数构建四状态模型、改变 Q/R、观察限幅/周期/噪声/延迟），请按[四状态 LQR 仿真实验操作手册](03_LQR四状态仿真实验操作手册.md)和配套[lqr_four_state_sim.py](../../../03_代码实验/02_项目实验/P1/lqr_four_state_sim.py)进行。该专门实验使用项目源码配置的参数快照，但仍是单平面教学仿真，不接硬件。

1. ball_wheel_mapping：用球角速生成三轮速，再解回球角速，记录往返误差。改纬度至退化值观察明确失败；不把它当平面全向矩阵。
2. balance_compare：固定四状态小角度教学模型，对照连续LQR与明确PD结构，统一τ输入、限幅、初态和扰动；比较位置、倾角、控制峰值与恢复，不代替原机PID全部层。
3. com_feedforward：固定合成双臂轨迹，按质量加权CoM、计算mg×偏移与反向补偿；比较对称/非对称姿态。数组计算不调用真实机器人也不自动证明前馈实机改善。

每次保存版本、参数、命令、数据来源、预期与实际、解释和失败。练习完成才更新学习进度。
