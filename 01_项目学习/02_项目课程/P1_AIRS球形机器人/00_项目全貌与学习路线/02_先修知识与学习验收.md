# 先修与学习验收

如果一上来被LQR、矩阵或力矩公式卡住，先别从头硬啃推导。先看[端到端闭环总图](03_P1端到端闭环、数据时序与实时性.md)，把传感器、控制器、轮子和球之间的因果关系认出来；再沿下面的小路线补缺失的基础。

1. 先认识角度、长度、速度和单位，再学矩阵“行乘列”与导数“变化有多快”；
2. 再看坐标系和球轮几何，理解轮子怎样带动球；
3. 然后看IMU、编码器和时间戳，分清测量、估计和积分出来的位置；
4. 最后学PID/级联控制和LQR，辨认本项目实际运行的PID与离线分析的LQR；
5. 阅读[一个控制周期](../02_源码阅读与运行/02_一个周期的调用与数据流.md)，再逐章学习01—06；
6. 用中文复述后再看源码、教学示例和英文面试题。

先修入口：[通用基础](../../../01_通用基础/00_基础课程总览.md)。不必先学完整机器学习。

系统验收一：不用看文档画出IMU、轮反馈、cmd_vel、双臂JointState/CoM、位置外环、姿态内环、ik、限幅、ROS/CAN与反馈之间的数据箭头。系统验收二：说明哪些是传感器测量、哪些是滤波/运动学估计、哪些是积分状态；指出轮速积分为什么漂移、是否有外部定位校正。系统验收三：区分控制器配置100 Hz、命令积分假设10 Hz、传感器回调频率和实测端到端时延；不能把配置当测量。系统验收四：说清固定增益LQR设计时算P/K、在线通常只需Kx；本项目C++运行路径仍为级联PID。系统验收五：区分小计算量、实时性、控制效果和能耗，给出每种判断所需的日志/指标。

原理验收一：手算球角速到三轮角速，并说清球半径/轮半径。原理验收二：画位置误差→倾角参考→姿态反馈→轮速命令，按源码指出两次t2v。原理验收三：解释CoM质量加权与重力矩，说明/com_vel是否消费。原理验收四：指出跌倒reset与明确电机停机的差别。原理验收五：用英文说明PID实机执行与LQR模型分析边界，并回答“如何测控制周期、抖动和数据年龄”。

学习状态从未学→直觉→手算→实现→分析→英文讲逐级记录，当前文件写好不等于已掌握。

## 复习工具：把控制周期讲成一条因果链

不要从矩阵符号开始背。每次复习都按同一个顺序追问：**机器人此刻是什么状态 → 状态由哪些传感器/估计得到 → 控制器比较什么目标 → 算出什么中间量 → 这个量怎样变成轮命令 → 下周期怎样收到反馈**。

```text
IMU姿态/角速度 + 轮反馈 + cmd_vel + 双臂关节状态
                ↓ 回调、滤波、缓存（时间可能不同步）
姿态与轮速估计 → 三轮正/逆运动学 → x/y/速度估计
                ↓
位置/速度外环给 roll/pitch 参考
                ↓
姿态内环 + CoM重力前馈
                ↓ 轴向控制量
三轮几何分配 → 整体范数限幅 → 命令滤波
                ↓
ROS驱动/CAN/电机 → 新轮反馈与IMU数据
```

这是一张职责图，不代表所有输入在同一时刻同步采样。复习时在每条箭头旁写下：数据单位、时间戳/缓存来源、下游使用者。

### P1 易混概念对照

| 容易混在一起 | 应该怎样区分 |
|---|---|
| 测量、滤波、估计 | IMU/编码器提供测量；滤波减少部分高频波动但引入延迟；由轮速积分的 x/y 是估计，会漂移。 |
| 位置外环与姿态内环 | 外环把位置/速度误差变成倾角参考；内环让机身跟踪倾角参考并提供阻尼。外环输出不是轮电机命令。 |
| PID、LQR | 级联 PID 是已检查的运行路径；四状态 LQR/Riccati 用于模型化分析或教学设计，不能因为算出 K 就说实机在运行 LQR。 |
| PID输出、CoM前馈、力矩 | “tau”变量名不能单独证明单位是 N·m。必须沿缩放、几何分配和电机协议追到接口，确认量纲和对象。 |
| reset、停止 | reset 清控制器内部状态不必然发送零命令，更不自动证明驱动/电机停止。要查输出和驱动超时链。 |
| 配置频率、真实频率 | 频率设置/定时器参数不是实测周期；要用相邻周期时间戳统计均值、最大值和抖动。 |

### 自测题（先遮住答案提示再讲）

1. **状态来源**：当前 x/y 是定位传感器直接读数，还是由轮速估计？提示：找轮速→球/机身速度→积分，并说明漂移来源。
2. **两层控制**：cmd_vel 目标和当前速度不同时，外环先给什么？姿态内环再给什么？提示：先答倾角参考，再答轴向控制量，最后才是三轮速度命令。
3. **LQR**：A、B、Q、R、P、K 的顺序是什么？提示：模型与代价定义→Riccati解P→算K→反馈；Q/R不是K，P也不是运行命令。
4. **双臂**：为什么手臂动作改变CoM前馈？提示：质量加权位置改变→重力对支撑点的力臂改变→预测倾覆矩改变；再说明反馈为何仍不可省。
5. **保护**：跌倒阈值触发后能否直接说“电机已停”？提示：分别找状态复位、明确零输出、驱动超时的证据。
6. **周期**：某控制入口配置100 Hz，能否声称每10 ms稳定执行？提示：要分配置、调度、执行耗时、测量周期与数据年龄。
