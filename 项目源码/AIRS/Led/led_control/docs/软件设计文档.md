# 机器人LED灯带控制系统 - 软件设计文档

## 1. 系统概述

本系统实现机器人多部位LED灯带的控制，包括：
- **STM32端**：基于STM32F103C8T6控制4路LED灯带（胸口、左臂、右臂、底盘）
- **ROS端**：通过串口接收ROS指令，控制灯带效果
- **硬件接口**：2个PWM+DMA通道驱动WS2812/WS2815灯带

### 1.1 硬件配置

| 区域 | LED数量 | PWM通道 | 灯珠型号 | 数据格式 |
|------|---------|---------|----------|----------|
| 胸口 | 24 | TIM1_CH2 | WS2815 | GRB |
| 左臂 | 11 | TIM1_CH2 | WS2812 | RGB |
| 右臂 | 11 | TIM1_CH2 | WS2812 | RGB |
| 底盘 | 24 | TIM3_CH1 | WS2812 | RGB |

**通道分配**：
- **PWM通道1**（TIM1_CH2）：串联控制胸口+左臂+右臂（共46个LED）
- **PWM通道2**（TIM3_CH1）：独立控制底盘（24个LED）

## 2. WS2812/WS2815控制原理

### 2.1 时序协议

WS2812/WS2815采用单线控制，通过PWM占空比编码0和1：

| 码型 | 高电平时间 | 低电平时间 | PWM占空比（72MHz@90） |
|------|------------|------------|----------------------|
| **0码** | 0.4μs | 0.85μs | 28/90 (31%) |
| **1码** | 0.85μs | 0.4μs | 61/90 (68%) |
| **复位** | >50μs低电平 | - | 连续输出0 |

### 2.2 数据格式

每个LED需要24位数据（3字节）：
- **WS2815**：GRB顺序（胸口灯带）
- **WS2812**：RGB顺序（手臂和底盘灯带）

**示例**：设置第一个LED为红色(255,0,0)
- WS2815格式: `G[0] R[255] B[0]` → 24位PWM波形
- WS2812格式: `R[255] G[0] B[0]` → 24位PWM波形

### 2.3 PWM+DMA实现原理

```
STM32定时器 → 产生72MHz PWM基准波形
     ↓
DMA传输 → 动态修改PWM占空比（28或61）
     ↓
GPIO输出 → 生成WS2812协议时序
```

**关键配置**：
- **定时器频率**：72MHz / 90 = 800kHz（WS2812标准频率）
- **DMA模式**：Memory-to-Peripheral，循环传输
- **缓冲区设计**：`[50个0] + [LED数据] + [50个0]`
  - 前50个0：稳定PWM输出
  - LED数据：实际颜色PWM编码
  - 后50个0：复位信号（>50μs低电平）

### 3.2 BSP层 (bsp_led.c/h)

**核心功能**：PWM+DMA底层驱动

#### 3.2.1 缓冲区设计

```c
// 身体区域缓冲区（胸口+左臂+右臂）
typedef struct {
    uint8_t StartData[50];                    // PWM稳定区
    uint8_t ColorData[46 * 24];              // 46个LED * 24位
    uint8_t EndData[50];                      // 复位信号
} BodyBufferStruct_t;                         // 总计: 1204字节

// 底盘区域缓冲区
typedef struct {
    uint8_t StartData[50];                    // PWM稳定区
    uint8_t ColorData[24 * 24];              // 24个LED * 24位
    uint8_t EndData[50];                      // 复位信号
} ChassisBufferStruct_t;                      // 总计: 676字节
```

#### 3.2.2 核心函数

**1. BSP_LED_Init()**
```c
void BSP_LED_Init(void)
```
- 初始化DMA缓冲区
- 清空所有LED颜色缓存
- 设置起始/结束数据为0

**2. BSP_LED_SetPixel()**
```c
void BSP_LED_SetPixel(LedRegion_t region, uint16_t index, uint8_t r, uint8_t g, uint8_t b)
```
- 设置指定区域的单个LED颜色
- 自动处理GRB/RGB格式转换
- 更新DMA缓冲区和逻辑缓存

**实现细节**：
```c
// 核心编码逻辑
for(int j = 0; j < 8; j++) {
    buffer[offset + j] = (data[0] & (0x80 >> j)) ? WS2812_PWM_BIT_1 : WS2812_PWM_BIT_0;
}
```

**3. BSP_LED_Show()**
```c
void BSP_LED_Show(void)
```
- 启动PWM+DMA传输
- 同时输出两路灯带数据
- 传输完成后停止DMA

**流程**：
```
停止DMA → 延迟1ms → 启动PWM+DMA → 等待传输(3ms) → 停止DMA
```

### 3.3 效果层 (app_led_effect.c/h)

**核心功能**：实现预制灯效算法

#### 3.3.1 效果类型

| 效果ID | 效果名称 | 参数 | 说明 |
|--------|----------|------|------|
| 0x00 | OFF | - | 关闭灯带 |
| 0x01 | SOLID | color | 常亮指定颜色 |
| 0x02 | BREATHING | color, speed | 呼吸灯（正弦波调光）|
| 0x03 | FLOWING | color, speed | 流水灯（单点移动）|
| 0x04 | MARQUEE | color, speed | 跑马灯（分组移动）|
| 0x05 | RAINBOW | speed | 彩虹渐变（HSV色轮）|
| 0x06 | CUSTOM | - | 自定义模式（ROS直接控制）|

#### 3.3.2 核心数据结构

```c
typedef struct {
    EffectMode_t mode;      // 效果模式
    RGB_Color_t color;      // 基础颜色
    uint8_t speed;          // 速度参数(0-100)
    uint32_t tick;          // 内部计数器
    uint8_t step;           // 状态步进
} RegionEffect_t;

RegionEffect_t EffectStates[4];  // 4个区域独立控制
```

#### 3.3.3 效果算法实现

**1. 呼吸灯 (BREATHING)**
```c
float angle = tick * (0.02f + speed * 0.08f / 100.0f);
uint8_t brightness = (sin(angle) + 1.0f) * 127.0f;
color_out = (color_base * brightness) >> 8;
```
- 速度映射：0-100 → 0.02-0.1 (正弦频率系数)

**2. 流水灯 (FLOWING)**
```c
uint16_t speed_factor = 10 - (speed * 9 / 100);    // 速度0-100 → 间隔10-1
uint16_t pos = (tick / speed_factor) % led_count;  // 当前亮灯位置
```

**3. 跑马灯 (MARQUEE)**
```c
uint8_t group_size = 5;     // 连续亮5个LED
uint8_t gap_size = 1;       // 间隔1个LED
uint16_t offset = (tick / speed_factor) % led_count;
```

**4. 彩虹效果 (RAINBOW)**
```c
uint8_t speed_factor = 1 + (speed * 9 / 100);      // 速度0-100 → 1-10
uint8_t hue_start = (tick * speed_factor) & 0xFF;  // HSV色相偏移
// 每个LED色相均匀分布：hue[i] = hue_start + i * 255 / led_count
```

#### 3.3.4 主循环处理

```c
void App_LED_Effect_Process(void)  // 每10ms调用一次
```
- 遍历4个区域
- 更新tick计数器
- 根据模式执行对应算法
- CUSTOM模式不处理（由ROS直接控制）

### 3.4 通信层 (app_comm.c/h)

**核心功能**：解析ROS串口协议

#### 3.4.1 协议格式

```
[帧头1][帧头2] [命令]  [长度][数据...] [校验和]
 0xAA   0x55   CMD    LEN   DATA      CS
```

**校验和计算**：`CS = (CMD + LEN + SUM(DATA)) & 0xFF`

#### 3.4.2 命令类型

**1. CMD_SET_EFFECT (0x01)** - 设置效果（无颜色）
```
数据格式: [区域ID][效果ID][速度]
长度: 3字节
示例: AA 55 01 03 00 02 32 37  (胸口呼吸灯,速度50)
```

**2. CMD_SET_EFFECT_COLOR (0x03)** - 设置效果（带颜色）
```
数据格式: [区域ID][效果ID][速度][R][G][B]
长度: 6字节
示例: AA 55 03 06 01 03 50 FF 00 00 5C  (左臂流水灯,速度80,红色)
```

**3. CMD_SET_COLOR (0x02)** - 自定义颜色数组
```
数据格式: [区域ID][起始索引][LED数量][R,G,B,R,G,B...]
长度: 3 + count*3 字节
示例: AA 55 02 09 00 00 03 FF 00 00 00 FF 00 00 00 FF 08
      (胸口从索引0开始设置3个LED: 红、绿、蓝)
```

#### 3.4.3 状态机实现

```c
typedef enum {
    STATE_WAIT_HEADER_1,   // 等待0xAA
    STATE_WAIT_HEADER_2,   // 等待0x55
    STATE_WAIT_CMD,        // 接收命令
    STATE_WAIT_LEN,        // 接收长度
    STATE_WAIT_DATA,       // 接收数据
    STATE_WAIT_CS          // 验证校验和
} CommState_t;
```

**中断接收处理**：
```c
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart) {
    App_Comm_RxHandler(rx_byte);  // 状态机驱动
    HAL_UART_Receive_IT(&huart1, &rx_byte, 1);  // 重新启动接收
}
```

### 3.5 主程序流程 (main.c)

```c
int main(void) {
    // 1. 硬件初始化
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    MX_DMA_Init();
    MX_TIM3_Init();
    MX_USART1_UART_Init();
    MX_CAN_Init();
    MX_TIM1_Init();
    
    // 2. 模块初始化
    BSP_LED_Init();           // LED驱动
    App_LED_Effect_Init();    // 效果模块
    
    // 3. 启动串口接收中断
    HAL_UART_Receive_IT(&huart1, &rx_temp, 1);
    
    // 4. 主循环
    while (1) {
        if (HAL_GetTick() - last_tick >= 10) {  // 10ms周期
            last_tick = HAL_GetTick();
            App_LED_Effect_Process();  // 更新效果
        }
    }
}
```

## 4. ROS端软件架构

### 4.1 节点设计 (led_driver_node.py)

**核心功能**：ROS话题 → 串口协议转换

#### 4.1.1 话题接口

**订阅话题**：`/robot_led/command` (std_msgs/String)

**消息格式（JSON）**：
```json
// 预设效果（无颜色）
{
    "region": "chest",
    "effect": "breathing",
    "speed": 50
}

// 预设效果（带颜色）
{
    "region": "left_arm",
    "effect": "flowing",
    "speed": 80,
    "color": [255, 0, 0]
}

// 自定义颜色
{
    "region": "chassis",
    "effect": "custom",
    "start_index": 0,
    "rgb_data": [255,0,0, 0,255,0, 0,0,255]
}
```

#### 4.1.2 区域映射

| ROS字符串 | STM32代码 | 说明 |
|-----------|-----------|------|
| "chest" | 0x00 | 胸口(24 LEDs) |
| "left_arm" | 0x01 | 左臂(11 LEDs) |
| "right_arm" | 0x02 | 右臂(11 LEDs) |
| "chassis" | 0x03 | 底盘(24 LEDs) |
| "all" | 0xFF | 所有区域 |

#### 4.1.3 效果映射

| ROS字符串 | STM32效果ID | 说明 |
|-----------|-------------|------|
| "off" | 0x00 | 关闭 |
| "solid" | 0x01 | 常亮 |
| "breathing" | 0x02 | 呼吸灯 |
| "flowing" | 0x03 | 流水灯 |
| "marquee" | 0x04 | 跑马灯 |
| "rainbow" | 0x05 | 彩虹 |
| "custom" | 0x06 | 自定义 |

#### 4.1.4 手臂同步功能

配置参数：`sync_arms: true`（默认启用）

**功能**：当设置左臂效果时，自动将相同效果应用到右臂

**实现逻辑**：
```python
if self.sync_arms and region_str == "left_arm" and success:
    self.sync_right_arm(cmd_data, region_str)
```

**应用场景**：机器人对称动作时保持双臂灯效同步

## 5. 通信协议详解

### 5.1 协议示例

**示例1：设置胸口呼吸灯（速度50，红色）**
```
发送: AA 55 03 06 00 02 32 FF 00 00 91
解析:
  AA 55     - 帧头
  03        - CMD_SET_EFFECT_COLOR
  06        - 数据长度6字节
  00        - 区域: 胸口
  02        - 效果: 呼吸灯
  32        - 速度: 50 (十进制)
  FF 00 00  - 颜色: R=255, G=0, B=0
  91        - 校验和: (03+06+00+02+32+FF+00+00)&0xFF
```

**示例2：设置底盘自定义颜色（前3个LED：红、绿、蓝）**

```
发送: AA 55 02 09 03 00 03 FF 00 00 00 FF 00 00 00 FF 0E
解析:
  AA 55     - 帧头
  02        - CMD_SET_COLOR
  09        - 数据长度9字节
  03        - 区域: 底盘
  00        - 起始索引: 0
  03        - LED数量: 3
  FF 00 00  - LED0: 红色
  00 FF 00  - LED1: 绿色
  00 00 FF  - LED2: 蓝色
  0E        - 校验和
```

### 5.2 错误处理

**STM32端**：

- 校验和错误：丢弃数据包，状态机复位
- 数据越界：函数内部边界检查，防止数组溢出

**ROS端**：
- 串口断开：捕获异常，记录日志
- JSON解析失败：记录警告，忽略该命令
- 参数范围检查：速度限制在0-100

### 6.3 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| LED不亮 | PWM未启动 | 检查`BSP_LED_Show()`调用 |
| 颜色错误 | GRB/RGB格式混淆 | 确认灯带型号和格式配置 |
| 闪烁 | DMA缓冲区错误 | 检查缓冲区大小计算 |
| 串口无响应 | 波特率不匹配 | 确认115200配置 |
| 效果不流畅 | 主循环阻塞 | 减少延迟函数使用 |
