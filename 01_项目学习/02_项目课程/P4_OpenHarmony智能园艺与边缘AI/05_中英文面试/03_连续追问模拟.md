# P4 连续追问模拟

训练方式：先不看答案口述，再看下面参考。每轮约10分钟，记录哪一步从理解变成背词。

**初学者练法：**第一遍只用中文讲清楚因果，不要求马上说出所有术语；卡住时停下来画对象、箭头和信号单位。第二遍再回答英文追问。先区分传感器读数、模型识别、服务建议、设备命令和设备回报。英文答案不能把建议说成执行，也不能把置信度说成整体准确率。先用[项目白话总览](../00_项目全貌与学习路线/03_P4端到端数据与执行链.md)把主线复述一遍。

## Round 1

**Interviewer:** Why split local control from server-side decisions?

**Candidate:** Local control handles immediate irrigation and manual operation. The server handles visual observations, richer decisions and user interaction. Basic actuator behavior should have a defined local policy during network loss.

**Interviewer, deeper:** Which behavior is actually implemented during disconnection?

**回答依据：** 本地处理及时灌溉和人工开关，服务器处理视觉、解释、界面；断网不能让最基本执行逻辑依赖LLM。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 2

**Interviewer:** What is hysteresis in irrigation control?

**Candidate:** Different start and stop thresholds prevent rapid switching near one boundary. Between the thresholds, the previous pump state is retained. The source values are configuration values, not universal soil thresholds.

**Interviewer, deeper:** What happens at exactly the threshold?

**回答依据：** 低于启动阈值开，高于停止阈值关，中间保持之前状态；源码56/65配置不等于所有土壤通用阈值。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 3

**Interviewer:** How should manual control interact with automatic watering?

**Candidate:** Manual operation needs an explicit mode and priority policy. A command called off does not necessarily mean automatic watering remains disabled; I would trace the actual transition and subsequent control cycle.

**Interviewer, deeper:** How would you represent a persistent manual stop?

**回答依据：** 显式模式与优先级，manual_off可即时覆盖；源码某些语音off会回自动，随后低湿度可重开，要读实际状态转换。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 4

**Interviewer:** How does INT8 quantization approximate floating-point values?

**Candidate:** A scale and zero point map real values to bounded integers. Dequantization reconstructs an approximation, with rounding and clipping error.

**Interviewer, deeper:** Why can outliers make calibration difficult?

**回答依据：** q≈round(x/scale)+zero_point并夹范围，反量化scale(q-zero_point)；范围和步长带舍入/截断误差。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 5

**Interviewer:** How is model deployment different from training?

**Candidate:** Training optimizes weights using data and an objective. Deployment converts and integrates a model for inference. An existing ONNX file is not evidence that I trained it.

**Interviewer, deeper:** What training records would support such a claim?

**回答依据：** 训练优化权重需数据标签损失和验证；部署做转换集成推理。仅best.onnx存在不能证明本人训练过程。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 6

**Interviewer:** Why does TCP framing need a length prefix?

**Candidate:** TCP delivers a byte stream rather than application messages. A length prefix allows the receiver to reconstruct frames despite partial or combined reads, provided size and byte-order checks are defined.

**Interviewer, deeper:** Can a single recv call return a complete frame reliably?

**回答依据：** TCP字节流可能分包粘包，没有消息边界；逐长度读足数据并限定大小，协议端序和分段顺序一致。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 7

**Interviewer:** Why include a rule-based fast path?

**Candidate:** Deterministic rules can handle clear conditions predictably, while richer cases use model-assisted reasoning. Fallback rules provide a defined path when model processing fails.

**Interviewer, deeper:** How would you resolve contradictory rules?

**回答依据：** 已明确低风险条件用确定规则直接处理，复杂语义再模型，失败回规则；需规则冲突和优先级明确。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 8

**Interviewer:** Should an agent proposal directly control hardware?

**Candidate:** An agent proposal should pass execution-policy checks for capability, authority, bounds, freshness and current mode. A command whitelist is useful but insufficient by itself.

**Interviewer, deeper:** What if the proposal conflicts with a manual stop?

**回答依据：** 建议进入执行策略校验能力、权限、范围、新鲜度、人工模式；白名单只是其中一项，不能跳过本地状态。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 9

**Interviewer:** Is an execution summary a hardware acknowledgement?

**Candidate:** A server summary shows a decision or dispatch, not necessarily physical execution. Confirmation needs a correlated device acknowledgement and, ideally, measured actuator feedback.

**Interviewer, deeper:** Can an acknowledged command still fail physically?

**回答依据：** 服务器选择或广播命令不证明GPIO/泵动作；需要设备确认、关联ID和实际反馈；当前摘要不能直接当完成。 追问需要回模型、源调用或实验条件；不要自动添加个人性能数字。

## Round 10

**Interviewer:** How would you verify that a remote watering command reaches the device correctly?

**Candidate:** I would trace the command schema on both sides, including the action name, duration, mode and message framing. In the reviewed snapshot, the server uses `start/stop`, while the Hi3861 parser checks strings such as `water_on/water_off`. I did not find an adapter in that path, so I would treat it as an integration risk and verify it with a protocol test and device logs.

**Interviewer, deeper:** Does this static mismatch prove that remote watering fails at runtime?

**回答依据：** 静态阅读能指出两边命令名称不一致、需要核对适配；不能排除未纳入快照的外部转换层，因此不能把风险说成已实测失败。

## Round 11

**Interviewer:** The model runs at 30 FPS. Is the system response time about 33 milliseconds?

**Candidate:** Not necessarily. Thirty FPS describes throughput under a defined measurement interval. A frame may still wait in the camera, network or agent queue. I would measure from capture time to the device response and report each stage, including the percentile latency and dropped-event count.

**Interviewer, deeper:** Why can a queue make a fast model appear slow to a user?

**回答依据：** 队列装的是等待处理的旧事件；单帧推理快不代表等待时间短。需要测数据年龄和排队时长，而不只看模型计时。

## Round 12

**Interviewer:** What is the difference between event deduplication and an idempotent actuator command?

**Candidate:** Event deduplication prevents the same observation from entering the decision workflow repeatedly. Idempotency makes repeating the same command safe at the actuator boundary. Neither alone proves exactly-once physical execution; the protocol also needs command IDs, device state and acknowledgement semantics.

**Interviewer, deeper:** What if a reply is lost after the pump has already started?

**回答依据：** 不能只按“没收到回复”就盲目再执行。需要用命令ID查询设备状态或设计可安全重复的命令，并记录恢复过程。

## Contribution challenge

**Interviewer:** Which part did you personally implement, and what evidence supports that?

**Candidate template:** My own contribution was [verified module and decision]. The available source supports [specific function or interface]. A separate teaching experiment helps me understand the principle, but I do not use it as evidence of historical deployment.

## Evidence challenge

**Interviewer:** Did the available version actually run on the robot?

**Candidate:** The source snapshot and the deployed version must be matched using a commit, configuration and execution record. I would distinguish what I can trace in this snapshot from what I can substantiate with my own project records.

## 复盘答案标准

每问记录：公式/单位是否正确，能否指出函数，个人动作是否明确，验证是否有数据，限制是否诚实，英文是否可理解。不会则明确不知道的部分并解释已知部分。下次优先补一项，不改写成“已掌握”。
