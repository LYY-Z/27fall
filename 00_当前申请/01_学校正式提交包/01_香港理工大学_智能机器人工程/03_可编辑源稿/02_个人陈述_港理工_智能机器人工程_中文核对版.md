# 个人陈述（中文版）— 香港理工大学 智能机器人工程理学硕士

过去两年里，我先后参与了三类需要在真实硬件上验证控制效果的机器人：一台 RoboMaster 英雄机器人，我负责闭合它的云台、发射机构与底盘控制回路；一台轮腿机器人，在腿长变化的过程中保持直立；一台三全向轮球形机器人，在双臂于其上运动时保持平衡。这些项目让我得出一个清晰结论：我能够实现控制器并让它运行，但现在需要比计算机专业通常要求的更严格地理解它为什么有效，以及如何系统地进行设计。这就是我申请智能机器人工程理学硕士的原因。

我在深圳技术大学攻读计算机科学与技术（专业排名 6/156），打下了扎实的编程与算法基础。随着机器人项目对控制理论提出越来越高的要求，我进一步修读了《自动控制原理》和《现代控制理论》。随后，在深圳市人工智能与机器人研究院（AIRS）实习期间，我将这些理论基础系统地应用于真实的机器人平衡控制问题，负责一台带双臂上肢的球形机器人的平衡控制。我先设计并在实机上部署了级联 PID 控制器，然后把系统建模为四状态倒立摆，用 LQR 分析各状态权重在稳定性与控制量之间的权衡。这个模型解释了单靠手工整定无法解释的调参现象和执行器饱和。用 URDF/Pinocchio 估计双臂带来的质心偏移并作为重力前馈接入，让我切身体会到上肢运动与底盘平衡耦合得多么紧密。我还把 ROS 状态处理与 CAN 电机执行集成起来，并加入了状态初始化、输出限幅与跌倒保护，使这个回路可以在实机上反复测试而不损坏机器人。最终，底盘在双臂沿固定轨迹运动时持续保持了动态平衡。

在此基础上，我又在两个实验室项目中将这种以控制为核心的方法从平衡延伸到运动与导航。在可变腿长轮腿机器人上，我实现了腿长调度的 LQR 与基于闭链腿部运动学的虚拟模型控制，并在 STM32H7/FDCAN 平台上完成实车整定。在车式移动机器人上，我搭建了从 EKF/AMCL 定位、Hybrid-A* 与 TEB 规划到 MPC 跟踪的完整链路，并在实车上跑通。之后在未来动力与开鸿的实习，又把我的经验向两个方向延伸：双臂机器人的 VR 遥操作，用约束逆运动学让双臂跟随操作者、并抑制奇异位形附近的速度放大；以及 OpenHarmony 上的多机器人平台软件。

这些经历与项目的核心课程直接对应。Advanced Control Technology 与 Robot Motion Planning 正是我有实践结果、却缺理论深度的两个领域；Principles of Robotic Mechanisms 会帮助我把只为一台机器人实现过的闭链运动学，放到更广泛的机械系统框架下理解；Embodied Robot Intelligence 则与我在 OpenHarmony 园艺系统中构建的 Agent 决策链、以及正在开鸿构建的安全门控执行链相连。我打算选择 dissertation 路线，用它完成一份关于平衡或导航控制的、有完整文档的研究，这是我至今还没有机会开展的一类系统性研究。Autonomous Vehicles 与 Computer Vision and Image Processing 两门选修课与我的导航和感知经验相合。

我的目标是在粤港澳大湾区成为一名机器人算法工程师，专注移动与足式平台的运动控制与导航，并逐步能够主导一款机器人产品的算法部分。一个设在机械工程系内、面向机器人系统的项目，能够补足我在机构与传感方面的训练，并与我在深圳积累的机器人产业经历形成直接衔接，是我通向这一目标最直接的下一步。这些经历让我积累了动手的硬件经验，也形成了把完整系统推进到验证阶段的工作习惯，并清楚认识到自己仍需补足的理论基础。
