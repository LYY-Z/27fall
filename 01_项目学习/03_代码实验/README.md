# 代码实验总览

独立教学代码不连接机器人，帮助把公式变成可阅读、可运行的程序。当前全部未运行核对，C++未编译；原项目运行另需版本、ROS/SDK和硬件条件。

## 学习顺序

1. [环境与运行](00_环境与运行/README.md)：先选择解释器和依赖。
2. [基础实验](01_基础实验/README.md)：矩阵、几何、估计、控制和通信。
3. [项目实验](02_项目实验/README.md)：每项目独立解释结构和代码。
4. [综合闭环](03_综合闭环/README.md)：位置估计、PD反馈、限幅和故意错误的延迟观测。
5. [实验记录](../05_实验与学习记录/README.md)：保存实际命令、原始CSV与解释。

完整脚本登记在[labs.csv](../00_总导航/数据/labs.csv)，未运行不计作成功。README给PowerShell/Bash命令，中文与空格路径均需引用。只读源码与真正启动硬件是不同层级。

## 逐函数阅读与当前授权

全部37份程序对应20份[逐函数阅读指南](../00_总导航/13_深化阅读与程序讲解索引.md)，先看参数/单位/矩阵形状和手算，再看函数体。用户明确要求暂不运行验证：本轮未运行/导入教学程序或测试，未编译C++，未安装依赖。C++17队列示例和设备异步所有权示例均为普通电脑Mock，不调用原机。
