# 香港中文大学机器人学申请材料说明

本文件夹按香港中文大学研究生申请系统的上传栏目整理。申请人上传材料与推荐人提交材料已分开，中文文件仅用于个人核对，不作为英文申请材料上传。

当前本科在读，没有 Graduate Certificate，因此不上传该项；没有香港身份证，也不上传 HKID Card。

## 推荐信

推荐信不在本页由申请人代替推荐人上传。缴纳申请费后，进入：

`Your Application List → View Options → My Referee(s)`

填写两位推荐人的真实信息，系统会向推荐人发送在线推荐信链接。英文推荐信 PDF 已放在 `推荐人提交材料` 文件夹，供推荐人核对、参考或按系统要求提交。

## CUHKAF 授权表填写与签名

`CUHKAF.pdf` 是港中文的空白授权表。它授权港中文核验申请人的教育背景，必须由申请人本人签名，不是推荐人签名。

请在 `申请人上传材料/授权表/LaiYongyi_AuthorizationForm.pdf` 中填写：

| 栏目 | 填写内容 |
|---|---|
| Signature | 申请人本人手写签名，可使用平时使用的中文或英文签名 |
| English Name | `LAI, YONGYI` |
| Date of Birth | `03 April 2005` |
| CUHK Application Number | 提交港中文申请后系统生成的申请编号；尚未生成前不要自行编造 |
| ID Number | `ER9566835` |
| Date | 实际签署日期；若于 2026 年 9 月 24 日签署，可填 `24 September 2026` |

填写申请编号后再签名和写日期，保存为 PDF 上传。签名应清晰、完整，不要只输入电脑字体姓名代替签名。

## 上传前检查

- 授权表必须已经填写、签名并写日期。
- 文件名使用英文、数字和下划线，避免中文、空格和特殊符号。
- 护照、身份证、IELTS 和证书文件应清晰可读，并符合系统的单文件大小限制。
- 推荐人信息提交后不要随意更换邮箱；港中文会将在线推荐信链接发送到填写的邮箱。

## 文件名与上传顺序

申请系统上传时优先使用上表中的英文文件名。`ID Card/Passport` 栏目先上传 `LaiYongyi_Passport.pdf`，如系统允许多文件，再上传 `LaiYongyi_IDCard.pdf`。如果系统只允许一个文件，应先确认系统是否要求将护照和身份证合并；不要在未确认的情况下覆盖护照文件。

推荐人提交材料中的英文推荐信为：

- `推荐人提交材料/学术推荐信/LaiYongyi_AcademicRecommendation_CUHK_Robotics_EN.pdf`
- `推荐人提交材料/企业推荐信/LaiYongyi_AIRSRecommendation_CUHK_Robotics_EN.pdf`

英文个人陈述与两封已签字英文推荐信已合并为 `申请人上传材料/其他材料/LaiYongyi_PS_RecommendationLetters.pdf`，第一页为正式目录说明，后续材料按个人陈述、学术推荐信、AIRS 企业推荐信的顺序排列。该文件用于在港中文系统的 `Uploaded Documents → Others` 栏目中补充上传；不建议将推荐信放入 `Other Certificates`。该补充上传不替代系统要求的推荐人在线提交流程；如系统后续要求通过推荐人链接提交，仍应按系统通知完成。

中文推荐信放在 `中文核对材料` 中，仅供本人和推荐人核对，不作为申请人上传的英文材料。
