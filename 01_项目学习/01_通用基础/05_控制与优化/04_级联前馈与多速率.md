# 04 级联前馈与多速率

先修：[03_限幅抗饱和微分与角度误差](03_限幅抗饱和微分与角度误差.md)。项目：P1、P2、P3、P7。目标：能按单位和周期算一轮控制，解释反馈的作用与限制。

## 1. 外环输出一个内环懂的目标

位置目标p*→位置误差→速度参考v*→速度误差→加速度/姿态参考→快速执行器/姿态环。外环负责慢目标，内环负责快动态。平衡机器人位置误差不能直接跳过姿态稳定把轮子猛加速，否则身体可能先倒。

P1可用位置/速度外环给有界roll/pitch参考，姿态/角速内环输出球/轮控制量。普通轮式机器人可以位置→速度→力矩，不需要虚构所有机器人都有姿态中间环。

## 2. 完整手算一轮

教学水平车p*=1,p=.2m，位置增益kp_pos=.5/s，v*=.5×.8=.4m/s。若v上限.3，给内环参考.3。当前v=.1，速度误差.2，速度增益kp_vel=2/s，a*=.4m/s²。dt=.1，v_next=.14，位置按恒加速增加.01+.002=.012m，p_next=.212。

下一轮外环根据新的p重新算，内环根据新v跟踪。速度参考不是实际速度；外环计算出来不说明内环已经做到。

## 3. 内环“快”不只是运行频率高

外环改变参考的速度，应慢于内环跟踪和稳定的能力。内环1000Hz执行但电机动态/滤波只能慢慢变化，外环仍需降低带宽。频率提高有助数字控制近似，不替代模型/带宽判断。

多速率例：内环dt=.01s，外环每5步即.05s更新，期间保持速度参考。每环积分用自己的实际周期，而不是外环每50ms却用10ms积分。共享状态读一次一致快照，参考变化限幅。

## 4. 前馈与反馈怎样合在一起

已知负载需支撑mg，可先给mg前馈，反馈补高度误差；已知轨迹加速度a_ref，可给ma_ref。前馈来自目标/模型，反馈来自误差，滤波减少测量波动，限幅表达能力，职责不同。

P1手臂固定轨迹造成质心变化，CoM前馈可提前补倾斜作用；反馈处理模型误差。P2leader重力补偿用g(q)，follower跟踪位置/速度。前馈估计错也可能放大扰动，要分别比较有/无前馈。

## 5. 失败、实验与英文

[级联实验](../../03_代码实验/01_基础实验/08_PID抗饱和与级联/README.md)用水平位置速度模型，增加延迟观察。失败：外环目标过快/超内环能力；多个积分环windup互相影响；旧数据跨环；内环尚未稳定就接外环。

“The outer loop generates a bounded reference for a faster inner loop. I first establish the inner loop's tracking ability, then choose the outer-loop bandwidth and reference limits accordingly.”

追问：Can a faster task frequency alone make the inner loop fast enough? No. The closed-loop plant response is what matters.

1. 概念：外环直接电机命令行吗？答：需按设计经过对应内环与接口，不能擅自绕过。
2. 计算：dt=.01外环5步，更新频率？答：20Hz，内环100Hz；只是教学设定。
3. 代码：外环每5步积分dt填什么？答：其实际更新间隔约.05s。
4. 解释：加CoM前馈后不能说稳多少？答：需同条件曲线/指标，无日志不填提升比例。

## 精读补充：把中间步骤讲清楚

### A. 外环并没有替内环执行

机器人离目标.8m，外环请求.4m/s，限成.3m/s；当前速度只有.1m/s。内环面对的是.2m/s速度误差，它必须依靠执行器逐步加速。下一次传感器真的测到.14m/s后，误差才变.16，不能在程序中把参考.3直接写进“当前速度”。

平衡机器人还要身体倾斜才能水平加速。位置环要求往前，速度环可能给小倾角，姿态环用轮端动作控制该倾角；姿态目标不是永远0，而是有界、可跟踪的参考。过快的参考可能让身体没有足够时间恢复。

### B. 外环每五次运行，状态与dt怎么办

内环读一致快照并每.01s更新，外环每.05s算新参考，其余四次保持。外环不能把每次累计的位置误差又重复积分五次，也不能把旧传感器消息当五条新独立信息。运行频率和实际闭环响应分别记录。
