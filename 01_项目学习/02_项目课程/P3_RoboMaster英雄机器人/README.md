# P3 RoboMaster 英雄机器人：多任务、多闭环怎样一起工作

## 先看机器人正在做什么

机器人一边让云台指向目标，一边让摩擦轮/拨盘完成发射，还要让麦克纳姆轮底盘移动。它们用到不同的反馈和控制输出，但共享 MCU、任务调度、电源和 CAN 通信资源。

```mermaid
flowchart LR
  R[遥控/视觉目标/模式] --> G[云台角度环 → 角速度环]
  I[IMU姿态与陀螺] --> G
  GM[云台电机反馈] --> G
  R --> L[发射状态与目标]
  LF[摩擦轮/拨盘反馈] --> L
  L --> CAN[CAN电机命令]
  R --> C[底盘速度目标]
  CF[四轮编码器与裁判功率] --> C
  C --> P[麦轮分配/功率缩放/轮速环]
  P --> CAN
  CAN --> GM
  CAN --> LF
  CAN --> CF
  T[FreeRTOS任务与中断] -.调度和时间影响.-> G
  T -.-> L
  T -.-> P
```
