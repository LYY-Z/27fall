# 实机实验与安全模板

实机实验的第一优先级是可控地停止机器人。任何控制算法都必须先通过“断使能、限幅、急停和人工观察”检查。

## 1. 实验前

- 确认机械结构、螺丝、线缆、电池和急停；
- 抬起轮子或使用支撑架完成方向、零位和低功率检查；
- 设置最大速度、角度、力矩、电流和加速度限制；
- 确认传感器时间戳、坐标轴、单位和数据频率；
- 确认控制器启动时积分器和旧命令已清空；
- 明确谁负责观察，谁负责操作，谁负责按急停；
- 预先写好触发停车的条件。

## 2. 实验中

每次只打开一个新模块，并保留上一版基线。实时观察：

| 观察项 | 异常表现 | 立即动作 |
|---|---|---|
| 姿态 | 角度快速发散、抖动变大 | 降低输出或急停 |
| 电机 | 异响、过热、持续饱和 | 断使能 |
| 通信 | 反馈超时、序号不连续 | 进入安全状态 |
| 轨迹 | 目标跳变、实际偏离 | 停止并查时间对齐 |
| 电源 | 电压下降、功率超限 | 降载或停止 |

## 3. 实验后

保存：

- 软件版本、参数和硬件配置；
- 原始日志，不只保存截图；
- 控制参考、传感器、执行器反馈和安全状态；
- 触发时间、停车原因和恢复步骤；
- 本次唯一改变的因素。

## 4. 停车条件

以下任一项成立都应停车：

- 状态数据过期或出现 NaN；
- 姿态超过预设安全范围；
- 反馈停止、错误码持续或通信恢复不稳定；
- 输出长期饱和；
- 机器人出现不可预测运动；
- 人员进入危险区域。

恢复不能直接重放旧命令。应清空旧目标，重新确认状态，再由小参考逐步增加。
