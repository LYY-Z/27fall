# P4 OpenHarmony 智能园艺与边缘 AI：传感器、视觉与设备动作

## 先把系统分成三条会交换信息的线

P4 同时有本地灌溉、边缘视觉和服务器服务。Hi3861 可以根据本地湿度和人工模式控制水泵；RK3588 负责采集图像、运行病害检测并发送结果；Python 服务处理事件、规则/Agent建议和 Web 交互。设备采样、模型推理、服务处理和网页显示各有自己的时间。

```mermaid
flowchart LR
  subgraph Edge[Hi3861 本地灌溉]
    S[湿度 ADC + 人工模式] --> H[滤波/滞回/安全判断]
    H --> P[GPIO 水泵]
    P --> S
  end
  subgraph Vision[RK3588 视觉]
    C[相机/V4L2缓冲区] --> I[预处理与YOLO/RKNN推理]
    I --> E[带置信度/时间的事件]
  end
  subgraph Service[Python 服务]
    E --> D[事件筛选与状态存储]
    D --> G[规则 / LangGraph / Web]
    G --> Q[受策略检查的命令请求]
  end
  Q -.协议名称映射需核对.-> H
```
