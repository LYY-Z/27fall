# 第一部分：发射逻辑

## 一、发射机构的两个部件

发射机构不是单一执行器，它由两部分组成：

| 部件 | 作用 | 控制目标 | 反馈 |
|---|---|---|---|
| 摩擦轮 | 高速旋转，靠表面摩擦把弹丸带出去 | 保持目标转速 RPM | 电机 RPM、电流 |
| 拨盘 | 转动弹仓，把弹丸送到发射位置 | 转到目标角度、完成送弹 | 累计编码器角、速度、电流 |

这两个部件**控制问题不同**：

- 摩擦轮：主要控制**转速**，弹丸撞击后会掉速，需要恢复。
- 拨盘：主要控制**位置和送弹状态**，要转到确定角度，还要判断是否堵住。

不能把它们当成同一个控制器。

---

## 二、发射状态机

### 2.1 状态枚举

| 状态 | 含义 | 动作 |
|---|---|---|
| READY | 准备发射 | 摩擦轮达到目标转速，等待发射指令 |
| SINGLE | 单发 | 拨盘转一个角度，送出一颗弹 |
| BLOCK | 堵转 | 拨盘卡住，需要处理 |
| BACK | 退弹 | 反向转，退出卡住的弹 |
| FAIL | 失败 | 多次尝试仍失败，停止 |
| RELAX | 放松 | 所有电流归零，重置累计角参考 |

### 2.2 状态转移表

| 当前状态 | 事件 | 下一状态 | 动作 |
|---|---|---|---|
| RELAX | 收到使能 | READY | 摩擦轮加速 |
| READY | Fire_ON | SINGLE | 设置拨盘目标角 |
| SINGLE | 到达目标角 | READY | 完成送弹 |
| SINGLE | 角差>阈值且超时 | BLOCK | 拨盘停止 |
| BLOCK | 自动处理 | BACK | 反向退弹 |
| BACK | 到达退弹角 | READY | 退弹成功 |
| BACK | 再次超时 | BLOCK 或 FAIL | 重试或放弃 |
| 任意 | RELAX 指令 | RELAX | 所有电流归零 |
| 任意 | 多次失败 | FAIL | 停止，等待人工 |

## 三、Fire_ON 和 Fire_OFF

### 3.1 Fire_ON

```text
Fire_ON:
  设置三个摩擦轮正负目标 RPM
  用裁判弹速变化调整 fire_speed
  拨盘状态从 READY 进入 SINGLE
```

- 三个摩擦轮：左、右、上。
- 目标转速根据需要的弹速计算。
- `fire_speed` 可能根据裁判反馈的弹速变化调整。

### 3.2 Fire_OFF

```text
Fire_OFF:
  非 RELAX 时：把速度参考设为 0
  但 SMC 仍可能产生制动电流
  不能说 Fire_OFF 必然所有摩擦轮电流为 0
```

关键区别：

- Fire_OFF 把目标轮速设为 0。
- 但电机还在转，反馈 RPM 不为零。
- 滑模控制器看到误差，仍会输出制动电流。
- 只有 RELAX 才明确把四路电流归零。

### 3.3 RELAX

```text
Launcher_Relax_Handle:
  四路 give_current 归零
  重置拨盘累计角参考
```

- 这是明确的安全动作。
- 所有发射相关电流清零。
- 拨盘参考重置，下次重新开始。

文档提醒：

> 不能从某个函数归零就断言全系统同时已停止：其他任务、缓存、发送队列和驱动超时仍要核对。

## 四、拨盘送弹逻辑

### 4.1 拨盘级联控制

```text
外环（角度环）：
  angle_error = feeder_target_angle - feeder_current_angle
  feeder_target_speed = Kp_angle * angle_error
  限幅到 ±max_speed

内环（速度环）：
  speed_error = feeder_target_speed - feeder_measured_speed
  feeder_give_current = Kp_speed * speed_error + Ki_speed * integral
  限幅到 ±max_current
```

### 4.2 送弹流程

```text
进入 SINGLE:
  feeder_target_angle = feeder_current_angle + 送弹角度
  示例：feeder_current_angle = 10000
       送弹角度 = 8192（一圈）
       feeder_target_angle = 18192
  trigger_timer = 0
  jam_counter = 0
```

拨盘转动，逐渐接近目标角。到达后：

```text
feeder_current_angle ≈ feeder_target_angle
angle_error ≈ 0
feeder_target_speed ≈ 0
feeder_give_current ≈ 0
状态回到 READY
```

## 五、堵转逻辑

### 5.1 为什么需要堵转判断

拨盘送弹时，如果弹丸卡住：

- 电机继续转，但拨盘转不动。
- 电流持续增大。
- 可能烧电机或损坏机构。

所以需要检测堵转，并及时处理。

### 5.2 常见错误做法

> 电流大就是堵转。

这是不对的。因为：

- 启动瞬间电流也大。
- 加速时电流也大。
- 负载变化时电流也大。

只看电流会误判。

### 5.3 源码做法

文档说：

> 堵转判断用目标与累计编码差、HAL 时间和状态，不是简单“电流大即堵转”。

翻译：

- **目标与累计编码差**：拨盘应该转到的角度，和实际转到的角度，差多少。
- **HAL 时间**：从开始送弹到现在，过了多久。
- **状态**：当前在 SINGLE、BLOCK 还是其他状态。

判断逻辑：

```text
如果：
  拨盘在 SINGLE 状态
  目标角度和实际角度差 > TRI_MINECD
  持续时间 > MAXTIME
则：
  判定为堵转
  进入 BLOCK 状态
```

### 5.4 阈值

文档提到：

- `TRI_MINECD = 5000`
- `MAXTIME = 1000`

解释：

- `TRI_MINECD`：编码器差值阈值。
- `MAXTIME`：时间阈值。

注意：

- 5000 个编码器计数对应多少角度？要看编码器一圈多少计数。
- 1000 是什么单位？tick 还是 ms？要看 HAL 时间定义。
- 等于阈值的分支还要注意严格 `<` 和 `>`。

### 5.5 堵转处理

```text
进入 BLOCK:
  停止拨盘电机
  feeder_target_speed = 0
  feeder_give_current = 0（或制动电流）
  摩擦轮：保持当前目标转速，不停
  jam_counter += 1
```

### 5.6 退弹

```text
进入 BACK:
  feeder_target_angle = feeder_current_angle - 退弹角度
  示例：feeder_current_angle = 10050
       退弹角度 = 2048
       feeder_target_angle = 8002
  feeder_target_speed = 负值（反向转）
  feeder_give_current = 负值
  trigger_timer = 0（重置计时）
```

退弹逻辑：

- 反向转，把卡住的弹退出来。
- 退弹角度通常比送弹角度小。
- 退弹速度可能比送弹慢，避免二次卡住。

### 5.7 退弹成功或失败

```text
退弹成功:
  状态：BACK → READY
  feeder_current_angle ≈ feeder_target_angle
  angle_error ≈ 0
  弹已退出，机构恢复正常

退弹失败:
  状态：BACK
  feeder_current_angle 几乎不变
  angle_error 仍然大
  trigger_timer 递增
  超过 MAXTIME 后再次判定堵转
  jam_counter += 1
  如果 jam_counter < 最大尝试次数：再次进入 BACK 或 BLOCK
  如果 jam_counter >= 最大尝试次数：进入 FAIL
```

### 5.8 FAIL

```text
状态：FAIL
feeder_target_speed = 0
feeder_give_current = 0
摩擦轮：可能继续转，也可能停止，取决于设计
等待人工处理或重新初始化
```

## 六、摩擦轮滑模控制（SMC）

### 6.1 滑模面

\[
s = \dot e + c \cdot e
\]

其中：

- \(e = \text{target\_rpm} - \text{measured\_rpm}\)：转速误差。
- \(\dot e = (e - e_{\text{previous}}) / dt\)：误差变化率。
- \(c\)：正系数。

### 6.2 滑模面意义

\(s = 0\) 定义了一个理想关系：

\[
\dot e = -c \cdot e
\]

解为：

\[
e(t) = e(0) \cdot e^{-ct}
\]

误差按指数速度衰减到零。

### 6.3 控制律

\[
u_{\text{internal}} = -c \cdot e - \rho \cdot \text{sat}\left(\frac{s}{\epsilon}\right)
\]

拆成两部分：

| 部分 | 名称 | 作用 |
|---|---|---|
| \(-c \cdot e\) | 等效控制 | 维持系统在滑模面上 |
| \(-\rho \cdot \text{sat}(s/\epsilon)\) | 趋近控制 | 把系统推到滑模面上 |

### 6.4 饱和函数

\[
\text{sat}(s/\epsilon) =
\begin{cases}
s/\epsilon, & |s| \leq \epsilon \\
+1, & s > \epsilon \\
-1, & s < -\epsilon
\end{cases}
\]

作用：在 \(s=0\) 附近平滑过渡，减少抖振。代价：边界层内留下小残差。

### 6.5 源码参数与手算

| 符号 | 值 | 含义 |
|---|---|---|
| \(c\) | 5 | 滑模面系数 |
| \(\rho\) | 2 | 趋近增益 |
| \(\epsilon\) | 1 | 边界层宽度 |
| \(dt\) | 0.001 s | 差分时间步 |
| \(max\_i\) | 10000 | 输出限幅 |

手算：

- 目标 RPM = 6000
- 测得 RPM = 5900
- 上次误差 = 98

\[
e = 100
\]

\[
\dot e = \frac{100 - 98}{0.001} = 2000
\]

\[
s = 2000 + 5 \times 100 = 2500
\]

\[
\text{sat} = +1
\]

\[
u_{\text{internal}} = -5 \times 100 - 2 \times 1 = -502
\]

外部负号：

\[
give\_current = +502
\]

注意：502 是协议电流尺度，不是安培。

### 6.6 外部负号

- 内部：\(u_{\text{internal}} = -c e - \rho \cdot \text{sat}\)
- 外部：\(give\_current = -u_{\text{internal}}\)

外部负号是为了**修正电机安装方向**。控制器假设正输出使电机正转，但实际电机可能相反。

### 6.7 版本说明

- `launcher.c` 定义了普通 PID 和 VSP 参数并初始化。
- 当前三个 `VSP_PID_Calc` 调用**被注释**。
- 实际活动代码是 `update_system → -smc_controller`。
- 不能说 PID、VSP、SMC 同时并行使用。

## 七、教学代码 launcher_control.py

### 7.1 被控对象

```python
speed += dt * (u - speed - load) / TIME_CONSTANT
```

- `TIME_CONSTANT = 0.15` s
- 模型：`0.15 * v_dot = u - v - load`
- 目标 = 1（归一化速度）
- 负载在 t ∈ [1, 1.2) 时为 0.6，其余为 0

### 7.2 PI 控制器

```python
candidate = np.clip(integral + error * dt, -1, 1)
raw = 4 * error + 3 * candidate
if abs(raw) < 5 or raw * error < 0:
    integral = candidate
u = np.clip(4 * error + 3 * integral, -5, 5)
```

- P = 4，I = 3
- 有抗积分饱和
- 输出限幅 ±5

### 7.3 边界滑模控制器

```python
def sliding_speed_control(error, rate, gain, boundary):
    return float(rate + TIME_CONSTANT * gain * np.clip(error / boundary, -1, 1))
```

- `rate` 参数实际是**测得轮速 v**，不是误差导数。
- 滑模面：`s = error = 1 - v`。
- 控制律：`u = v + T * k * sat(e/φ)`。

### 7.4 手算

v = 0.9，e = 0.1，k = 5，φ = 0.2：

- `sat = 0.1 / 0.2 = 0.5`
- `u = 0.9 + 0.15 × 5 × 0.5 = 1.275`
- 无负载：`v_dot = (1.275 - 0.9) / 0.15 = 2.5`
- `e_dot = -2.5`

### 7.5 教学 vs 源码

| | 源码 | 教学 |
|---|---|---|
| 滑模面 | `s = e_dot + c e` | `s = e = 1 - v` |
| 控制律 | `u = -c e - ρ sat(s/ε)` | `u = v + T k sat(e/φ)` |
| 外部负号 | 有 | 无 |
| 拨盘逻辑 | 有 | 无 |
| 堵转判断 | 有 | 无 |

教学脚本只覆盖摩擦轮转速控制，不覆盖完整发射逻辑。

# 第二部分：麦轮运动学与轮速反馈

## 一、麦轮结构

### 1.1 普通轮子 vs 麦轮

普通轮子：

- 只能沿一个方向滚动。
- 想横移，必须整辆车转方向。

麦轮：

- 轮子外圈有一圈斜着的小滚子。
- 滚子允许轮子在某个方向自由滑动。
- 同时轮子的驱动方向仍能推地。

### 1.2 X 型布局

```text
FL ↘        ↙ FR
     \      /
      \    /
      /    \
     /      \
RL ↗        ↖ RR
```

- FL：左前
- FR：右前
- RL：左后
- RR：右后

---

## 二、为什么每只轮子不只管一个方向

车体要：

- 前进 \(v_x\)
- 横移 \(v_y\)
- 旋转 \(\omega\)

四只轮子都会同时感受到这三种运动的影响。

每只轮子的目标转速：

\[
\omega_w = \frac{1}{r} \cdot (\text{前进分量} + \text{横移分量} + \text{旋转分量})
\]

---

## 三、麦轮矩阵推导

### 3.1 轮子处的速度

轮子不只在车体中心，它在四个角上。

车体既有平移，又有旋转。

轮子处的总速度：

\[
\vec{v}_{\text{wheel}} = \vec{v}_{\text{body}} + \vec{\omega} \times \vec{r}
\]

二维叉积：

\[
\omega \times (r_x, r_y) = (-\omega \cdot r_y, \omega \cdot r_x)
\]

所以：

\[
\vec{v}_{\text{wheel}} = (v_x - \omega r_y, \quad v_y + \omega r_x)
\]

### 3.2 为什么 \(\omega \times (r_x, r_y) = (-\omega r_y, \omega r_x)\)

三维叉积：

\[
(a_1, a_2, a_3) \times (b_1, b_2, b_3) = (a_2 b_3 - a_3 b_2, \quad a_3 b_1 - a_1 b_3, \quad a_1 b_2 - a_2 b_1)
\]

代入 \(\vec{\omega} = (0, 0, \omega)\)，\(\vec{r} = (r_x, r_y, 0)\)：

- 第一分量：\(0 \cdot 0 - \omega \cdot r_y = -\omega r_y\)
- 第二分量：\(\omega \cdot r_x - 0 \cdot 0 = \omega r_x\)
- 第三分量：\(0 \cdot r_y - 0 \cdot r_x = 0\)

结果：

\[
\vec{\omega} \times \vec{r} = (-\omega r_y, \omega r_x, 0)
\]

### 3.3 投影到驱动方向

麦轮有两个方向：

| 方向 | 含义 | 能否传递力 |
|---|---|---|
| 驱动方向 | 轮子转动时推地的方向 | 能 |
| 自由方向 | 滚子允许滑动的方向 | 不能 |

只有驱动方向分量驱动轮子。

投影 = 点乘。

### 3.4 逐轮推导

| 轮子 | 位置 | 驱动方向 | 投影公式 |
|---|---|---|---|
| FL | \((a, b)\) | \((1, -1)\) | \((v_x - \omega b) - (v_y + \omega a)\) |
| FR | \((a, -b)\) | \((1, 1)\) | \((v_x + \omega b) + (v_y + \omega a)\) |
| RL | \((-a, b)\) | \((1, 1)\) | \((v_x - \omega b) + (v_y - \omega a)\) |
| RR | \((-a, -b)\) | \((1, -1)\) | \((v_x + \omega b) - (v_y - \omega a)\) |

### 3.5 矩阵形式

\[
\omega_w = \frac{1}{r}
\begin{bmatrix}
1 & -1 & -d \\
1 & 1 & d \\
1 & 1 & -d \\
1 & -1 & d
\end{bmatrix}
\begin{bmatrix}
v_x \\ v_y \\ \omega
\end{bmatrix}
\]

其中 \(d = a + b\)。

### 3.6 每列含义

| 列 | 含义 |
|---|---|
| 第一列 | 前进，四轮都加 |
| 第二列 | 横移，对角正负 |
| 第三列 | 旋转，左负右正 |

## 五、源码轮序和教学不同

### 5.1 源码公式

```text
wheel0 = (vy - vx + vw * rotate_ratio_f)   // RF
wheel1 = (vy + vx + ...)                    // LF
wheel2 = (-vy - vx + vw * rotate_ratio_b)  // RB
wheel3 = (-vy + vx + ...)                   // LB
```

源码轮序：RF/LF/RB/LB。

教学轮序：FL/FR/RL/RR。

### 5.2 不能直接换

| 项目 | 教学 | 源码 |
|---|---|---|
| 轮序 | FL/FR/RL/RR | RF/LF/RB/LB |
| 前进方向 | +x 前 | 源码自己的约定 |
| 横移方向 | +y 左 | 源码自己的约定 |
| 旋转比例 | d = a + b | rotate_ratio_f、rotate_ratio_b 可能不同 |
| 电机正方向 | 教学定义 | 实际电机安装 |

必须显式对齐。

## 六、统一缩放

### 6.1 为什么需要缩放

四轮目标 RPM 可能超过电机上限。

### 6.2 独立截断的问题

```text
[100, 200, -100, -200] → [100, 150, -100, -150]
```

比例变了，车会往别的方向走。

### 6.3 统一缩放

```text
max = 200
scale = 150 / 200 = 0.75
[100, 200, -100, -200] × 0.75 = [75, 150, -75, -150]
```

比例保持，整体变慢。

### 6.4 源码实现

```text
先算 int16_t wheel_rpm
再求 max
如果 max > M3508_MAX_RPM
  统一乘 scale = M3508_MAX_RPM / max
```

整数化会有小量化误差。

## 八、矩阵的逆

### 8.1 为什么需要逆

已知四轮速度，反推车体运动：

\[
\text{body} = A^+ \cdot \omega_w
\]

用途：里程计、打滑检测、状态估计。

### 8.2 相容性

\(A\) 是 4×3，满列秩。

任意四轮速度不一定满足无滑动的刚体运动。

只有落在 \(A\) 的列空间里的四轮速度，才对应真实刚体运动。

### 8.3 打滑影响

单轮打滑时，理想矩阵不再准确，里程计会漂。

# 第三部分：功率缓冲与输出缩放

## 一、为什么需要功率限制

### 1.1 现实场景

英雄机器人同时要做很多事：

- 云台跟踪目标。
- 摩擦轮高速旋转。
- 拨盘准备送弹。
- 底盘快速移动。

这些都需要电。但电池和裁判系统有功率上限。

如果不管功率：

- 可能触发裁判罚则。
- 可能拉低电压，影响其他子系统。
- 可能烧保险丝。

### 1.2 谁来提供功率预算

裁判系统会给出：

| 信息 | 含义 |
|---|---|
| `chassis_power_limit` | 底盘允许的功率上限 |
| `power_management_chassis_output` | 是否允许底盘输出 |
| 缓冲能量信息 | 超级电容还剩多少能量 |

源码里：

```text
限制来源 = Referee.GameRobotStat.chassis_power_limit - 5
```

减 5 留余量。

---

## 二、基础物理：功率、能量、电流

### 2.1 功率 W

功率是**每秒使用多少能量**。

\[
P = \frac{dE}{dt}
\]

单位：瓦特，W = J/s。

机械功率：

\[
P = \tau \cdot \omega
\]

电功率：

\[
P \approx U \cdot I
\]

铜耗：

\[
P_{\text{铜}} = I^2 R
\]

### 2.2 能量 J

能量是**存量**。

\[
E = \int P \, dt
\]

单位：焦耳，J。

缓冲能量：

\[
E_{\text{next}} \approx E + (P_{\text{allow}} - P_{\text{used}}) \cdot dt
\]

### 2.3 功率和能量的区别

| | 功率 | 能量 |
|---|---|---|
| 单位 | W = J/s | J |
| 含义 | 每秒用多少 | 总共还剩多少 |
| 类比 | 水龙头流量 | 水箱里有多少水 |

### 2.4 缓冲能量公式解释

想象一个水箱：

- 进水口：允许功率 \(P_{\text{allow}}\)，单位 W。
- 出水口：实际功率 \(P_{\text{used}}\)，单位 W。
- 水箱里的水：缓冲能量 \(E\)，单位 J。

净功率：

\[
P_{\text{allow}} - P_{\text{used}}
\]

- 正：缓冲充电。
- 负：缓冲放电。

乘以 \(dt\)：

\[
(P_{\text{allow}} - P_{\text{used}}) \times dt
\]

单位：W × s = J。

加到 \(E\) 上：

\[
E_{\text{next}} = E + (P_{\text{allow}} - P_{\text{used}}) \times dt
\]

### 2.5 超级电容

超级电容就像一个水桶：

- 电机需要大功率时，水桶帮忙放水。
- 电机功率需求低时，水桶存水。

裁判看的是电池输出是否超过上限，电容充放电是内部的事。

---

## 三、功率模型 \(P(k) = a k^2 + b k + c\)

### 3.1 一个电机的功率组成

机械功率：

\[
P_{\text{mech}} = \tau \cdot \omega
\]

铜耗：

\[
P_{\text{copper}} = I^2 \cdot R
\]

总功率：

\[
P = P_{\text{mech}} + P_{\text{copper}} + P_{\text{other}}
\]

### 3.2 缩放系数 k

源码把四个轮子的**目标速度**都乘一个系数 k：

\[
\omega_{\text{target}}' = k \cdot \omega_{\text{target}}
\]

### 3.3 缩放后电流怎么变

稳态下电流和力矩成正比：

\[
\tau = K_t \cdot I
\]

目标速度降低后，所需力矩也变小：

\[
I' \propto \tau' \propto k \cdot I
\]

### 3.4 机械功率怎么变

- 如果负载是粘性摩擦：力矩和速度都乘 k，机械功率乘 k²。
- 如果负载是恒定摩擦：力矩不变，机械功率乘 k。
- 真实负载介于两者之间。

所以机械功率是两部分之和：

\[
P_{\text{mech}}' = a_1 \cdot k^2 + b_1 \cdot k
\]

### 3.5 铜耗怎么变

\[
P_{\text{copper}}' = (k \cdot I)^2 \cdot R = k^2 \cdot I^2 R = k^2 \cdot P_{\text{copper}}
\]

铜耗乘 k²。

### 3.6 静态损耗

驱动器、传感器、控制器本身也耗电，基本不随 k 变，是常数：

\[
P_{\text{static}} = c
\]

### 3.7 合起来

\[
P(k) = \underbrace{a k^2}_{\text{铜耗 + 部分机械}} + \underbrace{b k}_{\text{另一部分机械}} + \underbrace{c}_{\text{静态}}
\]

| 系数 | 来源 | 物理含义 |
|---|---|---|
| \(a\) | \(I^2 R\) + 部分机械功率 | 与 k² 成正比 |
| \(b\) | 部分机械功率 | 与 k 成正比 |
| \(c\) | 常数项 | 静态损耗 |

---

## 四、a、b、c 怎么算

### 4.1 核心思路

a、b、c 不是直接给的，而是**用轮 PID 参数和测得 RPM 算出来的**。

### 4.2 单个轮子的电流

轮 PID 输出：

\[
I = K_p \cdot e + K_i \cdot \int e
\]

误差：

\[
e = \text{target\_rpm} - \text{measured\_rpm}
\]

缩放后：

\[
e(k) = k \cdot \text{target\_rpm} - \text{measured\_rpm}
\]

代入：

\[
I(k) = K_p \cdot (k \cdot \text{target\_rpm} - \text{measured\_rpm}) + K_i \cdot \int e
\]

整理：

\[
I(k) = A \cdot k + B
\]

其中：

\[
A = K_p \cdot \text{target\_rpm}
\]

\[
B = -K_p \cdot \text{measured\_rpm} + K_i \cdot \int e
\]

### 4.3 单个轮子的功率

\[
P(k) = (A k + B)^2 R + K_t (A k + B) \cdot k \cdot \omega_{\text{target}}
\]

展开合并：

\[
P(k) = \underbrace{(R A^2 + K_t A \omega_{\text{target}})}_{a_i} k^2 + \underbrace{(2RAB + K_t B \omega_{\text{target}})}_{b_i} k + \underbrace{RB^2}_{c_i}
\]

### 4.4 四个轮子加起来

\[
a = \sum_{i=1}^{4} a_i
\]

\[
b = \sum_{i=1}^{4} b_i
\]

\[
c = \sum_{i=1}^{4} c_i
\]

### 4.5 简化理解

| 系数 | 来源 | 物理含义 |
|---|---|---|
| \(a\) | 铜耗和部分机械功率 | 与 k² 成正比 |
| \(b\) | 部分机械功率 | 与 k 成正比 |
| \(c\) | 静态损耗 | 常数 |

a、b、c 都是从 PID 参数和 RPM 算出来的，不是手动设的。

---

## 五、判断是否超出功率限制

### 5.1 方法

先用 k=1 代入，算当前功率：

\[
P(1) = a \cdot 1^2 + b \cdot 1 + c = a + b + c
\]

- 如果 \(P(1) \leq P_{\text{limit}}\)：不超限，k=1，不缩放。
- 如果 \(P(1) > P_{\text{limit}}\)：超限，需要解方程找 k < 1。

### 5.2 举例

假设：

- \(a = 0.5\)
- \(b = 2.0\)
- \(c = 1.0\)
- \(P_{\text{limit}} = 25\) W

\[
P(1) = 0.5 + 2.0 + 1.0 = 3.5 \text{ W}
\]

\[
3.5 < 25
\]

不超限。

再假设：

- \(a = 10\)
- \(b = 20\)
- \(c = 5\)

\[
P(1) = 10 + 20 + 5 = 35 \text{ W}
\]

\[
35 > 25
\]

超限，需要缩放。

---

## 六、解二次式求 k

### 6.1 目标

要满足：

\[
a k^2 + b k + c \leq P_{\text{limit}}
\]

即：

\[
a k^2 + b k + (c - P_{\text{limit}}) = 0
\]

### 6.2 求根

\[
k = \frac{-b \pm \sqrt{b^2 - 4a(c - P_{\text{limit}})}}{2a}
\]

取合理根，限制在 [0, 1]。

### 6.3 限制 k

- \(k < 0\)：取 0。
- \(k > 1\)：取 1。
- \(0 \leq k \leq 1\)：正常。

### 6.4 边界情况

| 情况 | 处理 |
|---|---|
| \(a \approx 0\) | 退化为一次方程 |
| 判别式 < 0 | 无实数解 |
| \(c > P_{\text{limit}}\) | 即使 k=0 也超 |
| 所有系数为 0 | 无功率信息 |

### 6.5 完整例子

假设：

- \(a = 10\)
- \(b = 20\)
- \(c = 5\)
- \(P_{\text{limit}} = 25\)

\[
10 k^2 + 20 k + 5 = 25
\]

\[
10 k^2 + 20 k - 20 = 0
\]

\[
k^2 + 2k - 2 = 0
\]

\[
k = \frac{-2 + \sqrt{4 + 8}}{2} = \frac{-2 + 3.464}{2} = 0.732
\]

---

## 七、恢复平滑

### 7.1 公式

\[
k_c \leftarrow k_c + (1 - k_c) \cdot k
\]

- \(k_c\)：当前实际用的缩放系数。
- \(k\)：恢复速度参数，比如 0.1。
- \(1 - k_c\)：距离 1 还有多远。

翻译：

> 每周期让 \(k_c\) 向 1 靠近一点点。

### 7.2 数字走一遍

假设 \(k_c = 0.5\)，恢复速度 \(k = 0.1\)：

| 周期 | k_c |
|---|---|
| 0 | 0.500 |
| 1 | 0.550 |
| 2 | 0.595 |
| 3 | 0.636 |
| 4 | 0.672 |
| 5 | 0.705 |
| ... | ... |
| 很多周期后 | 接近 1 |

### 7.3 为什么要这样

如果直接从 0.5 跳到 1：

- 底盘动作突然变强。
- 可能让车抖动。
- 可能让功率瞬间超限。

平滑恢复让动作逐渐变强，更稳定。

### 7.4 和功率限制的关系

```text
1. 解二次式，得到目标缩放 k_solve
2. 如果 k_solve < k_c：
     直接取 k_c = k_solve（限制介入，立即缩小）
3. 如果 k_solve >= k_c：
     k_c += (1 - k_c) * k（慢慢恢复）
4. rpm_set *= k_c
```

### 7.5 注意

文档说：

> 恢复平滑后不再严格满足原阈值。

翻译：

- 平滑恢复后，实际功率可能重新超过限制。
- 不能把它当成绝对硬保证。

---

## 八、统一缩放

### 8.1 四轮同乘

\[
\omega_{\text{new}} = k_c \cdot \omega_{\text{old}}
\]

- 保持比例。
- 保持方向。
- 整体变慢。

### 8.2 为什么不用逐轮缩放

逐轮缩放会改变方向比例，车会往别的方向走。

## 九、源码已知问题

文档提到：

> calc_power_limit 里 sum_err 约束两个边界都为负 MAX 的调用值得核对，不能把其解释成正常对称积分限幅。

翻译：

- 代码里有个 `sum_err` 约束。
- 两个边界都是负的 MAX。
- 正常积分限幅应该是 \([-MAX, +MAX]\)。
- 两个都是负 MAX，意味着积分只能在负区间变化。
- 这可能是 bug，也可能有特殊原因，需要核对。

# 第四部分：完整数据流总结

## 一、发射链路

```text
遥控/裁判/模式
  ↓
Fire_ON / Fire_OFF
  ↓
设置摩擦轮目标 RPM
设置拨盘状态和目标角
  ↓
update_system
  ↓
smc_controller（摩擦轮）
  ↓
give_current
  ↓
CAN 发送

拨盘：
  feeder_target_angle
  ↓
  角度环 → feeder_target_speed
  ↓
  速度环 → feeder_give_current
  ↓
  Trigger_Finish_Judge 判断完成/堵转
  ↓
  状态转移
```

## 二、底盘链路

```text
车体速度 [vx, vy, ω]
  ↓
麦轮矩阵
  ↓
四轮目标 RPM
  ↓
最大轮同比缩放
  ↓
功率限制缩放（乘 k_c）
  ↓
四轮 PID
  ↓
give_current
  ↓
CAN 发送
```

## 三、功率限制内部流程

```text
1. 读轮 PID 参数、测得 RPM、目标 RPM
2. 建立电流估计
3. 建立二次功率模型 a k² + b k + c
4. 读裁判功率上限，减 5
5. 读缓冲能量，低时加危险项
6. 解二次式求 k
7. 限 k 在 [0, 1]
8. 恢复平滑：k_c += (1 - k_c) * k
9. rpm_set *= k_c
10. 送入四轮 PID
```

# 第六部分：最直白的总结

## 发射逻辑

1. **两个部件**：摩擦轮管转速，拨盘管送弹位置。
2. **六个状态**：READY、SINGLE、BLOCK、BACK、FAIL、RELAX。
3. **正常流程**：READY → SINGLE → 到达目标角 → READY。
4. **堵转判断**：角差 > TRI_MINECD 且时间 > MAXTIME。
5. **堵转处理**：SINGLE → BLOCK → BACK → READY 或 FAIL。
6. **退弹**：反向转，角度小于送弹角，速度可能更慢。
7. **重试限制**：超过最大次数进入 FAIL。
8. **Fire_OFF vs RELAX**：前者设速度参考 0，后者所有电流归零。
9. **摩擦轮独立**：堵转不影响摩擦轮。
10. **边界**：阈值要按编码器齿比和时间单位解释，注意 `<` 和 `<=`。

## 麦轮运动学

1. **麦轮特殊**：外圈有斜滚子，允许一个方向自由滑动。
2. **驱动方向**：轮子能推地的方向，与车体轴成 45°。
3. **轮子位置**：四个角，旋转时每个轮子额外获得速度。
4. **关键公式**：轮子处速度 = 车体平移 + 旋转贡献。
5. **逐轮投影**：把轮子处速度投影到驱动方向，得到轮速。
6. **矩阵结果**：4×3，输入 [vx, vy, ω]，输出四轮角速度。
7. **每列含义**：前进全正，横移对角正负，旋转左负右正。
8. **手算**：[1, 0.5, 1] → [1, 19, 11, 9] rad/s。
9. **源码轮序不同**：RF/LF/RB/LB，不能直接换。
10. **统一缩放**：超过上限时四轮同乘 scale，保持方向比例。

## 功率限制

1. **总功率三部分**：铜耗、机械功率、静态损耗。
2. **铜耗**：I²R，电流乘 k，铜耗乘 k²。
3. **机械功率**：一部分乘 k²，一部分乘 k。
4. **静态损耗**：常数 c。
5. **合起来**：P = a k² + b k + c。
6. **a**：平方项系数，主要来自铜耗。
7. **b**：线性项系数，主要来自恒定摩擦。
8. **c**：常数项，静态损耗。
9. **判断超限**：算 P(1) = a + b + c，和 P_limit 比较。
10. **解二次式**：求满足功率限制的 k。
11. **限制 k**：在 [0, 1]。
12. **恢复平滑**：k_c += (1-k_c)k，慢慢向 1 恢复。
13. **统一缩放**：四轮同乘 k，保持方向。
14. **超级电容**：存能量，短时透支。
15. **功率 vs 能量**：W 和 J 不同，不能直接加减。
16. **低速大电流**：也可能高功率，不能只看速度。
17. **源码风险**：sum_err 两个负 MAX，需核对。
