# 2027 Fall 全学校英文面试准备

> 适用范围：正式提交包目录中列出的 11 个学校/项目方向。所有答案要以网申系统里的正式项目名、本人实际经历和面试邀请为准；本资料用于训练，不代表已收到面试邀请。

## 推荐阅读顺序

1. [学校清单与事实核验](01_学校清单与事实核验.md)：看清提交包、项目名称、招生批次和需本人核实的风险。
2. [网络面试信息核验与练习优先级](06_网络面试信息核验与练习优先级.md)：区分官方面试信息、申请者回忆和练习推断。
3. [通用英文回答与自我介绍](02_通用英文回答与自我介绍.md)：先练 30 秒/60 秒介绍、申请动机和职业规划。
4. [学校定制回答](02_学校定制/README.md)：只准备自己申请系统中实际对应的项目。
5. [项目与实习技术深挖](03_项目实习技术深挖.md)：沿输入、模型、算法、输出、执行、验证和局限做技术复盘。
6. [行为面试与团队合作](04_行为面试与团队合作.md)：练真实经历、责任边界、安全和协作。
7. [模拟面试与口语训练](05_模拟面试与口语训练.md)：做完整模拟、计时和自评分。

## 这套资料的事实边界

- 学校文件夹里有材料，不等于已完成网申或收到面试邀请。
- 学校网页写“可能面试”不等于每位申请者都会面试；未公布的语言、题目、形式和时长，不作推断。
- 个人贡献、团队成果、教学推导、仿真和实机结果分开表述。
- 没有日志或报告证据的精度、成功率、频率、延迟和提升比例，不编数字。
- 项目批次或名称如与申请系统不一致，以个人网申及官方邮件为准。

## 练习方法

每题先用英文讲 30–90 秒；面试官追问时再下钻。每次录音后只改三件事：事实是否准确、技术因果是否完整、英文能否一遍听懂。不要逐字死背。
