## 从手算到代码

1. covariance检查形状、对称与半正定；P,Q,R不能任意填负方差。
2. predict计算均值Ax+Bu和P的两侧传播；本例Q=σa²BBᵀ，过程扰动是每步恒定随机加速度，不是连续白噪声谱密度。
3. update创新y-Hx；S=HPHᵀ+R；解线性方程KS=PHᵀ，不显式求逆。
4. 均值修正x+Kr；Joseph形式更新P。S奇异明确报错；对称化只消除舍入反对称，不修复错误模型。
5. main先给两手算案例，再生成真值、测量和估计。输出与真值比较，未运行前不写实测RMSE。

预期标量P=4,R=1,x=10,y=12得K=.8,xnew=11.6,Pnew=.8。二状态P=[[4,1],[1,2]],H=[1,0],r=2得K=[.8,.2]ᵀ、状态[11.6,2.4]、Pnew=[[.8,.2],[.2,1.8]]。

`kalman.csv`包含时间、真位置速度、测量、估计、创新、两个增益、位置/速度方差与交叉协方差。位置方差m²，速度方差m²/s²，交叉m²/s；K速度分量1/s。seed仅固定教学噪声序列。

## 实验设计与故障

分别改measurement-std=.05/1，比较测量噪声与估计反应；改process-std=0/.8，观察模型不确定性。这里参数同时改变仿真噪声与估计器匹配假设；想研究错误调参，应只改Q或R、保留真值噪声，再记录两者。

把H改[0,1]要同时生成速度测量并改单位，不能只改矩阵。负方差拒绝；P=R=0,H=1让S=0应报错。固定偏置不是本例零均值噪声，加入后应解释估计偏差，而非宣布滤波自动消除。
