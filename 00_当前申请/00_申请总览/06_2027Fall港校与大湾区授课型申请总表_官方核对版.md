## 三、各校申请入口、流程与材料

### 1. 香港中文大学（深圳）SDS：MAIR 与 Computer Science

**申请入口**：

- [在线申请系统](https://pgapply.cuhk.edu.cn/)
- [MAIR 官方项目页](https://sds.cuhk.edu.cn/en/mair)
- [Computer Science 官方项目页](https://sds.cuhk.edu.cn/en/page/2132)

**申请流程**：

1. 注册港中深研究生申请系统；
2. 选择项目并填写个人、教育和联系方式；
3. 上传成绩单、排名、英语、CV、PS及身份证明；
4. 填写两位推荐人的邮箱；
5. 支付 RMB 600 申请费；
6. 等待材料初审；
7. 初审通过后，根据邮件参加 assessment/exam；
8. 在系统查看结果并按 offer 要求确认入学。

**官网明确材料**：

- 学位证/在读证明；
- 官方成绩单，须体现课程和成绩，并有教务处或学院盖章；
- 专业排名证明；
- IELTS/TOEFL/GMAT 成绩单；
- 英文 CV；
- 英文 Personal Statement，MAIR和CS页面均约600词；
- 身份证正反面；
- 两封推荐信，推荐信落款需要推荐人签名；
- 其他获奖、实习、项目或资格证明。

**推荐信方式**：在系统填写推荐人邮箱后，学校会向推荐人发送相关邮件或链接。申请人不能替推荐人冒充提交机密推荐信。两位推荐人应分别确认内容并在允许的格式上签字。

### 3. 香港理工大学 MSc Intelligent Robotics Engineering

**申请入口**：[2027 项目页面](https://www.polyu.edu.hk/study/pg/tpg/2027/43101-ir-irt)｜[PolyU eAdmission](https://www38.polyu.edu.hk/eAdmission/index.do)

**流程**：

1. 在 eAdmission 注册账户；
2. 选择 43101 Intelligent Robotics Engineering；
3. 填写教育背景、英语成绩和经历；
4. 上传系统要求的成绩单、证书和 CV；
5. 按系统要求上传 PS、推荐信或补充材料；
6. 支付 HK$600 申请费；
7. 等待学院审核；
8. 合适申请人可能收到面试或测试邀请；
9. 查看 offer 并按规定确认入学。

**官网当前明确内容**：

- 相关工程或理科本科背景；
- 31 学分，1.5 年全日制；
- 核心课程包括具身机器人智能、机器人机构、机器人运动规划、软体机器人、先进控制技术和先进机电产品；
- 课程页将 CV 列为附加材料，成绩单/证书为必需材料，其他材料可按申请情况提交；
- 学费 HK$9,000/学分，1 学分的工程伦理课程不收费，因此按30个收费学分约 HK$270,000；
- 合适候选人可能参加面试；课程通常安排在工作日晚上，也可能有白天或周末安排。

建议你仍准备一份 PolyU 专用 PS 和两封推荐信，是否上传以系统字段为准。PS重点写机器人控制、运动规划、状态估计和实机验证，不要把材料重心放在普通软件开发。

### 4. 香港城市大学本部：P75、P53 与 P66

**申请入口**：[城大在线申请](https://www.cityu.edu.hk/en/pg/taught-postgraduate-programmes/apply-now)｜[项目总表](https://www.cityu.edu.hk/pg/taught-postgraduate-programmes/list)

4. 支付每个项目 HK$600 申请费；
5. 等待学院滚动审核；
6. 若项目要求面试或补充材料，按邮件完成；
7. 在系统查看 offer，并按 offer letter 规定确认入学。

**材料准备**：

- 身份证或护照；
- 学位证/在读证明；

**三项目的材料重点**：

城大当前页面主要仍为 2026 入学信息。P75、P53和P66的2027具体截止日期、学费和申请字段，必须等 2027 页面更新后重新核对。

### 5. 香港城市大学（东莞）：AI、CS 与 EEE

**申请入口**：[东莞研究生招生主页](https://pga.cityu-dg.edu.cn/)｜[研究生项目列表](https://pga.cityu-dg.edu.cn/programmes)

**统一流程**：

1. 进入东莞研究生招生网站；
2. 选择项目并在线填写申请；
3. 上传学历、成绩单、英语及系统要求的补充材料；
4. 参加项目要求的面试或其他考核；
5. 等待滚动录取结果；
6. 收到 offer 后，在规定期限内支付首笔学费确认入学。

**当前官网可以确认的信息**：

- AI：2年，当前学费 RMB150,000/年，申请费免费；
- CS：2年，当前学费 RMB140,000/年，申请费免费；

你的优先顺序应为 **AI > CS > EEE**。东莞 AI 更贴近机器人算法和AI就业，CS更稳妥但方向宽泛，EEE主要偏电子、通信和电力系统。2027 Fall的新学费、申请时间和系统字段尚未公布，不能直接照搬2026页面。

## 四、通用材料包

### 需要提前准备的文件

| 材料 | 版本 | 使用说明 |
|---|---|---|
| 护照/身份证明 | 彩色 PDF | 港中深和东莞项目尤其注意身份证正反面要求 |
| 在读证明/学位证 | 中英文 PDF | 应与申请状态一致；毕业后再补最终学位材料 |
| 官方成绩单 | 中英文盖章 PDF | 不使用截图；必要时附 GPA 计算方式 |
| 专业排名证明 | 中文或英文盖章 PDF | 港中深明确鼓励提交；你的排名属于重要优势 |
| IELTS 成绩单 | 官方电子版 PDF | 你的 IELTS 6.5优先使用；无需在 CV 中写四六级分数 |
| 通用英文 CV | PDF | 只保留当前提交版；根据专业选择轻微调整顺序 |
| 专属英文 PS | PDF/系统文本 | 必须按项目课程和职业目标调整；严格遵守字数 |
| 学术推荐信 | 英文 PDF/系统提交 | 傅向华副院长；内容只写其实际了解的课程、成绩和校内表现 |
| 企业推荐信 | 英文 PDF/系统提交 | AIRS导师；内容只写其实际观察到的实习工作 |
| 项目/竞赛证明 | PDF | 按项目相关度选择，不要无差别上传全部文件 |
| 中文对照版 | 留底 | 用于核对和面试准备，不作为英文项目的替代提交件 |

### 当前材料的统一原则

- 英文 CV、PS、推荐信中的姓名、日期、学位、成绩、排名和项目顺序必须一致；
- 申请材料中重点呈现机器人算法、控制、导航、感知和实机验证；
- OpenHarmony、BSP、CAN、FreeRTOS等工程内容只作为支撑，不盖过机器人算法主线；
- 团队项目只写自己能够在面试中解释的模块；
- 推荐信必须由真实推荐人确认、修改并按系统要求提交；
- 学校没有要求推荐信时，保留两封备用，不强行上传；
- PDF必须可阅读、可复制文字，避免直接拍照或低清扫描。

## 六、预算与住宿判断

| 项目类型 | 判断 |
|---|---|
| 港中深 | 学费接近预算上限，但在深圳就读，生活与住宿成本更可控；MAIR和CS均需预留额外生活费 |
| 港城莞 | 学费和住宿显著低于香港本部，最适合作为预算友好的保底；当前住宿价格以官方页面为准，2027需复核 |
| 港理工/港城本部/港科大本部 | 学费可能在预算范围内，但香港租房、饮食和交通会使总成本明显上升；不能只看学费 |
| 港科广 | 学费目前可接受，但2027收费、住宿和具体安排需等项目页更新；建议按校内住宿规划 |

如果人民币 33 万是“全部花费”而不是“学费上限”，应优先保证港城莞 AI/CS，并谨慎考虑香港本部项目；港中深 MAIR 与 CS 需要单独核算住宿、交通和生活费。如果 33 万只是学费预算，主申项目组合可以保持当前规模。
