## 1. 反解是找满足规则的输入

正向已知关节速度，算末端速度：v=Jq̇。反向已知目标v，求q̇。先不谈复杂机器人，用：

\[
2q_1+q_2=10,\qquad q_2=4.
\]

从第二式得q2=4，代回第一式2q1+4=10，q1=3。就是求解Ax=b，A=[[2,1],[0,1]]，b=[10,4]。

q1、q2在本章是一般未知量，接到雅可比时才代表关节速度。求解结果要重新代回两条方程，不能只信软件没有报错。

## 2. 高斯消元的手算

考虑：

\[
x+2y=5,\qquad3x+4y=11.
\]

把第二行减去第一行的3倍：

\[
(3x+4y)-3(x+2y)=11-3\times5
\Longrightarrow-2y=-4.
\]

所以y=2，再代第一式x+4=5，x=1。

我们没有改变解：若原两式成立，它们的线性组合也成立；保留第一式和新第二式，又能恢复旧第二式。因此“某行减另一行倍数”保存方程组的解。

增广矩阵记录同一操作：

\[
\left[\begin{array}{cc|c}1&2&5\\3&4&11\end{array}\right]
\to
\left[\begin{array}{cc|c}1&2&5\\0&-2&-4\end{array}\right].
\]

竖线右边是b，不是A的一列。行交换、非零倍乘、减去另一行倍数是基本操作。

## 3. 逆矩阵是“所有输入都能唯一反解”的规则

若方阵A存在A^{-1}使：

\[
A^{-1}A=AA^{-1}=I,
\]

I是单位矩阵，对任何x都有Ix=x，那么从Ax=b左乘A^{-1}：x=A^{-1}b。

逆矩阵不是把每个元素变成倒数。A=[[2,1],[0,1]]的逆是：

\[
A^{-1}=\begin{bmatrix}.5&-.5\\0&1\end{bmatrix}.
\]

它编码的是q1=.5b1-.5b2，q2=b2。把b=[10,4]代入仍得[3,4]。

**求方程解**只求一个b对应的x；**求完整逆**把所有b的反解规则都算出来。工程上只需要一个解时用 `solve(A,b)`，不用先显式算完整逆。

## 4. 2×2逆公式怎样得到

\[
A=\begin{bmatrix}a&b\\c&d\end{bmatrix}.
\]

构造C=[[d,-b],[-c,a]]，直接乘：

\[
AC=\begin{bmatrix}ad-bc&-ab+ab\\cd-dc&ad-bc\end{bmatrix}
=(ad-bc)I.
\]

若ad-bc≠0，除以这个数得到I：

\[
\boxed{A^{-1}=\frac1{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}}.
\]

ad-bc叫行列式det(A)。当它为0，不能除。对更大方阵，用增广[A|I]消元到[I|A^{-1}]，不需要背巨大代数余子式展开。

手算A=[[1,2],[3,4]]，det=4-6=-2，逆=[[-2,1],[1.5,-.5]]。乘b=[5,11]：[-10+11,7.5-5.5]=[1,2]。

## 5. 方程为什么会无解或多解

改成：x+2y=5，2x+4y=10。第二式只是第一式2倍，没有提供新信息。可以取y=t，x=5-2t，所以无穷多解。

若第二式右边变11：2x+4y=11，与第一式2倍要求的10矛盾，消元得到0=1，因此无解。

两种情况A一样，是b决定是否能满足矛盾。奇异矩阵不意味着任何b都无解。

## 6. 秩是独立规则/独立输出方向的数量

秩可以从消元后的非零主元数理解。[[1,2],[2,4]]只有一个主元，rank=1。两行线性相关，两列也只提供一个独立方向。

满秩2×2提供两个独立方向，才能唯一从二维输出回到二维输入。一般A=m×n，rank≤min(m,n)：

- rank=n：满列秩，输入方向互相独立；
- rank=m：满行秩，覆盖所有输出方向；
- 方阵可逆：rank=n=m。

机器人直腿雅可比两列可能同向。你改变两个关节速度，仍只能在末端某些方向产生一阶速度。不是关节都停止了，是独立作用减少。

## 7. 3×3如何手算：以全向轮分配为例

设三轮线速度规则：s1=vy+ρω；s2=-√3vx/2-vy/2+ρω；s3=√3vx/2-vy/2+ρω。ρ≠0是轮到中心的几何距离。

三式相加：s1+s2+s3=3ρω，所以ω=(s1+s2+s3)/(3ρ)。第三式减第二式：s3-s2=√3vx，所以vx=(s3-s2)/√3。

第一式减去刚求的ρω：

\[
v_y=s_1-\frac{s_1+s_2+s_3}{3}
=\frac23s_1-\frac13s_2-\frac13s_3.
\]

这三条反解规则就是前向矩阵的逆M。不是凭空写出M，是消元把vx、vy、ω分别表达出来。若s=[1,1,1]m/s且ρ=.2m，vx=vy=0，ω=3/(.6)=5rad/s。符号和轮布局假设要与实际底盘一致；P1球体几何另讲。

## 8. 代码、限制与排查

```python
import numpy as np
A = np.array([[1., 2.], [3., 4.]])
b = np.array([5., 11.])
x = np.linalg.solve(A, b)
residual = A @ x - b
```

`residual`应接近0而不要求浮点数完全等于0。接近奇异时可能得到很大的x：小数误差会被放大，需看奇异值/条件数，而不只是det是否刚好等于0。

失败：①非方阵不能求普通逆，改用最小二乘/伪逆或约束优化。②主元极小，手算不稳定，应换主元并看尺度。③真实轮半径或符号错，数学反解正确仍是错误物理模型。

## 精读补充：把中间步骤讲清楚

### A. 增广矩阵求逆的每一步

A=[[1,2],[3,4]]。把单位矩阵并排，写[A|I]：

```
1  2 | 1  0
3  4 | 0  1
```

第二行减第一行3倍，得到 `[0,−2|−3,1]`；第二行除−2，得到 `[0,1|1.5,−.5]`；第一行减第二行2倍，得到 `[1,0|−2,1]`。左侧成为I，右侧就是A⁻¹=[[-2,1],[1.5,−.5]]。

为什么右侧同时操作？你在找把A变成I的整组行操作；相同操作施加到I，就得到这整组操作的矩阵。于是它乘A产生I，正是逆的定义。

### B. 行列式为零之后，仍要看目标

A=[[1,2],[2,4]]。b=[3,6]时，两式都要求x+2y=3，无穷多解；b=[3,7]时，第二式与第一式2倍矛盾，无解。不要把“奇异”直接翻译成“机器人完全不能动”：它失去某些独立任务方向，还可能沿可实现方向运动。

### C. 与伪逆怎样接起来？

普通逆想精确还原所有输入；非方阵或降秩时做不到。伪逆先考虑输出残差，再在等价最小残差解中取最小输入范数。接下来两章会从实际最小化问题算它，而不只是把A⁻¹符号换成A⁺。
