## 按代码学习

1. `gauss_solve`复制输入，找当前列绝对值最大的主元，再交换行，避免除以很小的数。
2. 消去主元下面的系数，把方程变为上三角，再从最后一行回代。奇异时明确报错。
3. `svd_pseudoinverse`取U、s、Vt，只对超过绝对阈值的奇异值倒数；乘回得到n×m映射。
4. `main`同时记录输入范数和残差：速度小不能单独证明跟踪好。

预期：方阵解[3,4]；[1,1]x=1的最小范数解[0.5,0.5]；奇异消元报错，但伪逆能给最小二乘解。weak的第二分量接近1000。把`--tolerance`设为0.01，弱方向被截断，该方向残差增大。

CSV `solutions.csv`列为案例、两个输入分量、残差范数、输入范数、奇异值；教学量无特定物理单位，单行秩案例只有一个奇异值，最后列留空。不可直接解释为某机器人关节速度。

练习：将b改为不在奇异矩阵列空间中的[1,3]，解释残差不为零；输入非方阵给消元应报形状错误。面试连接：Why is a pseudoinverse useful for redundant joints? 参考[伪逆教材](../../../01_通用基础/01_数学与物理基础/07_范数最小二乘与伪逆.md)。
